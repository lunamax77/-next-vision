## 2. レビューで評価されている点（＝訴求すべき点）

1. **「別途準備いらず・オールインワン」** … 離型剤まで同梱で、届いてすぐ作れるのが高評価。**最重要の購入理由**。
2. **作れる種類の多さ** … 1つのキットで複数モチーフが作れる満足感。
3. **起毛（フロッキング）でふわふわ** … 本物の肉球のような質感が「かわいい」と好評。差別化の核。
4. **安全性** … 無毒・低刺激・気泡が出にくい＝親子/ギフト需要に効く。
5. **手順が簡単** … 「まぜる→流す→待つ→外す」の分かりやすさ。レビュー最頻の高評価語が「簡単」。
6. **ギフト需要** … 「プレゼントにも◎」の声が多い。箱の見栄え・高級感が効く。

### 競合の弱み／付け入る隙（仮説）
- パッケージが**ティール系の一般的デザイン**で、ブランドの世界観が弱い。
- 手順・注意書きが分かりにくい/簡素との声も。→ **裏面の図解**で差別化余地。
- ブランドとしての継続購入導線（SNS・シリーズ展開）が弱い。

## 3. ぷにラボへの反映（パッケージ／企画）

### 3-1. パッケージに反映済み（プレビューに実装）
- 正面に **「これだけで作れる／オールインワン」シール** と **「ふわふわ起毛仕上げ」シール** を追加。
- 正面下部に **「6種類つくれる ・ 安心の低刺激シリコーン ・ 日本製」** を明記。
- **裏面を新設**：作り方 **かんたん4ステップ**（まぜる→いろづけ→型に流す→まって外す）を図解。
  - 「仕上げに起毛パウダーで本物みたいなふわふわに！」の一言を強調。
  - **セット内容（全部入り／別途準備不要）** を明記。
  - **ご使用上の注意**（対象年齢15歳以上・誤飲注意・換気・手袋推奨 等）を記載。
  - JANバーコード枠・製造者（株式会社ネクストビジョン／MADE IN JAPAN）を配置。
- 世界観は競合のティールを避け、**白×ぷにピンク×ラベンダー＋金**で「かわいい×少し高級」に。

### 3-2. 商品企画への提案（今後の検討事項）
- **型のラインナップ**：肉球を主役に、星・さくら・ねこ・ドーナツ等で「◯種類作れる」を最大化。
- **起毛仕上げ**を標準同梱にし、ぷにラボの体験価値の中心に据える。
- **安全訴求**：食品グレード相当・低刺激をパッケージと商品説明で明記（根拠資料は調達先から入手）。
- **ギフト対応**：化粧箱の質感を上げ、「プレゼントにも」の販促文言・ラッピング可否を検討。
- **シリーズ/継続**：季節限定カラー・追加型の単品販売でリピート導線を作る。
- **SNS動線**：箱・説明書にハッシュタグ／作例投稿の誘導（#ぷにラボ 等）。
