## 0. 案件概要

- **強み**: 猫の手スクイーズ(液状シリコーン製)を**原価約500円/個**で自社製造可能に。
- **競合**: MELLAB SQUISHY KIT = 自分で作るDIYキット、**4,000円で2個**作れる構成。
- **確定方針**:
  - 完成品スクイーズを**主力**(想定売価 680〜980円)
  - DIYキットを**上位ライン**(想定売価 2,480〜2,980円)
  - 競合より明確に安く、**量販狙い**
  - チャネル: メルカリ/minne/Creema で検証 → 自社EC/Amazon、**TikTok Shop** も視野

### 代表決定事項(2026-08-07 確定)
- **ブランド/キット名 = ぷにラボ(PuniLabo)** ※完成品ラインも同ブランドで統一
- **区分 = 玩具**(誤飲・小部品の注意表示、対象年齢設定、PL対策が必須)
- **商標 = 取得する**(第28類中心。実出願は弁理士依頼+承認後)
- **価格・送料(確定)**: 完成品 **基本880円 送料込み** / メルカリ **950〜990円 送料込み** / キット 2,480円+送料別
- **優先作業 = パッケージデザイン案 + EC掲載文**(→ 01, 02 参照)。デザインは実制作(プレビュー)に着手。
- **PL保険** = スクイーズ+エアー遊具を想定(業種7090はエアー遊具=物品賃貸業に対応)。推奨A-2(5億/21,250円)。専門家と相談中。
- **商標** = 弁理士は代表側で用意。社内で準備書類を作成(→ 04 参照)。
- 初回発注数 = 未定(小ロット検証: 完成品300個/キット50個を推奨、原価表待ち)

## 1. プロダクト(商品構成・原価)

### 競合キット推定原価
- 推定原価合計 **約1,250〜2,180円**(売価4,000円に対し原価率31〜55%)。化粧箱・複数モールドが主因。

### 自社版ライン設計
**完成品ライン(売価680〜980円)** — 初期SKU 4〜6型推奨
- 1個あたり推定原価 約430〜585円(シリコーン80〜100g が最大コスト)
- 粗利率: 680円=約26% / 780円=約36% / 880円=約43% / 980円=約49%
- **推奨スイートスポット: 780〜880円**。680円は無地SKU等 原価を絞った型に限定。

**DIYキットライン(売価2,480〜2,980円)**
- 同梱: シリコーン約200g(2液型)/ 猫の手モールド+追加型2〜3種 / 着色料・ラメ・ビーズ / 使い捨て小物 / 説明書 / 化粧箱
- 推定原価 **約1,240〜1,830円**
- 粗利率: 2,480円=約40% / 2,780円=約46% / 2,980円=約50%
- **競合4,000円に対し2,480〜2,780円で明確に安く、粗利40%超確保可能。**

### 量産・原価低減
- 最大コストはシリコーン。使用量最適化(薄肉/中空化)で10〜20%削減余地。
- ロット別 完成品推定原価: 500個=550〜620円 / 2,000個=480〜520円 / 5,000個=420〜470円 / 10,000個〜=380〜440円。
- 量販狙いなら**5,000個/ロット以上**で原価450円前後が視野。

## 2. マーケティング(ブランド・PR)

### ターゲット
- A: かわいい雑貨コレクター(10代後半・完成品複数色) / B: ASMR癒し層(20代・リピート+ギフト) / C: 体験派+保護者(キット主対象)

### 差別化の核
「**作れる。でも、作らなくても、もう可愛い。**」完成品で裾野を取り、体験層はキットへ引き上げ。

### ブランド名候補(推し順)
1. **にくきゅ / Nikukyu**(検索性・親しみ)
2. **PuniPaw(プニパウ)**(触感+肉球、海外視野)
3. **ぷにきゅ / Punikyu**(汎用・親しみ)
- 他: もちにく / にゃぷに / Pawty / こねこの手 / Squnya
- ※最終決定+**商標調査は代表判断・実行前確認**。

### パッケージ方向性
- 競合のティール(青緑)を意図的に外し、**白ベース×ピンク〜ラベンダーのパステルグラデ**で棚差別化。
- 透明窓で実物のラメ・グラデを「見せて売る」。金の細ラインでチープ感回避。
- 完成品=小袋/台紙、キット=箱でギフト・体験感。

### PR/SNS(TikTok Shop 初速エンジン + Instagram Reels)
- バズ動画5本: ①ASMR耐久 ②680円全色開封(コスパ驚き) ③作ってみた(キット送客) ④体験vs完成品 一般比較 ⑤推し活/コレクション
- 初動はマイクロ〜ナノインフルエンサー複数にギフティング(※対外行為=要承認)。
- 4週間投稿カレンダー: 1週=世界観確立 / 2週=コスパ拡散 / 3週=体験訴求 / 4週=コミュニティ化。

## 3. 営業(チャネル・拡販)

### チャネル別役割
- **メルカリ**(完成品)+ **minne/Creema**(キット): 初期コストゼロで検証。
- **自社EC(BASE→Shopify)**: 手数料最小、世界観・まとめ買い導線。
- **Amazon(FBA)**: 検索購買の量販エンジン(完成品)。
- **TikTok Shop**: 映え×衝動買い。供給安定後に本格参入(日本版は2025年6月末ローンチ)。
- **楽天**: 費用対効果を見て後半判断。

### 拡販フェーズ
- Phase 0(〜1ヶ月): メルカリ+minne でゼロ円検証。
- Phase 1(1〜3ヶ月): 自社EC構築 + SNS拡散。
- Phase 2(3ヶ月〜): Amazon FBA → TikTok Shop → 楽天検討。実績を持って卸/OEMへ。

### 売上ラフ試算(標準ケース目安・手数料前)
- 完成品 月600個/売上48万/粗利18万 + キット 月80個/売上21.6万/粗利13.6万 = 合算 月売上約70万/粗利約32万(手数料・送料・広告前)。

### 卸・BtoB
- 雑貨店・バラエティショップ / ガチャ / ハンズ・ロフト系 / ノベルティ・OEM。**BtoCで実績を作ってから提案**。

## 4. 業務管理(損益・法務・スケジュール)

### 損益の最重要示唆
- **完成品の低価格帯(680/780円)は「送料の扱い」が黒字/赤字の分岐点**。
  - 単品発送で送料自己負担だと赤字化しやすい。対策: 送料顧客負担 or 980円中心 / まとめ買いで送料按分 / 最安発送 / 自社EC(手数料最小)主軸。
- **利益はキットが牽引、完成品は集客・数量担当**という役割分担が現実的。

### 立ち上げ概算
- 初期投資 **約70〜130万円**(在庫量・キット試験要否で変動)。
- 検証出品まで **約8〜10週**(クリティカルパス=パッケージ製版リードタイム)。

### 法務・表示(一般的留意点・最終判断は専門家/代表)
- 必須: 特商法表記 / 景表法(比較・二重価格の根拠)
- 要確認: **おもちゃ(食品衛生法)該当性** / **効能表現(薬機法)「ストレス解消」等の範囲** / PL法・PL保険 / 玩具安全STマーク / 原産国・材質・対象年齢表示 / 商標・意匠の他社権利。

### 主要リスク
- 送料負け / 過剰在庫 / 品質クレーム(気泡・臭い) / 知財模倣 / 価格競争 / プラットフォーム依存 / 法令表示違反 / 製品事故(PL)。
