### 推奨: 見積A プラン2(生産物賠償 5億円 / 年21,250円)
- 玩具×子供(誤飲リスク)×EC量販は、単独重篤事故に加え「同一欠陥ロットによる複数請求の集積」がテールリスク。
- **限度額を上げる限界コストが極小**: B-3(1億)→A-1(3億)=+1,350円で3倍、A-1→A-2(5億)=+730円、A-2→A-3(7億)=+530円。「安いのだから厚く買う」が合理的。
- 容認下限: A-1(3億, 20,520円)。保守寄りならA-3(7億, 21,780円)も可。**見積B(低限度額群)は非推奨。**

### 要確認(加入前に代理店へ)
- **【最重要】業種コード7090「その他物品賃貸業」が実態(玩具の製造・販売)と不一致の疑い** → 告知不一致による支払拒否リスク。自社製造/OEM/輸入のどの立場で玩具の製造物として正しく引受されているか必ず確認。
- キット(顧客が組み立てる半製品)が生産物賠償の対象か、組立後事故を拾えるか。
- リコール/回収費用は原則対象外 → 特約の要否。
- 越境EC(特に北米)は国内PL保険の対象外が通例。
- 算出基礎売上3,000万円を実売上が超えた際の通知義務・調整ルール。

## 2. 商標出願(ぷにラボ)
- フロー: J-PlatPat先行調査→出願→方式/実体審査→(拒絶理由通知は応答可)→登録査定→登録料納付→設定登録。存続10年・更新可。
- 区分: **第28類(おもちゃ)を中核**。EC店舗ブランド重視なら**第35類(小売役務)を追加**。補足候補16類/20類。
- まず標準文字「ぷにラボ」を第28類で。ロゴ・ローマ字(punilabo)は必要に応じ別途。
- 先行調査の観点: 表記ゆれ(プニラボ/punilabo等)・称呼(ぷにらぼ)の類似・28/35類内の登録+係属を確認。「ラボ」は多用語尾のため「ぷに」の識別力がポイント。
- 費用感(概算): 自力 約44,900円/1区分、弁理士依頼 約10〜18万円/1区分。2区分(28+35)は自力約8.6万/弁理士18〜30万。
- 期間: 概ね8〜12ヶ月。早期審査で約2ヶ月に短縮可。
- 留意: **実出願は代表承認+弁理士依頼を推奨。販売・公開前の早期出願が有利(先願主義)。**

## 3. 初回発注(生産)ロット
- 方針: 新規・需要未検証・子供向けのため「原価最適化」より**需要+安全/品質検証を優先**。
- 推奨初回数量:
  - **完成品(880円): 300個前後**(レンジ300〜500)。CVR・レビュー・不良/返品率・安全検証に十分かつ在庫露出を抑制。
  - **キット(2,480円): 50個前後**(レンジ30〜50)。単価高・DIY説明リスクを小さく検証。
- 大ロット(3,000〜5,000個〜)移行条件: 消化率・不良/返品率の安定・安全基準対応の確定・反復需要の確認。目安は「2〜3ヶ月で売り切れる量」。
- 要確認: 数量帯別原価表・MOQ・**金型/初期費用(推定5〜30万円)**・リードタイム・目標粗利率・保管/物流・安全基準対応。**設計確定前に大量生産しない。**
