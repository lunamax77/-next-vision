# 先行商標調査 — 手順と記録シート

目的: 同一・類似の先行商標があると拒絶される(商標法4条1項11号)。出願前に必ず調べる。
ツール: J-PlatPat(特許庁・無料) https://www.j-platpat.inpit.go.jp/
※ 本環境からは特許庁サイトにアクセスできないため、画面操作は代表またはサービス側で実施。

## A. 文字商標の調査(キッズライセンスパーク / ぷにラボ / NextVision)

1. J-PlatPat → 商標 → **商標検索**
2. 「称呼(類似検索)」に読みを入れる。区切りを変えて複数回。
   - キッズライセンスパーク: `キッズライセンスパーク` / `キッズライセンス` / `ライセンスパーク`
   - ぷにラボ: `プニラボ` / `プニ` / `ラボ`(ラボ単体は多数ヒットするので区分で絞る)
   - NextVision: `ネクストビジョン` / `ネクストヴィジョン`
3. 「区分」に `35 41`(必要なら `28 16`)を入れて絞る。
4. ヒットした商標について、①称呼が同じ/似ている ②指定役務が重なる の両方を満たすものを記録。

**注意**: 「ネクストビジョン」は一般的な語の組合せで、他社の先行登録が複数ある可能性が高い。
その場合はロゴ(図形)との結合商標として出願する、または区分でずらす。

## B. 図形商標の調査(ペンギンのマスコット)

1. J-PlatPat → 商標 → **図形等分類表**でウィーン分類コードを確認
   - ペンギン: `3.7.7`(ペンギン)、`3.7.24`(様式化した鳥)
   - 擬人化(ネクタイ・二足歩行): `3.7.25`(衣服を着た鳥・擬人化)
2. **商標検索**の「図形等分類」に上記コードを入れ、区分 `35 41 28` で絞る。
3. ヒットした図形と見比べ、「全体の印象(外観)が似ているか」を判断。
   - 見るポイント: 体色(青×白)、赤いネクタイ、頭のとんがり、ポーズ
   - 「ペンギン」というだけでは類似にならない。特徴の組合せが似ているかが基準。
4. 気になるものはスクショを保存し、下の記録シートに貼る。

## C. Web・ドメイン・SNS の実態調査(登録外の使用者)

- Google で `"キッズライセンスパーク"` `"ぷにラボ"` を完全一致検索。他社の同名サービスがあれば記録。
- 他社が先に「周知」になっている名称は、登録できても紛争リスクがある。

## E. 判定の目安

- **○ 出願可**: 同一区分で称呼・外観が似ている先行商標なし
- **△ 要相談**: 似た商標があるが指定役務がずれている → 弁理士に判断を依頼
- **× 変更**: 同一・類似の登録が同じ役務にある → 名称/デザインを変える(出願しても拒絶される)
