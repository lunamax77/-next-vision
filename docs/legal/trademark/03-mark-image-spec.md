# 商標見本(画像)の作成仕様

特許庁の願書に添付する「商標登録を受けようとする商標」の画像仕様。

## 特許庁の要件

| 項目 | 要件 |
| --- | --- |
| サイズ | 縦・横 **8cm以内**(電子出願では 8cm×8cm 相当の画像。大きい場合は縦横15cm以内で「商標の大きさ」欄に記載) |
| 形式 | 電子出願: JPEG / BMP(推奨 JPEG)。書面: 枠内に印刷または貼付 |
| 解像度 | 200〜400dpi 推奨(8cm×8cm ≒ 630〜1260px) |
| 色 | 色付きで出願すると **その色**で権利化。白黒(線画)なら色に関係なく権利化されるが、実際の使用と印象が違いすぎるのはNG |
| 背景 | 白または透明→白。余計な装飾・キラキラ・影は入れない |
| 文字 | 図形のみで出願するなら文字は入れない。文字入りにすると「結合商標」になり、文字違いのグッズには効きにくい |

## A. ペンギンマスコット(図形商標)

- 元画像: `site/images/mascot.png`(442×560px・透過PNG・カラー)
- 作成手順:
  1. 背景を白に統一(透過→白)
  2. 余白を上下左右 5% 程度に整える。正方形にする必要はない(縦長で可)
  3. 長辺 8cm(約 945px @300dpi)に合わせる。元が442×560のため、**印刷品質のために高解像度の元データ(AI/SVG/2000px以上)をデザイナーから取り寄せるのが望ましい**
  4. JPEG(品質90以上)で `docs/legal/trademark/marks/A-penguin-color.jpg` に保存
- 推奨: **カラー版で出願**(青×白×赤ネクタイが識別の核)。予算に余裕があれば白黒線画版も別出願を検討。
- 「商標の詳細な説明」欄は不要(通常の図形商標)。

## B. キッズライセンスパーク(文字商標)

- **標準文字**で出願する(画像不要)。願書に `【標準文字】` と記載し、文字を書くだけ。
- 表記は `キッズライセンスパーク`(全角カタカナ・スペースなし)に統一。
- ロゴデザインで出願したい場合は別途図形として作成(サイトに専用ロゴがあれば `marks/B-klp-logo.jpg`)。

## C. NextVision ロゴ(結合商標・後回し)

- 元画像: `site/images/logo.png`(408×460px)
- 「N」のシンボル + `NextVision` 文字の結合商標として、A と同じ手順で JPEG 化。

## 作成結果(2026-09-07)

- 元データ: Googleドライブ `（新）NextVision/ロゴ/IMG_1620.PNG`(1024×1024・透過PNG)。同フォルダの ChatGPT 生成版(背景クリーム・影あり)は使わない
- 出力: `marks/A-penguin-color.jpg` 718×876px・300dpi(約6.1×7.4cm)・白背景・余白5%。特許庁の8cm以内に収まる
- 参考保存: `marks/A-penguin-source-1024.png`(元データのコピー)
- 注意: 1024pxは印刷用としては最低限。将来グッズ用にベクター(AI/SVG)化を推奨

## 保存先

`docs/legal/trademark/marks/` を作り、最終版のみ置く。ファイル名は `<記号>-<名前>-<color|mono>.jpg`。
(本環境に画像処理ライブラリが無いため、変換は代表のPC または Canva で実施。Canva へのアップロードは
外部サービスへのデータ送信にあたるため、事前に代表の了承をとる。)
