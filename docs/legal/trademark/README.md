## 1. 何を登録するか(案)

| # | 商標 | 種別 | 優先度 | 根拠 |
| --- | --- | --- | --- | --- |
| A | ペンギンのマスコット(`site/images/mascot.png`) | 図形商標 | ★★★ | 今回の依頼の主対象。キャラクター商品・グッズ展開の土台 |
| B | 「キッズライセンスパーク」 | 文字商標(標準文字) | ★★★ | 人気No.1コンテンツ名。他社に取られると事業名を変えることになる |
| C | 「NextVision」ロゴ(`site/images/logo.png`) | 図形(結合)商標 | ★★ | 社名は登記で守られるが、ロゴ・サービス名としての独占は商標が必要 |

| 第41類 | イベント・ワークショップ・体験教室の企画運営、娯楽施設の提供、遊戯用器具の貸与 | ◎ 必須 | ◎ 必須 |

## 3. 費用(特許庁印紙代・2026年時点)

| 項目 | 計算 | 2区分 | 3区分 |
| --- | --- | --- | --- |
| 出願料 | 3,400円 + 8,600円×区分 | 20,600円 | 29,200円 |
| 登録料(10年一括) | 32,900円×区分 | 65,800円 | 98,700円 |
| 登録料(5年分納) | 17,200円×区分 | 34,400円 | 51,600円 |
| **1件合計(10年)** | | **86,400円** | **127,900円** |

- A + B の2件・各2区分 = **約172,800円**(印紙代のみ・登録まで)。
- 弁理士に依頼する場合は上記に加え 1件あたり概ね 5〜15万円(出願+登録手数料)。
- 電子出願でなく書面出願の場合は電子化手数料(1件 2,400円+800円×枚数)が別途。
- 出典: [商標登録費用 2026](https://zero-startup.com/trademark-registration-cost-and-guide) / [阿部国際法律事務所 2026ガイド](https://abe-legal.jp/ja/news/trademark-registration-guide-2026)

## 4. 進め方の3ルート

| ルート | 費用感(A+B, 各2区分) | 手間 | 向いている場合 |
| --- | --- | --- | --- |
| ① 自分で電子出願 | 印紙代のみ 約17万円 | 大(電子証明書取得・出願ソフト設定) | コスト最優先 |
| ② オンライン商標サービス(Cotobox / Toreru 等) | 約25〜30万円 | 小(Web入力、弁理士チェック付き) | **推奨**。手間と費用のバランスが良い |
| ③ 弁理士事務所に直接依頼 | 約35〜45万円 | 最小 | 拒絶理由への対応・海外展開も見据える場合 |

推奨: **② オンライン商標サービス**。図形商標の類似判断や指定役務の文言調整をプロに見てもらえる。

## 5. スケジュール目安

| 段階 | 期間 | 備考 |
| --- | --- | --- |
| 先行調査(J-PlatPat) | 1〜3日 | `01-prior-search.md` |
| 願書確定・出願 | 1週間 | 代表承認後 |
| 特許庁 審査 | 出願から約6〜8か月 | 早期審査を申請すれば約2か月(既に使用中の商標が条件・今回該当) |
| 登録料納付・登録 | 登録査定から30日以内 | 納付後 約1か月で登録証 |
| **合計** | **通常 8〜10か月 / 早期審査で 3〜4か月** | |

出願日で先後が決まるため、**調査が終わり次第すぐ出願**が鉄則。

## 6. 代表の決定(2026-09-07)

| 項目 | 決定 |
| --- | --- |
| 区分 | **第41類 + 第35類**(2区分) |
| ルート | **オンライン商標サービスを使い、代表が自分で申込**(弁理士事務所への直接依頼はしない) |
| 予算 | 上限は設けないが **30万円以下が望ましい** |
| 出願人 | **株式会社ネクストビジョン**(登記上の住所・代表者名義) |
| スピード | **できるだけ早く出願**。早期審査を申請する |
| 対象 | ペンギン(A)+キッズライセンスパーク(B)の2件で進める(※代表の明示回答なし。異なる場合は指示ください) |

### 決定前のメモ(参考)

1. **対象**: A ペンギン + B キッズライセンスパーク の2件で進めてよいか(C・D は後回し)
2. **区分**: 各 第41類+第35類 の2区分か、第28類(玩具グッズ)も足すか
3. **ルート**: ①自力 / ②オンライン商標サービス / ③弁理士
4. **予算上限**: 印紙代 約17万円(+サービス手数料)を承認するか
5. **出願人名義**: 株式会社ネクストビジョン(法人)でよいか。登記上の商号・本店所在地の確認が必要
6. **早期審査**: 申請するか(使用実績の資料提出が必要・追加費用なし)

## 7. AIができること / できないこと

- **AIが完了済み(L0)**: 計画、区分・指定役務案、願書ドラフト、調査手順、商標見本の仕様整理
- **代表の作業が必要(L2・対外行為)**:
  - J-PlatPat での最終確認(画面操作は代表またはサービスの弁理士)
  - サービス申込・出願・印紙代の支払い ← **お金が動くため代表承認必須**
  - 電子出願する場合の電子証明書取得(法人代表者のマイナンバーカード等)
