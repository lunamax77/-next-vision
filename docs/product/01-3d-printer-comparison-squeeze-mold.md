## 1. 前提整理: スクイーズ型の作り方と3Dプリンターの役割

スクイーズ(低反発ウレタン/シリコン製)は、一般に次の流れで作る。

```
①原型(マスター)を作る → ②原型からシリコン型を取る → ③型にスクイーズ材を流して量産
```

3Dプリンターが担うのは主に **①原型** で、場合によって **②型そのものを直接プリント** する。

| パターン | 内容 | 向く方式 |
|---|---|---|
| A. 原型をプリント → シリコン型取り | 一番一般的。原型は硬くて良い。シリコン型は柔らかく、抜きやすい | 光造形 |
| B. 型を直接プリント(硬い型) | 2つ割り型を直接プリント。型取り工程を省けるが、複雑形状は抜けない/割れる | 光造形(表面) / FDM(簡単な形なら) |
| C. 型枠・治具・箱 | シリコンを流す枠、位置決め治具など | FDM |

**注意(重要)**: レジン(光造形)の原型から **付加型(プラチナ)シリコン** で型取りすると、未硬化レジン成分の影響で
シリコンが固まらない「硬化阻害」が起きることがある。対策は以下のいずれか。
- 洗浄を十分に行い、二次硬化(UV照射)を規定通りしっかり行う
- 原型表面にサーフェイサー/クリア塗装などでコーティングする
- 硬化阻害に強い **縮合型シリコン** を使う(型の寿命は付加型より短い)
- 型取り前に小片でテストする(必須)

## 2. 方式の比較: 光造形(MSLA) vs FDM

| 項目 | 光造形(レジン) | FDM(フィラメント) |
|---|---|---|
| 表面の仕上がり | ◎ 積層痕がほぼ見えない。型に最適 | △ 積層痕が出る。パテ・ヤスリ処理が必要 |
| 細部の再現 | ◎ 0.02〜0.05mm | ○ 0.1〜0.2mm |
| 材料費(1個あたり) | 約100〜250円(30〜60g) | 約80〜150円(30〜50g) |
| 後処理 | 洗浄→二次硬化が必須(手袋・換気) | ほぼ不要(サポート外しのみ) |
| 消耗品 | レジン、FEPフィルム、LCD、IPA/水 | フィラメント、ノズル |
| 安全・環境 | 未硬化レジンは有害。換気・手袋必須。廃液処理あり | 匂い少ない(PLA)。扱いが楽 |
| 造形時間(手のひらサイズ) | 1〜3時間(高さ依存、複数個同時OK) | 1〜3時間 |
| ワークショップでの扱いやすさ | △ 参加者に触らせにくい | ◎ 参加者の前で動かせる |
| 初期費用(周辺込み) | 3.5〜7万円 | 3〜5万円 |

→ **型・原型の品質を優先するなら光造形。ワークショップの「見せる・触らせる」道具としてはFDM。**

## 6. 選定にあたって代表に確認したいこと

1. 型は「原型→シリコン型取り」方式か、「型を直接プリント」方式か(未定ならAを推奨)
2. 月あたりの想定制作数(数個なら S2、継続的なら S1/S4)
3. ワークショップの場でプリンターを動かして見せたいか(YesならFDM追加の価値大)
4. 設置場所の換気(光造形はレジン臭・換気必須)
5. 予算上限

---

## 7. 補足: 導入後の最初のステップ(案)

1. 小さなテストピース(3cm角)で造形→洗浄→二次硬化→シリコン型取りテスト(硬化阻害確認)
2. 既存スクイーズ1種を3Dモデル化(Tinkercad / Fusion 等)し、原型を出力
3. シリコン2つ割り型を作り、スクイーズ材で試作
4. 問題なければワークショップ用に型を複数複製
