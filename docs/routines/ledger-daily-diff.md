# 売掛・買掛 前日対比(手順書)

参照スプレッドシートの売掛・買掛について、**前日から何がどう変わったか**を毎朝わかるようにする仕組み。

## なぜスナップショットが要るか

参照シートは**月ごとのタブ**が上書きで更新されていくため、シートを見ても「昨日いくらだったか」は残っていない。
そこで**毎朝、その日の値を別ファイルに記録**しておき、翌日それと比較して増減を出す。

> **原本は読むだけ。** スクリプトは参照シートを `getValues()` で読むのみで、書き込み・編集は一切しない。
> 記録も比較結果も、AI専用フォルダ内の**新規ファイル**として作る(憲章 4-1 原本不可侵)。

## 全体の流れ

```
[参照シート(月タブ)]  ← 読むだけ
   │ ① 毎朝6〜7時 Apps Script が当日の売掛・買掛を読む
   ▼
[AI専用/10_売掛買掛スナップショット/2026-08-20.json]   ← その日の記録
   │ ② 前日のJSONと突き合わせて増減を計算
   ▼
[_前日対比_2026-08-20.txt]                            ← 差分レポート
   │ ③ 朝8時の定時報告がこれを読んで要約
   ▼
[プッシュ＋メールで通知]
```

## セットアップ

`daily-ledger-snapshot.gs` を使う。

1. https://script.google.com/ → 新しいプロジェクト → コードを貼り付けて保存
2. **まず `inspectLedger` を実行**して権限を承認。
   実行ログに、検出したタブと売掛・買掛の項目・合計が出る。
   **意図どおり拾えているかここで確認する**(この関数は何も書き込まない)。
3. 問題なければ `dailyLedgerSnapshot` を一度実行 → 初日の基準値が記録される。
4. トリガー →「時間主導型 / 日付ベースのタイマー / **午前6時〜7時**」で `dailyLedgerSnapshot` を登録。
   朝8時の定時報告より前に用意されるようにする。

> **前日対比が出るのは2日目から。** 初日は「基準値を記録しました」という内容になる。

## 出力されるレポートの形

```
■ 売掛・買掛 前日対比 (2026-08-20 ← 2026-08-19)

【8月】売掛 合計 28,366,695  (前日比 +995,506)
    [増] ネクセル  15,071,645 → 15,925,745  (+854,100)
    [新規] 新通  484,000
    [減] エディオン  1,242,594 → 900,000  (-342,594)

【8月】買掛 合計 11,389,000  (前日比 -833,645)
    [減] アワー  8,608,645 → 8,100,000  (-508,645)
    [消滅] エグボック  325,000 → なし
```

- **動いた取引先だけ**を挙げる(変化がなければ「変化なし」)。
- 並び順は**増減額の大きい順**。
- 区分は 増 / 減 / 新規 / 消滅 の4種類。

## 読み取りの仕組み(調整するとき)

- タブごとに「**売掛**」「**買掛**」が同じ行に並ぶ見出し行を探し、その下を項目として読む。
- 売掛は「売掛」列から「買掛」列の手前まで、買掛は「買掛」列から行末まで。
- 各行で「**金額(数値)より前にある文字列**」を取引先名、「**最初に現れる数値**」を金額とみなす。
  → 見出し列より左の備考(例: 社長作成、1営業日17時)や、金額より後ろのラベル(例: 個人事業主)は自然に除外される。
- 「売掛/買掛」の見出しが無いタブ(スタッフ稼働表など)は自動でスキップされる。

うまく拾えない項目があれば、`inspectLedger` のログを見て、`HEADER_SEARCH_ROWS` / `BLOCK_MAX_ROWS` や
`pickPair_` の判定を調整する。

## 注意点

- **同日に再実行**した場合、その日のスナップショットと差分レポートは作り直される(過去日には触れない)。
- スナップショットは日々溜まる。月次・週次の推移を見たくなったら、この蓄積をそのまま使える。
- 金額が `0` の行も記録される(0 → 金額あり、は「増」として出る)。
