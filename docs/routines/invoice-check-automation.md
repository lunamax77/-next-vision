# 下請け請求書チェック 自動化(手順書)

下請けから DreamCreation に届く請求書(メールのPDF添付)を、参照スプレッドシートの
「買掛」金額と突き合わせ、**ズレがあれば通知する**仕組み。すべて確認・報告のみで、
原本(スプレッドシート・請求書PDF・メール)は書き換えない。支払い可否は代表が判断する。

## 全体の流れ

```
[下請けの請求書メール(PDF添付)]
   │ ① Apps Scriptが1時間ごとに添付PDFをDriveへ自動保存
   ▼
[Google Drive: AI専用/受信請求書]
   │ ② チェック用ルーティンが2〜3時間ごとに新着PDFを読む
   ▼
[PDFの請求額 vs 参照シート「買掛」]
   │ ③ 一致/ズレ/要確認 を判定
   ▼
[プッシュ＋メールで通知(lunamax77@gmail.com)]
```

## なぜこの形か(制約)

- この環境のGmailツールは**添付PDFの中身を読めない** → 一旦Driveに保存すれば読める。
- 「メール到着で即時」トリガーは仕組み上使えない → **定期チェック**(2〜3時間ごと)にする。

---

## セットアップ① Gmail→Drive 自動保存(Apps Script)

`gmail-to-drive-invoice-saver.gs` を使う。設定手順はファイル冒頭のコメント参照(要約):

1. https://script.google.com/ → 新しいプロジェクト → コードを貼り付け
2. `saveInvoiceAttachmentsToDrive` を一度実行して権限を承認
3. トリガー →「時間主導型 / 1時間おき」を追加

→ これで「AI専用/受信請求書」フォルダに、新着の請求書PDFが自動で溜まる。
   処理済みメールには `invoice-saved` ラベルが付く(元メールは削除・改変しない)。

## セットアップ② チェック用ルーティン(Routines UIで作成)

- 名前: 請求書チェック
- スケジュール: **2〜3時間ごと**(例: 平日 9・12・15・18時)
- 実行: 新しいセッション
- コネクタ: Google Drive(必須)。表と同じアカウントで読めること。
- 通知: プッシュ ＋ メール

### 貼り付け用プロンプト

```
あなたは竹村代表グループ(ドリームクリエーション)の経理チェックAIです。下請けから届いた請求書を、参照スプレッドシートの「買掛」金額と突き合わせ、ズレを報告します。すべて"読むだけ"(スプレッドシート・PDF・メールを編集/削除しない=原本不可侵)。送信もしない。支払い可否は代表が判断する。

手順:
1. Google Driveの「受信請求書」フォルダ(AI専用フォルダ ID 1e3g5RB9DjsAu_83KUbIqgf13VIr5dAC8 の直下、タイトル『受信請求書』)を探し、直近4時間以内に追加・更新されたPDFを対象にする。無ければ「新着の請求書なし」と報告して終了。
2. 各PDFを読み、①請求元(会社名)②件名/対象(店舗・案件)③対象期間 ④請求金額(税込)⑤消費税 ⑥支払期日 を抽出する。
3. 参照スプレッドシート(ID 1rdPmp9wKzktUh8QcZ4ydXOrU4nfcjwOEfqz55UFUp98)を開く。このシートは【タブ(シート)が月ごと】に分かれている。請求書の対象月(例: 7月度 → 7月のタブ)に対応するタブを選び、その月タブの「買掛」列から請求元に対応する想定金額を探す(社名の表記ゆれに注意。例: エグボック=325000)。対象月が読み取れない/該当タブが無い場合は最新月のタブで判定し、その旨を「要確認」に記す。
4. 突き合わせて判定する:
   - ✅ 一致: 請求元・金額が表の想定どおり
   - ⚠️ ズレ: どこが違うかを具体的に(例: 請求額350,000 vs 表325,000 → 差+25,000 / 対象期間の相違 / 消費税率 / 支払期日 など)
   - ❓ 要確認: 表に該当社が無い / 候補が複数で確定できない / PDFが読めない
5. 形式: 冒頭に一言サマリー(対象件数・うちズレ○件)。請求書ごとに「請求元 / 対象 / 請求額 / 表の想定額 / 判定」を箇条書き。金額は必ず明記。

注意: これは確認用の下書き。表・PDF・メールへの書き込みは一切しない。判断に迷う点は「要確認」として残す。
```

### 補足・既知の注意点

- **重複通知**: チェック間隔3時間に対し確認窓を4時間にしているため、境界の請求書が2回報告されることがある(安全側)。
- **月タブの選択**: 参照シートは【月ごとのタブ】に分かれている。請求書の対象月のタブを正として突き合わせる。対象月が読み取れない/該当タブが無いときは最新月タブで判定し「要確認」にする(同じ社名でも月により金額が異なるため、月の取り違えに注意)。
- **社名の対応表**: メールの差出人社名とシートの表記が違う場合(例: 代行送信サービス経由)、対応が取れないと「要確認」になる。頻出のズレが分かってきたら、社名の対応表をこのファイルに追記して精度を上げる。
