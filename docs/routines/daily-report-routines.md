# 定時報告ルーティン(手動登録用)

竹村代表グループ(ドリームクリエーション / ネクストビジョン)の毎日の定時報告を、
claude.ai または Claude アプリの「Routines(定期実行/スケジュール)」から手動登録するための文面集。

すべて **Gmail・Googleカレンダー・Googleドライブ「AI専用」を"確認して報告するだけ"** のルーティン。
送信・返信・編集・削除・予定変更は一切しない(原本不可侵・対外承認ルール順守)。

## 報告の構成(重要)

- **朝(8:00)= リセット。** その日の「ベースライン(起点)」を丸ごと作る。差分セクションは無し。
- **昼・夕・夜 = 2段構成。**
  1. **【1】前回からの変化** を必ず最初に置く(前の時間帯以降に増減した分だけ)。
  2. その下に **【2】本日の積み上げまとめ**(今朝のリセット以降ぜんぶの累積)を置く。
- **翌朝の8:00でまたリセット。** 積み上げは1日単位でクリアされる。

各セッションは記憶を持たないため、「前回からの変化」は**時間の区切り**で判定する:
昼=今朝8時以降 / 夕=昼12時以降 / 夜=夕方18時以降。積み上げはいずれも「今朝8時(リセット)以降」。

## 登録時の共通設定

- **時刻**: 日本時間(下表)。
- **実行方法**: 新しいセッションで実行(fresh session)。
- **連携(コネクタ)**: Gmail / Google Calendar / Google Drive を必ずON(これが無いと中身を読めません)。
- **通知**: プッシュ通知 ＋ メール(lunamax77@gmail.com)。
