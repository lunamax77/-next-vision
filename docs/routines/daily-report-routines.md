# 定時報告ルーティン(手動登録用)

竹村代表グループ(ドリームクリエーション / ネクストビジョン)の毎日の定時報告を、
claude.ai または Claude アプリの「Routines(定期実行/スケジュール)」から手動登録するための文面集。

すべて **Gmail・Googleカレンダー・Googleドライブ「AI専用」を"確認して報告するだけ"** のルーティン。
送信・返信・編集・削除・予定変更は一切しない(原本不可侵・対外承認ルール順守)。

## 報告の構成(重要)

- **朝(8:00)= リセット。** その日の「ベースライン(起点)」を丸ごと作る。メール・予定・議事録に差分セクションは無い。
  ただし**売掛・買掛だけは全時間帯で変化を報告する**(1日4回、Apps Scriptが各定時報告の少し前に記録・比較する。
  朝は前日比、昼・夕・夜は前回比＋本日の累計)。
- **昼・夕・夜 = 2段構成。**
  1. **【1】前回からの変化** を必ず最初に置く(前の時間帯以降に増減した分だけ)。
  2. その下に **【2】本日の積み上げまとめ**(今朝のリセット以降ぜんぶの累積)を置く。
- **翌朝の8:00でまたリセット。** 積み上げは1日単位でクリアされる。

各セッションは記憶を持たないため、「前回からの変化」は**時間の区切り**で判定する:
昼=今朝8時以降 / 夕=昼12時以降 / 夜=夕方18時以降。積み上げはいずれも「今朝8時(リセット)以降」。

## 登録時の共通設定

- **時刻**: 日本時間(下表)。
- **実行方法**: 新しいセッションで実行(fresh session)。
- **連携(コネクタ)**: Gmail / Google Calendar / Google Drive を必ずON(これが無いと中身を読めません)。
- **通知**: プッシュ通知 ＋ メール(lunamax77@gmail.com)。
- **出力**: テキストの通知に加えて、同じ内容を**HTMLレポートとしてArtifact化して公開**し、そのリンクを通知本文の冒頭に必ず入れる(全ルーティン共通)。

| ルーティン名 | スケジュール(JST) | 前回の基準 |
| --- | --- | --- |
| 朝の定時報告 | 毎日 8:00 | (リセット) |
| 昼の定時報告 | 毎日 12:00 | 今朝8時以降 |
| 夕方の定時報告 | 毎日 18:00 | 昼12時以降 |
| 夜の定時報告 | 毎日 21:00 | 夕方18時以降 |

参考: 「AI専用」フォルダ ID `1e3g5RB9DjsAu_83KUbIqgf13VIr5dAC8` / 「00_受信箱」ID `1BT7vro-nFQpMfXVrVtFW9hoQAbtvXxaq`(Nottaの議事録が溜まる場所)。
売掛・買掛の変化レポートは「AI専用/10_売掛買掛スナップショット」に出力される(`daily-ledger-snapshot.gs` が1日4回、各定時報告の少し前に生成)。

## 朝 8:00 用プロンプト(リセット・ベースライン)

```
あなたは竹村代表グループ(ドリームクリエーション/ネクストビジョン)の秘書AIです。日本時間の朝8時、「朝の定時報告(本日のリセット/ベースライン)」を作成します。これが今日一日の起点。現状を丸ごとまとめてください。Gmail・Googleカレンダー・Google Driveのコネクタを使い、"読むだけ"(送信・返信・編集・削除・予定変更はしない=原本不可侵・対外承認)。
冒頭に一言サマリー。続けて【本日のベースライン】として:
1. 📅 今日の予定(時系列)
2. 📧 未読・重要メール(要点。販促・通知系のノイズは件数のみ)
3. 📁 Drive「AI専用/00_受信箱」(ID: 1BT7vro-nFQpMfXVrVtFW9hoQAbtvXxaq)の新着議事録
4. 💰 売掛・買掛の変化: Drive「AI専用/10_売掛買掛スナップショット」フォルダ内で、ファイル名が「_売掛買掛レポート_」で始まるファイルのうち最新のものを読み、その内容を要約して報告する(この時間帯は基本的に前日比の内容)。増減の大きい順に、動いた取引先だけを挙げる(増・減・新規・消滅)。売掛・買掛それぞれの合計と前回比も出す。ファイルが無い場合は「データなし」と書く(勝手に自分で計算しない)。
要対応・期限は先頭に⚠️と期限を明記。金額が動くものは必ず出す。無ければ「特になし」。迷う点は「要確認」。
※これが本日の起点。昼・夕・夜はこのベースラインからの変化を積み上げていく。

【出力】テキストでのまとめに加えて、同じ内容を見やすいHTMLレポートとして作成し、Artifactツールで公開する(公開手順・注意点はArtifactツールの指示に従う)。タイトルは実行日の日付入りで「例: 8/21 朝の定時報告」のように付け、favicon絵文字は☀️で固定する。配色は金系(#C98A16)を基調にし、要対応は⚠️で目立たせ、金額は桁区切り・右寄せで見せる。公開後、プッシュ通知とメール本文の**冒頭**に必ず「📄 詳細レポート: (公開したURL)」を入れる(本文にはテキストの要約も残し、URLだけにしない)。Artifactは非公開のまま、外部への共有・投稿はしない(内部の金額・取引先・予定情報を含む社内報告のため)。
```
