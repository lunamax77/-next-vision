# 定時報告ルーティン(手動登録用)

竹村代表グループ(ドリームクリエーション / ネクストビジョン)の毎日の定時報告を、
claude.ai または Claude アプリの「Routines(定期実行/スケジュール)」から手動登録するための文面集。

すべて **Gmail・Googleカレンダー・Googleドライブ「AI専用」を"確認して報告するだけ"** のルーティン。
送信・返信・編集・削除・予定変更は一切しない(原本不可侵・対外承認ルール順守)。

## 登録時の共通設定

- **時刻**: 日本時間(下表)。
- **実行方法**: 新しいセッションで実行(fresh session)。
- **連携(コネクタ)**: Gmail / Google Calendar / Google Drive。
- **通知**: プッシュ通知 ＋ メール(lunamax77@gmail.com)。

| ルーティン名 | スケジュール(JST) |
| --- | --- |
| 朝の定時報告 | 毎日 8:00 |
| 昼の定時報告 | 毎日 12:00 |
| 夕方の定時報告 | 毎日 18:00 |
| 夜の定時報告 | 毎日 21:00 |
