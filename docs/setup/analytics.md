# GA4（Google アナリティクス）と Search Console 設定手順

**対象**: 竹村代表　**所要時間**: 約30分（GA4 20分 ＋ Search Console 10分）　**必要なもの**: 会社で使う Google アカウント

## 何ができるようになるか

- **GA4**: 何人がHPを見たか、どのページが見られたか、**電話番号のタップ数**（`phone_click`）、**フォーム送信数**（`form_submit`）、**LINEボタンのタップ数**（`line_click`）が分かります。
- **Search Console**: Google 検索で「どんな言葉で・何回表示され・何回クリックされたか」が分かります。マーケ担当のSEO施策の効果測定に使います。

HP側の準備（計測タグ・イベント送信）は済んでいます。あとは **測定ID（`G-` で始まる11桁）を取得して、HP内の仮の文字 `G-XXXXXXXXXX` を置き換える** だけです。

---

## 手順1: GA4 のプロパティを作る（10分）

1. https://analytics.google.com/ を開き、会社の Google アカウントでログイン
2. 初めての場合は「**測定を開始**」。既にアカウントがある場合は左下の歯車「**管理**」→「**プロパティを作成**」
3. **アカウント名**: `NextVision`（初回のみ）→ 次へ
4. **プロパティ名**: `nextvision.fun`／**タイムゾーン**: 日本／**通貨**: 日本円 → 次へ
5. ビジネスの説明（業種: 「ビジネス、産業」など任意／規模: 小規模）→ 次へ
6. ビジネス目標: 「見込み顧客の発掘」にチェック → 作成 → 利用規約に同意
7. **データ収集の開始**: プラットフォームは「**ウェブ**」を選ぶ
8. ウェブサイトのURL: `nextvision.fun`（https を選択）／ストリーム名: `nextvision.fun` → 「**ストリームを作成**」
9. 表示される「**測定ID**」（`G-` + 英数字10桁、例: `G-AB12CD34EF`）を控える

## 手順2: 測定IDを HP に入れる（5分）

HTMLの6ファイル（index / klp / punilab / seal / air / thanks）に仮のID `G-XXXXXXXXXX` が入っています。これを本物に置き換えます。

### やり方A: ジョブズ（AI）に頼む（推奨）

チャットで次のように伝えるだけです。
> 「GA4の測定IDは G-AB12CD34EF です。HPのプレースホルダを置き換えてデプロイして」

### やり方B: 自分でコマンド実行（Mac / Linux のターミナル）

リポジトリのフォルダで、`G-AB12CD34EF` を本物のIDに変えて実行:

```bash
sed -i.bak 's/G-XXXXXXXXXX/G-AB12CD34EF/g' site/*.html && rm site/*.html.bak
grep -c "G-AB12CD34EF" site/*.html     # 各ファイル 1 と出ればOK（gtagのURLとconfigで2箇所→行数では1）
git add site && git commit -m "GA4 測定IDを設定" && git push
```

push すると自動デプロイされます（[deploy.md](deploy.md)）。

## 手順3: 動作確認（3分）

1. 別のブラウザ or スマホで https://nextvision.fun/ を開き、電話番号をタップしてみる
2. GA4 画面 → 左メニュー「**レポート**」→「**リアルタイム**」を開く
3. 「過去30分のユーザー」に 1 以上、「イベント数（イベント名別）」に `page_view` と `phone_click` が出ていればOK
   （反映まで1〜2分かかることがあります）

## 手順4: 主要イベントを「キーイベント（コンバージョン）」にする（3分）

問い合わせ数をGA4のレポートで目立たせるための設定です。

1. GA4 左下「**管理**」→「データの表示」列の「**イベント**」
2. 一覧に `form_submit` `phone_click` `line_click` が出ていたら（一度発生しないと出ません）、右側の「**キーイベントとしてマークを付ける**」をON
3. 出ていない場合は「**キーイベント**」→「**キーイベントを作成**」→ イベント名に `form_submit` と入力 → 保存（同様に `phone_click`、`line_click`）

## 手順5: Search Console に登録する（10分）

GA4 と同じ Google アカウントなら、GA4 経由で所有権確認ができます（ファイル設置不要）。

1. https://search.google.com/search-console/ を開く
2. 左上「プロパティを追加」→ 右側の「**URL プレフィックス**」に `https://nextvision.fun/` と入力 → 続行
3. 所有権の確認画面で「**Google アナリティクス**」を選んで「**確認**」
   - 手順2のデプロイが済んでいて、GA4 と同じアカウントなら数秒で「所有権を確認しました」と出ます
   - うまくいかない場合: 「**HTMLタグ**」方式を選び、表示される `<meta name="google-site-verification" content="...">` をコピーしてジョブズに渡してください（全ページの `<head>` に入れて再デプロイします）
4. 左メニュー「**サイトマップ**」→ 「新しいサイトマップの追加」に `sitemap.xml` と入力 → 「**送信**」
   - ステータスが「成功しました」になればOK（反映まで数時間〜数日）
5. （任意）左メニュー「**設定**」→「ユーザーと権限」で、マーケ担当が使うアカウントを追加

## 手順6: GA4 と Search Console をリンクする（2分・任意）

GA4 の「管理」→「サービス間のリンク」→「**Search Console のリンク**」→「リンク」→ プロパティを選ぶ → 送信。
GA4 のレポートに検索キーワードが出るようになります。

## 補足

- 計測タグは全ページの `<head>` 先頭にあります。Cookie 同意バナーは日本の toB サイトでは必須ではないため入れていません（要確認: 必要なら追加します）。
- 自分たちのアクセスを除外したい場合: GA4「管理」→「データストリーム」→ ストリーム → 「タグ設定を行う」→「内部トラフィックの定義」で会社のIPを登録 →「データフィルタ」で有効化。
- 送られるイベントの詳細:

| イベント名 | いつ送られるか | 主なパラメータ |
| --- | --- | --- |
| `phone_click` | `tel:` リンク（ヘッダー・フッター・CONTACT・右下ボタン）をタップ | `link_url`, `link_text`, `page_path` |
| `form_submit` | 問い合わせフォームの送信ボタンを押した時 | `purpose`（ご用件）, `content`（ご希望の体験） |
| `line_click` | LINEボタン（右下・CONTACT）をタップ | `link_url`, `page_path` |
