# LINE公式アカウント 開設と HP への導線設定

**対象**: 竹村代表　**所要時間**: 約20分　**必要なもの**: スマホの LINE アプリ（または メールアドレス）、会社ロゴ画像

## 何ができるようになるか

HP 全ページの右下に緑の「**LINEで相談**」ボタン、トップページの CONTACT に「LINEで相談する」ボタンが出ます（**すでに設置済み**）。
現在は URL が仮のため、ボタンは「準備中」表示（タップすると電話／フォームに案内）になっています。
LINE公式アカウントを作って **友だち追加URL（`https://lin.ee/〜`）を1箇所に書き込む**と、全ページのボタンが有効になります。

---

## 手順1: LINE公式アカウントを開設する（10分・無料）

1. https://www.lycbiz.com/jp/service/line-official-account/ を開き「**LINE公式アカウントをはじめる**」（無料）
2. 「**LINEアカウントで登録**」（自分の LINE でログイン。会社用に分けたい場合は「メールアドレスで登録」）
3. 入力内容
   - **アカウント名**: `NextVision｜キッズ体験イベント`（20文字以内・後から変更可）
   - **業種**: 大業種「専門サービス」→ 小業種「イベント・プロモーション」など近いもの
   - **会社/事業者名**: 株式会社NextVision
4. 「確認」→「完了」→ 「**LINE Official Account Manager に移動**」
5. 最初に設定しておくとよいもの（各1〜2分）
   - **プロフィール画像**: ロゴ（`site/images/logo.png`）
   - **あいさつメッセージ**（設定 → あいさつメッセージ）: 例
     > 友だち追加ありがとうございます！株式会社NextVisionです。
     > 商業施設・店舗向けのキッズ体験イベント（キッズライセンスパーク／ぷにラボ／シールデコ／エア遊具）を企画運営しています。
     > 「開催予定日」「会場の広さ」「ご予算」をお送りいただければ、担当者からご提案します。（平日 9:30-18:00 に返信）
   - **応答設定**: 「チャット」をON（手動で返信できるようにする）
6. 無料プラン（コミュニケーションプラン）は **月200通まで無料配信**。1対1のチャット返信は無制限です。toB 問い合わせ用途なら無料で十分です。

> **要確認**: 認証済アカウント（青バッジ）の申請は任意です。検索に出やすくなりますが、審査に数日〜かかります。今回は未認証のままで進めて問題ありません。

## 手順2: 友だち追加URL（lin.ee）を取得する（3分）

1. LINE Official Account Manager（https://manager.line.biz/）→ 対象アカウント
2. 左メニュー「**友だちを増やす**」→「**友だち追加ガイド**」
3. 「**URLを作成**」または「**友だち追加URL**」の項目に `https://lin.ee/XXXXXXX` 形式の短い URL が表示される → **コピー**
   - 「QRコード」もここでダウンロードできます（チラシ・名刺用。マーケ担当へ）

## 手順3: HP に URL を書き込む（2分）

URL は **1箇所だけ** 書き換えれば全ページに反映されます。

### やり方A: ジョブズ（AI）に頼む（推奨）

> 「LINEの友だち追加URLは https://lin.ee/AbCdEfG です。HPのLINEボタンを有効にしてデプロイして」

### やり方B: 自分で編集する

- ファイル: `site/assets/site.js`
- 冒頭付近のこの行を、本物の URL に書き換える:

```js
  var NV_LINE_URL = 'https://lin.ee/XXXXXXX';   // ← ここを書き換える（1箇所だけ）
```

- `index.html` の CONTACT ボタンにも仮URLが入っていますが、`site.js` が自動で同じURLに揃えるので **編集不要** です
  （念のため揃えたい場合のコマンド: `sed -i.bak 's#https://lin.ee/XXXXXXX#https://lin.ee/AbCdEfG#g' site/assets/site.js site/index.html && rm site/*.bak site/assets/*.bak`）
- 保存 → commit → push で自動デプロイ（[deploy.md](deploy.md)）

## 手順4: 動作確認（2分）

1. スマホで https://nextvision.fun/ を開く
2. 右下の緑ボタンをタップ → LINE アプリで「友だち追加」画面が開けばOK
3. PC では右下に「LINEで相談」の緑ボタン、スマホでは **LINE（緑）と電話（オレンジ）の丸ボタンが縦2段** で出ます

## 運用のヒント

- LINE からの相談も、必ず **会社名・担当者名・希望日・会場** を聞いて、問い合わせスプレッドシート（[form.md](form.md)）に手で1行追加すると案件管理が一元化できます。
- 返信は原則 1営業日以内（HP・自動返信で「1営業日以内にご連絡」と案内しています）。営業は平日のみ。土日祝の問い合わせは翌営業日に返信します（代表決定 2026-09-07）。
- ボタンの見た目（色・文言・位置）は `site/assets/site.js` の中の CSS で調整できます。変更したいときはプロダクト担当へ。
