# 問い合わせフォーム（contact.php）とスプレッドシート記録の設定手順

**対象**: 竹村代表　**所要時間**: 約30分　**必要なもの**: CORESERVER コントロールパネル、会社の Google アカウント

## 仕組み

```
HP のフォーム ──POST──▶ contact.php（サーバー）
                          ├─ 代表宛に通知メール（data@nextvision.fun）
                          ├─ 送信者に自動返信メール（文面: site/mail-templates/autoreply.txt）
                          ├─ Google スプレッドシートに1行追記（GAS ウェブアプリ経由・失敗しても送信は成功扱い）
                          └─ 完了ページ thanks.html を表示
```

- 迷惑投稿対策: 同一サイトからの送信か確認／ハニーポット（bot だけが埋める見えない欄）／必須・形式・文字数チェック
- 設定値は `site/config.php`。**リポジトリには仮の値だけ**入れてあり、本番の値は **サーバー上のファイルに直接書きます**（自動デプロイの対象外なので上書きされません）。

---

## 手順1: メール送信の前提を確認する（3分）

1. CORESERVER コントロールパネル → 「**メール**」→ `data@nextvision.fun` が作成済みであることを確認（HP 公開時に作っているはず）
2. 「**サイト設定**」→ nextvision.fun → **PHP のバージョンが 8.x** になっていることを確認（7.4 でも動きますが 8.x 推奨）

> **要確認（重要）**: 自動返信メールは `data@nextvision.fun` を差出人として送ります。迷惑メール判定を避けるため、
> CORESERVER 側で **SPF レコード**（DNS の TXT: `v=spf1 include:_spf.coreserver.jp ~all` 相当。正確な値はコントロールパネルの「DNS設定」の案内に従う）と、
> 可能なら **DKIM** を有効にしてください。未設定でも送れますが、Gmail 宛などで迷惑メール扱いになる確率が上がります。

## 手順2: 記録用スプレッドシートと GAS を作る（15分）

1. https://sheets.google.com/ → 「空白」で新規作成 → 名前を `HP問い合わせ一覧` にする
2. メニュー「**拡張機能**」→「**Apps Script**」
3. 開いたエディタの `function myFunction() {}` を **全部消して**、`docs/setup/gas-webhook.gs` の中身を **丸ごと貼り付け**
4. 上のほうの `var SHARED_TOKEN = 'CHANGE_ME_RANDOM_TOKEN';` の `CHANGE_ME_RANDOM_TOKEN` を、
   **自分で決めたランダムな英数字（20文字以上）** に変える（例: パスワード生成サイトで作る）。この文字列は手順3でも使うので控える
5. 保存（Ctrl+S）。プロジェクト名を聞かれたら `nextvision-contact-webhook`
6. 右上「**デプロイ**」→「**新しいデプロイ**」
   - 左の歯車「種類の選択」→「**ウェブアプリ**」
   - 説明: `v1`／次のユーザーとして実行: 「**自分**」／アクセスできるユーザー: 「**全員**」
   - 「**デプロイ**」→ 「アクセスを承認」→ 自分のアカウントを選択 → 「詳細」→「（安全ではないページ）に移動」→「許可」
     （自作スクリプトなので警告が出ますが問題ありません）
7. 表示される「**ウェブアプリ**」の URL（`https://script.google.com/macros/s/……/exec`）を **コピー**して控える
8. 動作確認: エディタ左上の関数選択で `testAppend` を選び「**実行**」→ スプレッドシートに見出し行とテスト1行が追加されればOK（テスト行は消してよい）

> コードを修正したときは、「デプロイ」→「**デプロイを管理**」→ 鉛筆 → バージョン「**新バージョン**」→ デプロイ、で URL を変えずに更新できます。

## 手順3: サーバー上に config.php を置く（5分）

1. CORESERVER コントロールパネル → 「**ファイルマネージャー**」（または FTP ソフト）
2. `domains/nextvision.fun/public_html/` を開く
3. `config.php` が **無ければ新規作成**、あれば編集。中身はリポジトリの `site/config.php` をコピーし、次の3箇所を本番値にする

| 項目 | 入れる値 |
| --- | --- |
| `GAS_WEBHOOK_URL` | 手順2-7 でコピーしたウェブアプリのURL |
| `GAS_TOKEN` | 手順2-4 で決めたランダム文字列（GAS 側と完全一致させる） |
| `NOTIFY_TO` | 通知を受け取るアドレス（初期値 `data@nextvision.fun`。複数ならカンマ区切り） |

4. 保存。ファイルのパーミッションは `604` または `644`（他の PHP と同じでOK）
5. **このファイルは Git に戻さない**（トークンが入るため）。リポジトリ側は仮の値のままで正しい状態です

## 手順4: テスト送信（5分）

1. https://nextvision.fun/#contact を開き、自分のメールアドレスでフォームを送信
2. 確認すること
   - 「送信が完了しました」ページ（thanks.html）が表示される
   - `data@nextvision.fun` に「【HP問い合わせ】会社名／担当者名」というメールが届く（返信するとそのまま送信者宛になります）
   - 入力したアドレスに「【株式会社NextVision】お問い合わせありがとうございます」が届く（迷惑メールフォルダも確認）
   - スプレッドシートに1行増えている
3. わざと会社名を空にして送信 → フォーム上部に赤いエラーが出て、入力内容が残っていればOK

### うまくいかないとき

| 症状 | 見るところ |
| --- | --- |
| thanks は出るがメールが届かない | 迷惑メールフォルダ／手順1の SPF。それでも来なければ CORESERVER の「エラーログ」に `[nextvision contact]` で始まる行がないか確認 |
| 「送信元を確認できませんでした」と出る | ブラウザの拡張機能でリファラを消している可能性。別ブラウザで再試行。頻発する場合はプロダクト担当へ |
| 「送信処理でエラーが発生しました」 | サーバーの mail 機能が無効。CORESERVER の PHP 設定で `sendmail_path` を確認 → 要相談 |
| シートに記録されない（メールは届く） | `GAS_WEBHOOK_URL` の貼り間違い、または `GAS_TOKEN` の不一致。ブラウザで URL を開いて `alive` と出るか確認 |
| 画面が真っ白 | `config.php` の書式エラー（カンマ・クォート抜け）。リポジトリの版からコピーし直す |

## 自動返信の文面を変えるには

- ファイル: `site/mail-templates/autoreply.txt`（マーケ担当が編集 → push → 自動デプロイ）
- 使える差し込み: `{name}` `{company}` `{email}` `{purpose}` `{plan}` `{content}` `{message}` `{date}`
- 件名を変えたい場合は `contact.php` 内の `'【株式会社NextVision】お問い合わせありがとうございます'` を編集（プロダクト担当へ）

## 運用ルール（案）

- 通知メールに **返信** すればそのまま送信者へ返信できます（Reply-To 設定済み）
- スプレッドシートの「対応状況」列（未対応／対応中／見積提出／受注／失注／対象外）を更新して案件管理に使う
- 1営業日以内の一次返信（HP・自動返信でそう案内しています）。営業は平日のみ、土日祝の問い合わせは翌営業日に返信（代表決定 2026-09-07）
