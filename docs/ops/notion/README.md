# Notion 導入設計(社内メモ共有+案件管理)

株式会社ネクストビジョンの社内ワークスペース構成案。
案件の列・ステータスは既存の `tools/pipeline/案件管理.xlsx` と同じにしてあり、移行しやすくしている。

> Notion のアカウント登録・有料プラン契約・メンバー招待は**対外行為**なので、代表が実行する。

---

## 1. 全体構成

```
🏢 ネクストビジョン(トップページ)
├── 📌 お知らせ・ルール        … 社内ルール、運用方針、テンプレの使い方
├── 💼 案件管理(DB)          … 1案件=1ページ。メインのデータベース
├── 📝 社内メモ(DB)          … 議事録・アイデア・調査メモ
├── ✅ タスク(DB)            … 案件にひもづく ToDo
├── 👥 顧客・取引先(DB)       … 会社・担当者の情報
└── 📚 ナレッジ              … 手順書・テンプレ・過去資料
```

DB 同士は「リレーション」でつなぐ:
案件 ⇄ 顧客、案件 ⇄ タスク、案件 ⇄ メモ。
→ 案件ページを開けば、関係する顧客・タスク・メモが全部見える。

## 2. 💼 案件管理 DB

| プロパティ | 種類 | 内容 |
|---|---|---|
| 案件名 | タイトル | 例: 〇〇社 夏祭りイベント |
| 案件ID | ID(自動採番) | 接頭辞 `NV` |
| ステータス | ステータス | 下記参照 |
| 顧客 | リレーション → 顧客・取引先 | |
| 経路・業種 | セレクト | 紹介 / Web / 既存 など |
| 案件内容 | テキスト | |
| 主なコンテンツ | マルチセレクト | |
| プラン | セレクト | |
| 受付日 | 日付 | |
| 開催日 | 日付 | |
| 会場 | テキスト | |
| 見積(税込) | 数値(円) | |
| 請求(税込) | 数値(円) | |
| 入金 | セレクト | 未入金 / 一部入金 / 入金済 |
| 担当 | ユーザー | |
| 次アクション | テキスト | |
| 次アクション期日 | 日付 | |
| タスク | リレーション → タスク | |
| メモ | リレーション → 社内メモ | |
| 備考 | テキスト | |

**ステータス**(Notion のステータス型の3グループに割り当て)

- 未着手: 問合せ
- 進行中: ヒアリング → 見積提出 → 受注 → 開催準備 → 開催済 → 請求済
- 完了: 入金済 / 失注 / 保留

### ビュー

| ビュー名 | 形式 | 設定 |
|---|---|---|
| 📋 ボード | ボード | ステータスでグループ化。メインの画面 |
| 📅 開催カレンダー | カレンダー | 開催日 |
| 🙋 自分の案件 | 表 | 担当 = 自分、完了を除く |
| ⏰ 今週のアクション | 表 | 次アクション期日 ≦ 今週末、期日順 |
| 💰 未入金 | 表 | ステータス = 請求済、入金 ≠ 入金済 |
| 📊 全件 | 表 | フィルタなし(集計: 見積・請求の合計) |

### 案件ページのテンプレート

```
## 概要
- 依頼内容:
- 予算感:
- 決裁者:

## ヒアリングメモ

## 見積・請求
- 見積書:(ファイル添付 or リンク)
- 請求書:

## 経緯ログ
- YYYY/MM/DD:
```

## 6. 導入手順

1. **代表**: Notion でワークスペース「ネクストビジョン」を作成(対外行為)
2. 上の構成でページ・DB を作る
3. 既存データの取り込み: `案件管理_import.csv` を案件管理 DB に「CSV をインポート」
   (または `案件管理.xlsx` の「案件一覧」シートを CSV で書き出して取り込み)
4. ステータス・セレクトの選択肢を整え、ビューを作成
5. **代表**: メンバーを招待(対外行為)
6. **代表**: Claude の Notion コネクタを claude.ai の設定から接続(対外行為)
   → 接続後は Claude が DB の作成・更新を代行できる

### 運用ルール(最小限)

- 案件の話は必ず案件ページに書く(チャットに流さない)
- ステータスは動いたその日に更新
- 毎週月曜に「⏰ 今週のアクション」と「💰 未入金」を確認

### プラン

- 少人数ならまず **Free** で開始し、メンバーが増えたら **Plus** を検討
  (料金・制限は変わるので契約前に公式サイトで確認)
