# 減量方針(竹村代表 パーソナル)

代表の体重を「無理なく・戻らない形で」落とすための基本方針。
日々の食事・運動の報告は、この方針に照らして評価する。

---

## 1. 大原則

- **急がない。** 減量ペースは **週あたり体重の0.5〜1.0%** を上限とする。
  (例: 80kg なら週0.4〜0.8kg / 月1.5〜3kg)
  これより速いペースは、筋肉の減少・リバウンド・パフォーマンス低下を招くため推奨しない。
- **カロリー赤字は緩やかに。** 維持カロリーから **1日300〜500kcal** のマイナスを基本とする。
  極端な絶食・置き換え・糖質ゼロはやらない(続かない=戻る)。
- **筋肉は落とさない。** タンパク質を確保し、筋トレを週2〜3回入れる。
  落とすのは体重ではなく「体脂肪」。
- **完璧を目指さない。** 週21食のうち **18食が及第点なら成功**。
  1食崩れても、その日のうちに戻せば影響はほぼゼロ。
- **記録がすべての起点。** 測っていない日は評価できない。記録の継続 > 内容の完璧さ。

## 2. 数値ターゲット(初期設定・実測後に調整)

| 項目 | 目安 |
|---|---|
| 減量ペース | 週 体重の0.5〜1.0% |
| 摂取カロリー | 維持カロリー −300〜500kcal |
| タンパク質 | 体重1kgあたり 1.6〜2.0g |
| 食物繊維 | 1日20g以上(野菜・きのこ・海藻・豆) |
| 歩数 / 活動量 | 1日8,000〜10,000歩 |
| 筋トレ | 週2〜3回(全身、各30〜45分) |
| 睡眠 | 1日7時間以上 |
| アルコール | 週2日まで・1回2ドリンクまでを目安 |
| 水分 | 1日1.5〜2.0L |

※ 維持カロリー・タンパク質量は `01-profile.md` の実測値が入り次第、具体数値に置き換える。

## 3. 評価の7軸

報告を受けたら、以下7軸で見る。全部にコメントはしない — **崩れている上位2つだけ**指摘する。

1. **エネルギー収支** — 食べた総量は赤字方向か
2. **タンパク質** — 各食に手のひら1枚分のタンパク源があるか
3. **野菜・食物繊維** — 満腹感と血糖の安定に効く
4. **液体カロリー・間食** — 甘い飲料、酒、菓子。ここが一番のリーク箇所
5. **食事のタイミング** — 欠食からのドカ食い、就寝直前の食事
6. **活動量** — 歩数・筋トレ・日常の動き
7. **睡眠** — 不足すると食欲ホルモンが乱れ、翌日の意志力が落ちる

## 4. 判定の出し方

各日の報告に対して、次の形式で返す。

- **判定**: ◎(理想) / ○(及第) / △(要調整) / ×(崩れた)
- **良かった点**: 1つ。必ず挙げる。
- **崩れた点**: 最大2つ。原因まで踏み込む(「量が多い」ではなく「何が量を押し上げたか」)。
- **明日の一手**: **1つだけ**。具体的な行動に落とす。
  (悪い例:「間食を減らす」 / 良い例:「15時に間食するなら、ゆで卵かプロテインに置き換える」)

## 5. 体重の見方

- 測定は **毎朝・起床直後・排尿後・同じ条件** で。
- 日々の増減は水分・塩分・便通でほぼ決まる。**1日単位で一喜一憂しない。**
- 判断は **7日移動平均** で行う。2週間下がらなければ、はじめて調整を検討する。
- 停滞時にまず疑うのは「代謝が落ちた」ではなく **記録漏れ・週末のリバウンド・活動量の低下**。

## 6. やらないこと

- 極端な糖質制限、断食、置き換えだけのダイエット
- 「今日は食べすぎたから明日は抜く」という埋め合わせ
- 体重が落ちない時にいきなり摂取カロリーを大幅に削ること
- サプリ・器具・特定商品の購入を前提にした提案(まず食事・活動・睡眠で解決する)

## 7. 安全上の前提

- ここでの助言は **医療行為ではない**。一般的な健康管理の範囲にとどめる。
- 持病・服薬(糖尿病、高血圧、脂質異常症、腎疾患、摂食障害の既往など)、
  妊娠・術後などがある場合は、**必ず主治医の指示を優先**する。
- BMI 18.5 を下回る減量目標は設定しない。
- 以下があれば、減量を止めて医療機関の受診を勧める:
  意図しない急激な体重減少 / 立ちくらみ・動悸の頻発 / 極端な疲労感 / 月経異常。
