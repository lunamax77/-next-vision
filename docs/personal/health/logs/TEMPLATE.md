## 月次ファイルの置き方

- 1ヶ月1ファイル: `logs/2026-08.md`
- ファイル先頭に月次サマリ(開始体重 / 現在体重 / 7日移動平均 / 所感)を置き、
  その下に日次記録を新しい順で積む。
