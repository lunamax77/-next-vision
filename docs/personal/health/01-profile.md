## GLP-1(マンジャロ / チルゼパチド)使用中の運用方針

**開始予定: 2026-08-25(火) 5mg 週1回**

### 前提

- 用量・増量・中止の判断は **すべて処方医の領域**。コーチ側は一切指示しない。
- 開始用量について: 一般に 2.5mg を4週間投与してから 5mg へ増量する。
  5mg からの開始は処方医の指示によるものか、代表に確認済みか要チェック。
- 処方元(医療機関か / 個人輸入か)を確認する。個人輸入品は偽造品リスクがあるため、
  医療機関の処方・定期フォロー下での使用を推奨する。

### 何が変わるか — 「食べすぎ」から「食べなさすぎ」への反転

薬で食欲が抑制されるため、摂取カロリーの管理は容易になる。
代わりに **摂取不足による除脂肪体重の減少** が最大のリスクになる。

> GLP-1 による減量では、失われる体重の 3〜4割が除脂肪(筋肉)由来になりうる。
> 代表の除脂肪65.0kg・基礎代謝1,760kcal は最大の資産であり、
> ここを削ると **薬を中止した時点でリバウンドする体** になる。

したがって本プランの主目的は「体重を落とすこと」ではなく、
**「除脂肪65kgを維持したまま体脂肪だけを落とすこと」** に置く。

### 食べる順番

食欲が落ちると、主食・嗜好品から食べて満腹になり、タンパク質が残る。
**タンパク質を最初に、必ず食べきる。野菜と主食は後回しで、余れば残してよい。**

### 副作用の観察項目

吐き気 / 嘔吐 / 下痢 / 便秘 / 倦怠感 / 食欲低下の程度 / 脱水感。
注射後 24〜72時間 がピークになりやすい(火曜注射なら水〜木)。

**以下は減量を中断し、受診を勧める:**
- 背中に抜けるような強い腹痛が持続(膵炎の可能性)
- 嘔吐・下痢で水分が摂れない(脱水)
- 立ちくらみ・動悸の頻発
- 意図しない急激な体重減少(週1.0%を大きく超える)

### 飲酒との組み合わせ(金・土 固定)

飲酒習慣は禁止せず、設計に組み込む。

- 火曜注射 → 副作用ピークは水〜木。金土には抜けているため、タイミングとしては整合的。
- **空腹での飲酒を避ける**(食欲低下下での飲酒は吐き気・低血糖リスクを上げる)。
  飲む前にタンパク源を入れる(サラダチキン / 枝豆 / 冷奴 / 刺身)。
- **1杯につき水1杯**を交互に。脱水は副作用と重なる。
- 糖質の少ない酒に寄せる(ハイボール / 焼酎の無糖割り / ワイン)。
  ビール・日本酒・果汁サワーは液体カロリーが積み上がる。
- 週2日で +1,000〜1,500kcal 程度なら平日の赤字で吸収可能。
- **金土の体重増加は水分。翌週火曜まで測定値を判断材料にしない。**

### 出口戦略(3ヶ月後を見据える)

薬は一生続けるものではない。中止後に戻らないために、投与期間中に
**除脂肪の維持 + 食習慣と運動習慣の定着** を完了させることを目標とする。
薬が効いている間に「食べる量が少なくても満足する食べ方」を体に覚えさせる。
