## 1. 評価制度の理解

### 1-1. 背景（8/12 説明会・4名共通）
- 資料は関西発ではない。九州から入手したもので、ほぼ東京が作成したものと説明されている。関西としての運用は未確定
- 目的: イベント隊 → 特販の順に精査（人員削減）が進んでおり、次はルーサポ・SV が対象になると見ている。半年先を見据えて質を上げる。「我々と会社としては全員残したい」（8/12 杉原面談）
- 「SVルーサポの…継続率を高めたい。一パーセントでも高めないと、この仕事なくなっちゃう」（8/12 ベスト面談）

### 1-2. 評価の4軸
軸の名前は面談ごとに少しずつ違う。最も詳しいのは 8/12 杉原面談で、以下はその版。

| 軸 | 中身 |
|---|---|
| ① 実績評価（定量） | 担当店舗の PI・SPSP・ドコモ光・ホーム5G の月次達成と、クオーター（3か月平均）の達成率 |
| ② 活動評価 | 週報の提出（例: 火曜まで）、記載内容の正確さ、週次ミーティングの実施 |
| ③ CS評価（定性） | 28項目を点数化する。量販店社員やキーマンとの関係、他コーナー活動、目標の把握、施策の展開、ドコモ方針の反映、アクションプランの作成と実行精度、報告の正確性、合意形成など。従来は「どんぶり勘定」「ザル」で、営業担当（旧タツミさん）の定性判断だった |

## 2. 指導の型（DC・森下が繰り返し使うロジック）

### 2-1. KPIファネルで語る（KGI は「終わった数字」）
- 獲得件数は KGI。その手前の アプローチ → ヒアリング／着座 → 提案 → クロージング・成約 が KPI
  - 「アプローチから着座までのパーセンテージってわかる？」「いや、わかんないっす」（8/12 祐介）
  - 「それ、KGIや。もう終わってるやん…KPIを比較しろっつってのに」（9/4 西）
  - 「店舗のマネジメントを語る上で、KPIを語らないのは、ちょっと違う」「相関関係…あるけど因果はないと思ってて、因果は絶対KPIで語らないといけない」（9/15 西）
- 量か質かを切り分ける
  - 「アプローチ一日3件で2件成約」と「100件で2件成約」は、どちらも結果は2件。前者はアプローチ量が課題で、後者は入口の興味付け（質）が課題（9/15 杉原）
  - 「量をやらないといけないやつが、量をやってないときは、もうほぼやる気がない」（8/28 祐介）
  - 素振りと打率のたとえ。質を上げるにはまず量（試行回数）が要る（8/28・9/15）
  - アプローチ数だけ増やしても、成約率は下がる。「10件も足りひんかった質への取り組みも絶対必要」（9/4 西）

### 2-2. 数字は必ず比較対象を持つ
- 「数字って必ず何かと比較しないと…比較ってAとBを比べること」「収集するのが仕事じゃなくてアクションするのが仕事」（8/12 杉原）
- 比較対象: 自分の過去、同じ遠隔レベル（レベル3・レベル5）の他店、関西全体、他の特販
  - 例: レベル3で、取れている店は「アプローチから着座が大体15%」、取れていない店は10%以下（8/28）
- 「分析はaとbを比較して初めて分析」「報告がゴールじゃない」（9/15 西）
- 報告された数字そのものを疑う。ミステリーショッパー方式で、離れた場所から30分観察し、「8組中何組のキャリアを聞けたか」で裏を取る（8/28 祐介）

### 2-3. 「なんとなく」禁止（理由と再現性）
- 「なんとなくはめちゃくちゃ怖い。負ける時のなんとなくも、勝つ時のなんとなくも…再現性がない」（8/12 祐介）
- 例外: 準備と仮説検証をやり切り、勝率6割以上と見たうえで進む「なんとなく」は OK（同）
- 「主観でなんとなくほんまにやめてほしい」（9/4 西）／「今そのなんとなくで言ってるやろ…それは弱い」（9/9 ベスト）
- POP の配置のような感覚的な判断も、行動心理学（アンカリング、フレーミング、ハロー効果、AIDMA など）で根拠を持たせる（8/12 祐介）

### 2-4. ゴールから逆算する／役割と責任を決める
- 「意図的に物事を考えるのって逆算なんよ。ゴールから考えるしかない」（8/12 ベスト）
- 「マネジメントの基本って役割と責任」「意図的に数字を作るのがもうマネジメント」（8/12 ベスト）
- まず「最高形」を定義し、その役割を担う人の準備（研修、根回し、バックアップ）まで設計する。スナイパーのたとえ（8/12 祐介）
- 逆算の実例
  - 家電コーナーの5件を12件にできるか（8/12 西）
  - 75ポイント → 3ポイント商材で約37組 → 構成比20%なら148組 → 週30組の商談が必要。これは無理なので「3ポイントの比率を上げるか、契約率を上げるか」の二択になる（9/9 ベスト）
- 「なぜ」を7回繰り返す（ロジカルシンキング）。自分の案を否定文で検証する（クリエイティブシンキング）（8/12 ベスト）
- 目標は「いける／いけへん」ではなく「いかせろ」（8/12 祐介）

### 2-5. 自分の答えを持ってから相談する
- 「事務局と喋った時に答えが出えへんっていうのは、僕は一番最悪…自分は答えを持った上で」（8/12 西）
- 「自分ならどうするんやろう」を日常的に考えておく訓練（8/12 祐介）

### 2-6. 発信・報連相（期待値を確認し、上に届ける）
- 「評価って相手の期待を超えて初めて評価」→ 上長（東村さん）に、期待・課題認識・取り組みへの理解の3点を聞く（8/12 ベスト・杉原）
- 「ハラダさんに送ってるからマル」という認識は改める。野尻さんにも「オウム返し」で伝える（8/12 西）。5分でも時間をもらう（8/20）
- 要点ファーストで話す。「役職者…要点しか聞かへん」「箱に区切って喋らないと」（8/12 西）
- 質問するときは、結論の一文だけでなく背景・目的・困りごとを添える（9/15 森下→杉原）
- 話し方（9/15 ディスカッション）
  - ゴールを置いてから話す
  - 否定形で返さず、いったん受け止める
  - 一文は30字程度にする
  - 語尾を暗くしない
  - 「つもり」を使わない
  - ロールモデルを持つ
- 第三者の評価は本人評価より強い（8/12 祐介）

### 2-7. 人を動かす・巻き込む
- 質問の形で場を回す（「前回ってこうでしたよね、どう思います？」）（8/12 森下）
- 「スパイ活動と味方作り」。何気ない会話から、相手の組織での位置・決裁権・ミッションを引き出す。ラウンダーには月初に方針を聞きに行き、敵ではないと示す（8/12）
- 上を使う
  - 揉め事は「平場」に上げる。上司（福井さん等）を巻き込み、野尻課長には「耳だけ」聞いてもらう（8/12 祐介）
  - 大事な話を伝える前は、経験者とトークフローをシミュレーションする（9/15）
- ベテラン特販には、まず話を聞いてマイルールを把握する。「知恵を貸してくれ」と相談ベースで頼む（9/15 西）
- 1店舗に集中して PDCA を回し、勝ちパターンをテンプレート化してから横展開する（8/20・8/28）
- 早めにエスカレーションする。「1カ月前とかからあげるべきだった」（9/9 祐介）

## 4. 報告書作成上の注意

1. **「実施したこと」と「検証済みの成果」を分ける**
