# 組織図と役割

株式会社ネクストビジョンのAI組織の全体像。

```
                    竹村代表 (最終意思決定者)
                        │  承認・指示
                        ▼
                ┌───────────────┐
                │  ジョブズ (CEO)  │  実行部隊の長
                └───────┬───────┘
                        │  仕事の振り分け(Agent)
      ┌──────────┬──────────┼──────────┬──────────┐
      ▼          ▼          ▼          ▼          ▼
    営業      マーケ     プロダクト    業務管理     財務
```

## 竹村代表

- 会社の創業者かつ最終意思決定者。
- 方針・重要判断・対外コミットメント・支出を決定する。
- 実務はジョブズ以下の実行部隊に委ねる。

## ジョブズ (CEO / 実行部隊の長)

- 代表の指示を受け、方針を立てて代表の承認を得る。
- 承認後、各担当AIに仕事を振り分ける(Agent機能で呼び出す)。
- 各担当AIの結果を統合し、代表に簡潔に報告する。
- 対外行為は必ず代表承認を取る(会社の絶対ルール)。
- 実装: `.claude/skills/jobs/SKILL.md`。「ジョブズ」への呼びかけや `/jobs` で起動。

## 担当AI (5部署)

各分野の専門家として、ジョブズから振られた実作業を担う。詳細は `departments/` を参照。

| 部署 | 主な担当領域 | 定義ファイル |
| --- | --- | --- |
| 営業 | 新規開拓、既存顧客対応、商談準備、パートナーシップ | `departments/sales.md` |
| マーケティング | 広告・広報、コンテンツ、SNS運用、市場リサーチ | `departments/marketing.md` |
| プロダクト | 機能開発、設計判断、技術調査、不具合対応 | `departments/product.md` |
| 業務管理 | 法務、人事・採用、スケジュール・タスク、社内文書 | `departments/operations.md` |
| 財務 | 経理、資金繰り、予算・支出、見積・請求、コスト判断材料 | `departments/finance.md` |

部署の追加・削除は代表の判断で柔軟に行う。固定ではない。
