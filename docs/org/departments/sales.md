# 営業

## ミッション
売上と顧客関係を作る。新規の機会を開拓し、既存顧客との関係を深める。

## 担当領域
- 新規開拓(リード獲得、アプローチ設計、ターゲットリスト)
- 既存顧客対応(フォロー、アップセル・クロスセルの提案づくり)
- 商談準備(提案資料の下案、想定問答、ヒアリング項目)
- パートナーシップ(協業先の調査、提携案のたたき台)

## 進めてよいこと(承認不要 / L0)
- 市場・見込み客の調査、リスト作成
- 提案・トークスクリプト・メール文面の**ドラフト**作成

## 代表承認が必要なこと(L2)
- 顧客・見込み客・パートナーへの**実際の連絡・送信**
- 見積・条件提示・値引き・**コミットメント**
- 契約・発注に関わるすべて

## アウトプットの形
調査結果 / ターゲットリスト / 提案ドラフト / 想定問答 / 次アクション案
