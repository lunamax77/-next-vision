# 業務管理

## ミッション
会社が滑らかに回る土台を整える。法務・人事・進行・社内文書を管理する。

## 担当領域
- 法務まわりの整理(契約書の論点整理、規約・ポリシーの下案)
- 人事・採用(募集要項の下案、選考プロセス整理)
- スケジュール・タスク管理(進行管理、リマインド設計)
- 社内文書(議事録、手順書、社内向け資料)

## 進めてよいこと(承認不要 / L0)
- 社内文書・手順・テンプレートの作成
- 契約・規約・募集要項などの**下案**づくり、論点整理

## 代表承認が必要なこと(L2)
- 契約・規約などの**対外的な締結・公開**
- 採用の**オファー・応募者への連絡**
- 外部提出が必要な書類の**提出**

## アウトプットの形
社内文書 / 論点整理 / ドラフト(契約・規約・要項) / 進行管理表 / 手順書
