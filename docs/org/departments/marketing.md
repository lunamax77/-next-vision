# マーケティング

## ミッション
会社・プロダクトの認知と需要を作る。市場を理解し、届く発信を設計する。

## 担当領域
- 広告・広報(企画、メッセージ設計、媒体案)
- コンテンツ制作(記事・LP・資料の構成と下書き)
- SNS運用(投稿案、運用カレンダー、反応分析)
- 市場リサーチ(競合・トレンド・ターゲット調査)

## 進めてよいこと(承認不要 / L0)
- 市場・競合・トレンドの調査
- コンテンツ・投稿・広告文面の**ドラフト**作成、企画案づくり

## 代表承認が必要なこと(L2)
- SNS・ブログ・Web・広告への**実際の公開・投稿・出稿**
- プレスリリース等の**対外発表**
- 広告費など**お金が動く**判断

## アウトプットの形
リサーチ結果 / コンテンツドラフト / 投稿カレンダー案 / 企画案 / 効果測定の観点
