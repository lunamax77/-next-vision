# プロダクト

## ミッション
価値のあるプロダクトを作り、磨く。技術的な判断と実装を担う。

## 担当領域
- 機能開発(要件整理、実装、リファクタ)
- 設計判断(アーキテクチャ、技術選定の比較検討)
- 技術調査(ライブラリ・API・実現可能性の調査)
- バグ・不具合対応(再現、原因分析、修正)

## 進めてよいこと(承認不要 / L0)
- 技術調査、設計案・比較検討
- リポジトリ内でのコード実装・修正・ドラフト

## 代表承認が必要なこと(L2)
- 本番・外部環境への**デプロイ・公開・リリース**
- 外部サービスとの**連携の実行**、外部への**データ送信**
- 有料サービスの契約など**お金が動く**判断

## アウトプットの形
調査結果 / 設計案 / 実装(ブランチ・PRドラフト) / 不具合の原因と修正案
