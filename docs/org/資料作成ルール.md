# 資料作成ルール（全AI共通）

株式会社ネクストビジョンで**書類・資料（見積書・請求書・契約書・提案書・説明資料など）を作成するときの共通ルール**です。すべてのAIはこのルールに従って資料を作ること。竹村代表のフィードバックで随時アップデートする。

---

## 1. 書類は種類ごとに独立ファイルにする

- **見積書・請求書・契約書は、それぞれ別ファイル**にする（1つのファイルに混在させない）。
- 種類の異なる書類を1ファイルにまとめない。相手が「見積書だけ」「契約書だけ」を扱えるようにする。
- 補足資料（見積根拠など）も、本体書類とは分けて別ファイルにする。

## 2. 改ページは必ず綺麗に（最重要）

> **1ページ目と2ページ目で内容が中途半端に続いてしまう状態にしない。** ブロックが収まらないときは、途中で割らず**塊ごと次ページの先頭**から表示する。

- **各ページに均等な余白を確保**する（`@page { margin: 13mm 14mm }` 等）。2ページ目以降が紙の上端に貼り付かないようにする。
- 次のブロックは**ページの途中で分割しない**（`break-inside: avoid;` と `page-break-inside: avoid;` を併記）：
  - 表の各行、金額の合計欄、備考、振込先、契約の各条文、署名・押印欄、宛先/発行元ブロック。
- **契約書は「1条文＝1つの分割不可ブロック」**にする（見出し＋本文をまとめて `break-inside: avoid`）。条文が見出しだけ取り残されたり、途中で切れたりしないようにする。
- 表が複数ページに跨ぐ場合は、**見出し行（thead）を各ページで繰り返す**（`thead { display: table-header-group; }`）。
- 見出しは**次の内容と一緒に**保つ（`h3, h4 { break-after: avoid; }`）。
- **見積書・請求書など短い書類は、極力1ページに収める**（余白・行間・不要な空行を詰める）。1ページに収まらず備考等があふれる場合は、まず余白を詰め、それでも無理なら②のルールで綺麗に次ページへ。

### 参考CSS（そのまま流用可）

```css
@media print{
  .doc{ margin:0; padding:0; }
  @page{ size:A4; margin:13mm 14mm; }         /* 全ページ均等余白 */
  .top,.lead-amt,.subject,.tots,.notes,.bank,
  .sign,.sign .box,.clause,.k-lead,.k-foot{
    break-inside:avoid; page-break-inside:avoid;  /* 途中で割らない */
  }
  table tr{ break-inside:avoid; page-break-inside:avoid; }
  thead{ display:table-header-group; }         /* 表の見出しを各ページで繰返す */
  h3,h4{ break-after:avoid; page-break-after:avoid; }
}
```

## 3. フォントはメイリオで統一

- 全資料で**メイリオ（Meiryo）優先**のゴシックに統一する。見出しに明朝を混ぜない。
- フォント指定例：`"Meiryo","メイリオ","Hiragino Kaku Gothic ProN","Hiragino Sans","Noto Sans JP",sans-serif`

## 4. 金額・体裁

- 金額は**税込表示**で統一し、全書類・全ページで**整合**させる（見積＝請求＝契約の合計が一致）。
- 発行元情報（社名・住所・連絡先・適格請求書登録番号）と**角印**を反映する。
- 書類の識別番号（見積番号・請求番号）・発行日・宛先を明記する。

## 5. 承認フロー（対外の鉄則）

- 作成物は最初は**社内ドラフト**。**竹村代表の承認後**に「正式発行」表記へ切り替える。
- **対外提出・送付・公開は、実行前に必ず代表の承認**を得る（`CLAUDE.md` 第3項）。AIから外部へ直接送信しない。

## 6. 仕上げ前の自己チェック

- [ ] 書類の種類ごとにファイルが分かれているか
- [ ] 各ページに余白があり、2ページ目が上端に貼り付いていないか
- [ ] 表・備考・条文・署名・振込先がページ途中で切れていないか
- [ ] 見積・請求など短い書類は1ページに収まっているか
- [ ] フォントはメイリオで統一されているか
- [ ] 金額は税込で、全書類・全ページ整合しているか
- [ ] （対外提出前）代表の承認を得たか
