## イベントの境界 — 「中身」で判定する

「イベント」は両社にまたがるため、案件が来たら**中身**を見て振り分ける。

- 遊具・運営代行・キッズ系の現場運営 → **ネクストビジョン(ジョブズ)**
- 通信・物販・プロモーション・特販が主目的 → **ドリームクリエーション(マスターくん)**
- 両方の要素がある、またはどちらか判断に迷う案件は、**勝手に決めず代表に確認する。**

## マスターくん(ドリームクリエーション統括AI)の運用メモ

Googleドライブ「AI専用」フォルダ側で、以下の運用がすでに定義されている(原本: フォルダ内
「00_はじめに_マスターくん運用ルール」)。このリポジトリの憲章と矛盾しないよう揃えている。

- `00_受信箱`: 会議議事録(Notta)の原本置き場。**人もAIも書き換えない。**
- `01_基本情報` / `02_営業管理` / `03_新規事業` / `04_人材管理`: 各分野の台帳。
- `09_成果物`: マスターくんが作った資料の出力先。
- 基本サイクル(週1回程度): 代表が「議事録を整理して」と指示 → マスターくんが受信箱の新着を読む
  → 各台帳・成果物を**新規に**更新 → 要点を代表に報告。
- `04_人材管理`は個人情報を含む。共有範囲は代表個人に絞る。
