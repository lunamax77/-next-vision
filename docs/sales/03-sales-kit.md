# 商談キット — ヒアリング＆提案の骨子（営業）

> **ドラフト（社内たたき台）。送信・提出は対外行為のため竹村代表の承認後に実行。**
> 本書は社内で使う商談用の道具立てです。ここに含まれる提案書・見積の**外部提出はすべて L2（対外行為）**であり、
> 竹村代表の承認なしに実行しません。

---

## 0. 商談の全体像

```
 ①問合せ受領 → ②初回ヒアリング → ③在庫・条件確認（社内） → ④提案書＋見積の作成（社内）
    → ⑤【代表承認】 → ⑥提案・見積の提出（対外） → ⑦質疑・調整 → ⑧【代表承認】→ ⑨受注・契約
    → ⑩開催準備 → ⑪搬入・設営 → ⑫開催・撤収 → ⑬請求【代表承認】→ ⑭入金確認 → ⑮フォロー・次回提案
```

- **④までは L0（社内作業）**。営業が承認なしで進めてよい。
- **⑤⑧⑬は必ず代表承認**。ここを飛ばさない。
- 各段階で `tools/pipeline/案件管理.xlsx` のステータスを更新する
  （問合せ→ヒアリング→見積提出→受注→開催準備→開催済→請求済→入金済／失注・保留）。

## 1. 初回ヒアリングシート

> 使い方：**全部を一度に聞かない。** ★は初回で必ず押さえる項目、それ以外は提案作成前までに埋める。
> 相手が答えにくい項目（予算）は幅で聞く。**わからない項目は「未確認」と書き、推測で埋めない。**

### 1-0. 案件基本情報

| 項目 | 内容 | 重要度 |
| --- | --- | --- |
| 受付日 | | ★ |
| 会社名・施設名 | | ★ |
| 部署・ご担当者名 | | ★ |
| 連絡先（TEL / MAIL） | | ★ |
| 流入経路 | HP問合せ／電話／紹介／代理店経由 など | ★ |
| 決裁者は誰か・ご担当者は決裁者か | 「社内でご確認いただく方はいらっしゃいますか」と柔らかく確認 | ★ |
| 社内の決裁プロセスと所要期間 | 稟議の有無・所要週数 | ○ |

| **開催希望日・曜日** | 「〇月ごろ、で構いません」。**土日・連休は早期に埋まるため最優先で確認** | ★ |

| **開催時間帯** | 開始・終了時刻。館の営業時間 | ★ |

### 1-2. 会場条件 ── ここが成立可否を決める

| 項目 | 確認する内容 | 効いてくる商材 |
| --- | --- | --- |
| **会場の所在地（住所）** | **配送実費の概算に必須**。大阪からの距離 | 全商材 ★ |
| **屋内／屋外** | 屋内向き＝ぷにラボ・シールデコ。屋内外OK＝KLP・エア遊具 | 全商材 ★ |
| **使えるスペースの寸法（縦×横）** | **KLPは10m×8m目安（コース＋受付・発行ブース込み）／ワークショップは6畳〜** | KLP・WS ★ |
| **図面の有無** | 「お図面をお送りいただければ配置案をお出しします」（HP記載） | 全商材 ★ |
| **スペースの形状** | 細長い／L字／柱がある。**KLPはコース配置を会場形状に合わせて調整可能** | KLP ★ |
| **床の材質・養生の要否** | カーペット／タイル／アスファルト。原状回復の範囲 | KLP・エア遊具 ○ |
| **屋外の場合の地面** | 舗装／土／芝。ペグ打ちの可否、アンカー・ウェイトの要否 | **エア遊具 ★** |
| **屋外の場合の風対策** | 風の抜け方、中止判断の基準 | **エア遊具 ★** |

### 1-3. エア遊具・KLP の設置条件（**特に具体的に確認する**）

> エア遊具は「送風機で常時膨らませ続ける」機材のため、**電源と高さと固定方法**が成立条件そのもの。
> ここを曖昧にしたまま受注すると、当日設置できない事故につながる。**必ず数字で押さえる。**

| # | 確認項目 | 具体的に聞くこと | なぜ必要か |
| --- | --- | --- | --- |
| 1 | **天井高** | 「天井の高さは何メートルありますか」「垂れ下がっている照明・スプリンクラー・配管・装飾はありますか」 | **エアリズム／エアリズム トランポリンは H1750mm（1.75m）**。膨張時の実寸に加え、**利用者が跳ねる・立ち上がる分の余裕**が要る。低い天井や吊り下げ物があると設置不可 |
| 2 | **設置寸法＋安全マージン** | 「〇m×〇mが確保できますか。**遊具の周囲に人が通る余白**も含めて確保できますか」 | HP記載「**設置寸法＋安全マージン**」。エアリズム系は **W2800×D1000×H1750mm** が本体寸法 |
| 3 | **電源（有無）** | 「電源はご用意いただけますか」 | **送風機に電源が必須**（HP記載）。KLPも免許証発行機材・EVカー充電で必要 |
| 4 | **電源（容量・口数・電圧）** | 「**何アンペアの回路を、何口**お使いいただけますか」「100Vですか、200Vですか」 | HP記載「ご用意いただける電源容量をお知らせいただければ、それに合わせた構成をご提案します」。**容量不足はブレーカー落ちに直結** |
| 5 | **電源（位置と距離）** | 「コンセントは設置場所から**何メートル**離れていますか」 | 延長コード・ケーブル養生の準備量が決まる。動線を横切る場合はマット養生が必要 |
| 6 | **発電機の要否** | 「屋外で電源がない場合、発電機の持ち込みは可能ですか」 | 電源がない会場では発電機が必要。**【要確認】当社で発電機を手配できるか／費用はどう扱うか** |
| 7 | **搬入経路（幅・高さ）** | 「搬入口の**幅と高さ**」「通路の幅」「曲がり角の有無」 | 機材が通らなければ何も始まらない |
| 8 | **エレベーター** | 「使用可能なエレベーターの**内寸・積載重量**」「養生の要否」 | 上階の会場は必ず確認 |
| 9 | **車両の横付け可否・駐車場** | 「トラックを搬入口に**横付け**できますか」「**車高制限**は何メートルですか」「作業用の駐車スペースはありますか」 | 立体駐車場の車高制限で搬入車が入れない事故が起きやすい |
| 10 | **搬入・搬出の時間帯** | 「営業時間外の作業は可能ですか」「**前日搬入**はできますか」 | HP記載「搬入・設営は前日か当日早朝」。営業中の搬入は不可の施設が多い |
| 11 | **保管場所** | 「開催期間中、資材を置いておけるスペースはありますか」 | 複数日開催・常設で必要 |
| 12 | **提出書類** | 「**保険の証明書、実施計画書、搬入届、火気/電気使用届**などのご提出は必要ですか」「**提出期限**はいつですか」 | HP記載：賠償責任保険の**証明書類の提出に対応**。**期限を逃すと開催できない** |
| 13 | **消防・管轄への届出** | 「消防署への届出が必要な形態でしょうか」 | 施設側の担当と役割分担を明確にする。**【要確認】当社が代行する範囲** |
| 14 | **控室・スタッフ動線** | スタッフの待機場所、休憩、トイレ | 運営代行時 |
| 15 | **原状回復の範囲** | 「撤収後、どの状態までお戻しすればよいですか」 | HP記載：運営代行は原状回復まで対応 |
| 16 | **KLP：走行面の状態** | 「床は平滑ですか」「傾斜・段差はありますか」「屋外なら砂利・凹凸はありますか」 | EVカーの走行安全に直結 |
| 17 | **KLP：受付・発行ブースの位置** | 撮影と免許証発行のためのブース設置場所 | 10m×8mの内訳（コース＋ブース） |
| 18 | **KLP：撮影の可否** | 「顔写真の撮影について、施設側のルールはありますか」 | 免許証は顔写真入り。**個人情報・肖像の取扱いルールを確認**【要確認：当社の写真データ取扱いポリシーの有無】 |
| 19 | **WS：テーブル・イスの用意** | 「テーブルとイスはご用意いただけますか、こちらで持ち込みますか」 | 6畳〜の設置に必要 |
| 20 | **WS：給排水・ゴミ** | ぷにラボは液剤を扱う。手拭き・ゴミの処理 | 会場ルールの確認 |

### 1-4. 予算・体制

| 項目 | 聞き方 | 重要度 |
| --- | --- | --- |
| **ご予算** | 「**〇〇万円くらいの規模でお考えでしょうか**」と幅で当てる。直球で「いくらですか」と聞かない | ★ |
| 予算の費目・年度 | 販促費／イベント費／年度予算か | ○ |
| **運営代行の要否** | 「当日は御社スタッフ様で運営されますか、それとも弊社で受付・安全管理まで担当しましょうか」 | ★ |
| 当日出せる先方スタッフ数 | PLAN A の場合に必須 | ○ |
| **過去の実施実績** | 「これまで同じような企画をされたことはありますか」→ **あれば必ず「そのときに困ったことは何でしたか」まで聞く** | ★ |
| 前回の課題 | 人手不足／行列／雨天中止／単価が高かった／盛り上がらなかった | ★ |
| **比較検討している他社の有無** | 「ほかにもご覧になっている会社はありますか」 | ○ |
| 決め手になるポイント | 価格／安全／実績／ワンストップ／日程 | ○ |

### 1-5. ヒアリング後に社内でやること（提案作成前）

1. **在庫・日程の確認**（**最重要**）。空いていない日を約束しない。【要確認：在庫カレンダーの所在】
   > ⚠ **保有台数は客先非公表（2026-08-24 代表確定）。** 台数を聞かれても答えない。
   > 「複数台ございます」「◯台まで出せます」といった**示唆する言い方も使わない**。
   > **答え方**：「**台数は公表していないのですが、ご希望の構成で対応できるかは確認して当日中にご回答します**」
   > → その場で受注可否を答えず、**必ず社内の稼働カレンダーで確認してから回答する**。
   > 同日複数会場・複数台・月額常設の引き合いは**すべてこのフローに乗せる**。
   > ※台数が非公表であるため、営業が独断で「できます」と答えられない。**社内確認が必須の運用**になる。
2. **会場条件の成立判定**（スペース／天井高／電源／搬入経路）。不成立なら**代替コンテンツを用意してから返す**
3. **配送費の概算**（会場所在地から）。※請求は実費精算（HP記載）
4. **運営代行の要員数の見積り**（KLP 2〜3名／WS 1〜2名／エア遊具 1〜2名がHP記載の推奨スタッフ数）
5. `tools/pipeline/案件管理.xlsx` を「ヒアリング」ステータスに更新

## 2. 提案書の骨子

> 目安 8〜12ページ。**「相手の課題 → 解決 → 具体的な絵 → 安心 → 金額 → 次の一歩」**の順。
> **提出は L2（対外行為）＝ 代表承認後。**

| 章 | タイトル | 書くこと | 注意 |
| --- | --- | --- | --- |
| **表紙** | 〇〇様 ご提案書 | 相手先名／企画名／開催予定時期／提出日／株式会社NextVision | 相手先名の誤記は致命的。必ず確認 |
| **1** | 本日いただいたご要望の整理 | **ヒアリングした課題を相手の言葉のまま書き戻す**（例：「週末のファミリー来館のきっかけをつくりたい」「商談中のお子様の過ごし方に困っている」） | **ここが最重要。**「ちゃんと聞いてくれた」がすべての土台。ここで外すと以降が響かない |
| **2** | ご提案の全体像 | 1枚で「何を・どこに・何日・誰が運営するか」。配置イメージ図（会場図面に落とす） | 図面をもらえていれば**必ず配置案を入れる**（HP でも「配置案をお出しします」と約束している） |
| **3** | コンテンツ詳細 | 提案する各コンテンツを1つ1ページ。**体験の流れ・所要時間・対象年齢・必要スペース・スタッフ数・電源** | HP／各コンテンツページの記載事実のみ。**創作しない** |
| **4** | 当日のタイムテーブル | 搬入・設営 → 開始 → 運営（回転数の想定）→ 終了 → 撤収・原状回復 | **回転数は「所要時間÷組」からの計算値**であることを明記し、来場者数を保証しない |
| **5** | 運営体制 | 誰が何を担当するか（当社スタッフ／貴社スタッフ）の**役割分担表**。PLAN A / B の違い | 「貴社にお願いしたいこと」を明確に。後の揉め事を防ぐ |
| **6** | 安全への取り組み | 賠償責任保険への加入と証明書類の提出対応／運転コースへのスタッフ常時立ち会いと速度・車間の管理／エア遊具の使用のたびの点検／こども免許証91×55mm（実物とサイズを変えている配慮） | **HP記載の4点のみ**。保険の金額・保険会社名など**HPにない情報は書かない**【要確認：保険内容の詳細をどこまで開示してよいか】 |
| **7** | 実績 | 大手家電量販店・大型商業施設・携帯キャリアの店頭イベントでの企画〜運営。関西・北陸ほか全国対応 | **【要確認】社名・写真の使用可否**。許諾範囲を超えないこと。**件数・来場者数の数字は創作しない** |
| **8** | お見積り | 機材レンタル費用（税別・内訳）／運営代行費／配送費（概算・実費精算）／消費税／合計 | **「税別」「スタッフ費別」「配送は実費精算」を必ず明記**。**代表承認前は提出しない** |
| **9** | ご利用の流れ | お問い合わせ→ヒアリング→お見積り→ご契約・準備→搬入・設営→開催・撤収（HPのFLOW と同じ6段階） | 「目安は開催の1か月前」を明記 |
| **10** | 雨天・中止時の取り扱い | 屋外の場合の判断基準と、屋内ワークショップへの切替（前日までのご相談で可） | **キャンセル料の規定は【要確認】。規定が未定のまま条件を書かない** |
| **11** | 次のステップ | 「〇月〇日までにご返答いただければ、日程を確保できます」 | **在庫を確認せずに日程確保を約束しない** |
| **付録** | 実施条件早見表 | HPの「条件早見表」と同内容（スペース・対象年齢・所要・スタッフ・電源・屋内外） | そのまま転記 |

### 2-1. 提案書を作るときの禁止事項

- ❌ **来場者数・売上増・満足度などの効果を数値で約束する**（HPにも数値の実績記載はない）
- ❌ **HPにない実績・社名・受賞歴・保有台数を書く**
- ❌ **HPと異なる価格を書く**（→ `pricebook.json` との ¥10,000 差は §5-1 の【要確認】）
- ❌ **値引き・特別条件を営業判断で書く**（L2：対外コミット）
- ❌ **キャンセル料・違約金の条件を、社内規定がない状態で書く**

> HP の「EFFECT／期待される効果」には「+30分 滞在時間」等の表現があるが、**これはHP上の期待値表現**。
> 提案書で使う場合は「**期待される効果**」という位置づけを崩さず、**保証・実測値として書かない**。
> **【要確認】この表現を提案書に転用してよいか。**

## 3. よくある反論と切り返し

> 原則：**否定しない → 事実で答える → 選択肢を出す。** 値引きで応えず、**構成で応える**。

### 3-1. 「高い」

| 相手の本音 | 切り返し |
| --- | --- |
| 予算枠に収まらない | 「ご予算をお聞かせいただけますか。**その範囲に収まる組み合わせをお出しします**」→ ①コンテンツを1つに絞る ②KLP→エア遊具単体（¥90,000→¥60,000）③2日→1日 ④**運営代行を外して機材のみ（PLAN A）にする** |
| 何にいくらかかるか分からない | 「表示は**機材レンタル費用（税別）**で、運営スタッフ費と配送費が別になります。**内訳をすべてお出しします**ので、削れるところを一緒に見ていきましょう」 |
| 他社より高い気がする | 「弊社の金額には、**設営・受付・安全管理・撤収・原状回復まで**が含められます（運営代行の場合）。**比較しやすいように、含まれるものを明記した形でお出しします**」※他社批判はしない |
| 2日開催で予算オーバー | 「**2日目以降は機材費が50%**になります。1日開催と2日開催で並べてお出ししますので、費用対効果でご判断ください」 |
| 長期でやりたいが高い | 「**エア遊具には月額のご用意があります**（エアリズム系 ¥360,000／月、カーニバル ¥330,000／月・税別）。**1か月常設なら日額換算で大きく変わります**」 |

**やってはいけない**：その場での値引き提示（L2）。「特別に」「今回だけ」は言わない。

### 3-2. 「スペースがない」

| パターン | 切り返し |

## 4. 見積もり作成の流れ

> **見積の「作成」は L0（社内作業）。「提出」は L2（対外行為）＝ 代表承認が必須。**
> `tools/invoicing/` のツールで生成した xlsx を、**承認前に外部へ送らない。**

### 4-1. 手順

```
Step 1  ヒアリング内容の確定
        └ 商材／台数／日数／会場所在地／運営代行の要否

Step 2  在庫・日程の確認【社内】
        └ 空いていなければ、ここで代替案に切り替える

Step 3  金額の組み立て
        ├ 機材レンタル費：pricebook.json の単価 × 数量 ×（初日満額＋2日目以降50%）
        ├ 運営代行費：別途見積【要確認：算定基準が未定】
        └ 配送費：概算で計上 → 請求時に実費精算（HP記載）

Step 4  ジョブJSON を作成
        └ tools/invoicing/jobs/ に配置（sample_quote.json を雛形にする）

Step 5  生成
        └ python3 tools/invoicing/generate.py jobs/<案件名>.json  → out/ に xlsx が出る

Step 6  社内チェック（§4-4 のチェックリスト）

Step 7  【竹村代表の承認】 ★ここを飛ばさない

Step 8  提出（対外行為）→ 案件管理表を「見積提出」に更新
```

### 4-2. ジョブJSON の書き方（`tools/invoicing/README.md` より）

```jsonc
{
  "type": "quote",
  "customer": "〇〇株式会社",           // 自動で「御中」が付く
  "subject": "キッズ体験イベントについて",
  "period": "2026年〇月〇日～2026年〇月〇日",
  "issue_date": "2026-08-24",
  "person": "〇〇",
  "rental_items": [                     // 最大4件
    {"item": "キッズライセンスパーク（スタンダード）", "qty": 1, "days": 2},
    {"item": "エアリズム トランポリン", "qty": 1, "days": 2}
  ],
  "transport_items": [                  // 見積は最大3件
    {"name": "配送料金(片道)　大阪→〇〇", "qty": 1, "days": 1, "unit_price": 00000}
  ],
  "output": "out/見積_〇〇_2026〇〇.xlsx"
}
```

- `item`（遊具名）＋ `days` を指定すると `pricebook.json` から単価を引いて**自動計算**（初日満額・2日目以降50%）。
- `unit_price` / `amount` を明示した場合はそちらが優先される。
- **運営代行費は pricebook に無い**ため、`name` と `amount` を明示して行を立てる。

### 4-3. 計算例（税別・機材費のみ／HP価格ベース）

| 構成 | 計算 | 機材費計 |
| --- | --- | --- |
| KLPスタンダード 1日 | 90,000 | **¥90,000** |
| KLPスタンダード 2日 | 90,000＋45,000 | **¥135,000** |
| KLPプレミアム 2日 | 135,000＋67,500 | **¥202,500** |
| エアリズム トランポリン 2日 | 80,000＋40,000 | **¥120,000** |
| ぷにラボ 1日 | 90,000 | **¥90,000** |
| KLPスタンダード＋エアリズム 2日 | 135,000＋90,000 | **¥225,000** |
| エアリズム 1か月常設 | 月額 | **¥360,000** |

＋ 運営代行費（別途）＋ 配送費（実費）＋ 消費税10%

### 4-4. 見積の社内チェックリスト（代表承認を求める前に全部つぶす）

- [ ] **単価がHP掲載額と一致しているか**　※`pricebook.json` はHPより¥10,000低い（§5-1【要確認】）。**未解決のうちは、生成物の単価を必ず目視で照合する**
- [ ] 日数計算（初日満額・2日目以降50%）が正しいか
- [ ] **運営代行費が漏れていないか**（PLAN B の場合）
- [ ] **配送費が計上されているか**、「概算・請求時に実費精算」の但し書きがあるか
- [ ] 消費税10%が正しく計算されているか（テンプレの数式）
- [ ] 宛名・件名・期間・担当者名の誤記がないか
- [ ] **発行元が正しいか** ← **テンプレートの発行元は現在「株式会社DreamCreation」**（適格請求書番号 T5120001206752、振込先 池田泉州銀行 難波支店）。**NextVision名義で出すならテンプレートの差し替えが必要**（`tools/invoicing/README.md` 記載）。**【要確認・最重要】**
- [ ] 有効期限・キャンセル規定の記載要否を確認したか【要確認：社内規定の有無】
- [ ] **在庫・日程を確認済みか**（押さえていない日を見積に書かない）
- [ ] **代表の承認を得たか** ← これがない限り送らない

### 4-5. 請求について

- 生成方法は見積と同じ（`"type": "invoice"`、`due_date` を追加）。
- **請求書の対外送付は L2（対外行為）**。`tools/invoicing/README.md` にも明記されている。**生成まで＝社内、送付は代表承認後。**
- 配送費は**見積時の概算ではなく、請求時に実費**で計上する（HP記載の約束）。

| 11 | 🔴 **DreamCreation は代表が代表取締役を務める会社だと判明** | 見積・請求テンプレートの発行元が「株式会社DreamCreation 代表取締役 竹村英哲」。**#2（発行元の名義）は単なるテンプレの残骸ではなく、商流の設計そのものの論点**。取り決め事項は `docs/sales/01-target-segments.md` §7-A のチェックリストを参照。**特に保険の被保険者がどちらの会社かは最重要** |
| 6 | **賠償責任保険の開示範囲**（保険会社名・保険金額を客先に伝えてよいか） | 商談で最も聞かれる項目。持ち帰りが増えると失注要因になる |
| 7 | **ぷにラボの材料の成分・アレルギー情報**（SDSの有無） | 学校・保育園・自治体で必ず聞かれる（プロダクト部門と連携） |
| 8 | **機材の保有台数と在庫カレンダーの所在** | 日程を約束できるかどうかの前提 |
| 9 | **発電機の手配可否と費用の扱い** | 屋外・電源なし会場での成立可否 |
| 10 | **開催時の写真撮影・SNS掲載の許諾フロー**、肖像権の取り扱い | 実績づくりに直結。マーケティング部門と連携 |
| 11 | **HPの「EFFECT／期待される効果」表現を提案書に転用してよいか** | 効果の断定表現になると対外リスク |
| 12 | ✅ **決着：取引先名は提案書に記載しない** | **2026-08-24 代表回答「承諾は取れていない」。** 提案書§7（実績）は**業種表記のみ**で書く。件数・来場者数の数字も創作しない |
| 13 | **消防等への届出を当社が代行する範囲** | 施設側との役割分担の明確化 |
| 14 | **提案書・資料の実物がまだ存在しない** | 「資料をお送りします」と言える状態にするため、資料制作の要否を判断いただきたい |
