## 5. 時間コスト(交通費より重い論点)

| 手段 | 1日あたり移動時間 | 月間(21日) |
|---|---|---|
| 電車 | 平均 約3時間50分 | **約80時間** |
| 車 | 平均 約2時間50分 | 約60時間 |

- 電車の場合、**実働の約35〜40%が移動時間**。時給2,000円換算で月16万円相当の機会損失。
- 交通費(6.9万円)と時間コスト(16万円相当)を合わせると、**東大阪拠点での滋賀担当は月23万円のコスト構造**。

## 6. 結論と提案

### 想定額
- **月 約6.9万円**(案B・1ヶ月定期)/ **月 約6.3万円**(6ヶ月定期)
- 年間 約76〜83万円/人

### 提案(優先度順)

1. **拠点の再設計を最優先で検討**
   草津・守山エリアに住居手当付きで営業を配置すれば、交通費は月1.5万円以下、移動時間は約1/4に。
   家賃補助 月3万円を出しても、交通費+時間コストの改善で会社側が明確に得。
   → 採用時点で「滋賀在住者 or 転居可能者」を条件にするのが最も効く。

2. **拠点が東大阪固定なら、6ヶ月定期(草津まで)+ 差額精算を経費規程の標準に**

3. **北部(彦根・長浜)は訪問日をまとめる**
   単独往復だと1日あたり5,000円超。月4日→2日に集約すれば約1万円の削減。
   ただし宿泊を挟むと宿泊費で相殺されるため、日帰りでの集約が前提。

4. **提供予定エリア(甲賀・野洲・東近江)開通時の増加を織り込む**
   担当店舗が14→17に増え、交通費は **月 +1.5万円程度** を見込む。

### 確認が必要な事項(代表判断・要確認)
- 交通費の支給方式(実費精算 / 定期支給 / 日当込み)
- 営業車(社用車)の配備有無 — 配備するなら案Cのコストは会社持ち、代わりに訪問効率が上がる
- 対象店舗リストの確定(ソフトバンク公式店舗検索での実数確認)
- 光10G提供エリアの最新状況(NTT西日本エリア判定ツール)
