# アプローチ文面ドラフト（営業）

> **ドラフト（社内たたき台）。送信・提出は対外行為のため竹村代表の承認後に実行。**
> 本書に収録した文面は**すべて未送信のドラフト**です。実在企業への送信・連絡は一切行っていません。
> 送信可否・宛先・文面の最終判断は竹村代表が行います。

## 0. 使う前に必ず読むこと

### 0-1. 絶対に守るルール

1. **送らない。** この文書はドラフト置き場です。実際の送信は代表承認後、代表の指示に従って行います。
2. **HPに書かれていない実績・保険・数字を書かない。** 使ってよい事実は §0-2 の範囲のみ。
   「〇〇件の実績」「来場者数〇〇名増」「満足度〇%」といった**数字は一切創作しない**。
3. **価格をコミットしない。** 文面に金額を入れる場合は必ず「機材レンタル費用（税別）」「運営スタッフ費・配送費は別途」と併記する。
   値引き・特別価格の提示は**代表承認なしに書かない**。
4. **押し売りにしない。** CTAは必ず「**資料だけでもお送りします**」「日程未定でも構いません」の温度で止める。
5. **卸値の数字は書かない。**（`01-target-segments.md` §5-5 の代表判断待ち）

```

④ 軽いCTA          … 「資料だけでも」「日程未定でも」。返事のハードルを最小に
```
