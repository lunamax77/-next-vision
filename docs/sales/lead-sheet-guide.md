# リード台帳 入力ガイド

> `lead-sheet-template.csv` をGoogleスプレッドシートにインポートして使う。
> サンプル行は**架空データ**なので、運用開始時に削除する。
> フォームからの自動記録（`site/contact.php` → GAS）が埋める列と、代表が一次返信時に入力する列を分けている（下記「1-1. PHPからの受信項目と列の対応」）。

## 1-1. PHPからの受信項目と列の対応（GAS側の書き込み仕様として、プロダクト担当に依頼）

`site/contact.php` がGASへPOSTするJSONを、台帳の列にこう入れてほしい。それ以外の列は空欄（ステータスは `新規`、ステップメール進捗は `未送信` を初期値に）。

| PHPのキー | 台帳の列 | 備考 |
|---|---|---|
| datetime | 受付日時 | `YYYY-MM-DD HH:MM` に整形 |
| （固定値）`フォーム` | 流入経路 | |
| company | 会社名 | |
| name | 担当者名 | |
| email | メール | |
| content | 希望商材 | |
| purpose / plan / message | 担当メモ | `【ご用件】…／【プラン】…／【本文】…` の形で1セルに結合。開催予定日や会場はここから代表が「希望時期」「会場・エリア」に転記する |
| autoreply_sent | 自動返信済み | true→`済`、false→`未` |
| referer / ip / ua | （台帳には入れない） | 必要なら別シート「受信ログ」に保存 |

## 1. 列の定義と入力ルール

| 列 | 入力ルール | 入力者 |
|---|---|---|
| 受付日時 | `YYYY-MM-DD HH:MM`。フォームは自動。LINE・電話は受けた日時を手入力 | 自動／代表 |
| 流入経路 | `フォーム` / `LINE` / `電話` / `紹介` / `その他` から選択（データの入力規則でプルダウン化） | 自動／代表 |
| 会社名 | 会社名または施設名。フォームの「会社名・施設名」をそのまま | 自動 |
| 担当者名 | 姓 名（スペース区切り）。敬称なし | 自動 |
| メール | LINE経由で未取得なら空欄のまま。見積時に取得したら追記 | 自動／代表 |
| 電話 | ハイフンあり。現行フォームに電話欄がないため、聞けた時点で追記 | 代表 |
| 業種 | `商業施設` / `家電量販店` / `携帯キャリア` / `住宅展示場` / `カーディーラー` / `自治体・学校` / `イベント会社` / `その他` から選択 | 代表 |
| 希望商材 | フォームの「ご希望の体験」をそのまま。複数は `／` 区切り（例：`キッズライセンスパーク／エア遊具`） | 自動／代表 |
| 希望時期 | 自由記述だが月を必ず入れる（例：`2026年11月の土日`、`未定`） | 代表 |
| 会場・エリア | `都道府県／会場の種類と広さ`（例：`大阪府／館内イベントスペース約60㎡`、`未定`）。送料概算とレイアウト判断に使う | 代表 |
| 温度感 | `A`（今すぐ客）/ `B`（検討中）/ `C`（情報収集）。判定基準は `followup-flow.md` 第4章。最新の判断で上書きしてよい | 代表 |
| ステータス | 下記「2. ステータスの定義」の値のみ。プルダウン化する | 代表 |
| 次回アクション日 | `YYYY-MM-DD`。**空欄にしない**（受注・失注・休眠の場合のみ空欄可）。アクションを終えたら必ず次の日付に更新する | 代表 |
| 担当メモ | 日付＋要点を追記型で。例：`09/07 一次返信済。図面待ち` `09/10 図面受領、配置案送付`。値引きや特別条件を口頭で話した場合は必ずここに残す | 代表 |
| 自動返信済み | `済` / `未`。フォームは自動で `済`。LINEはあいさつメッセージが出るので `済`、電話は `未`（確認メールを送ったら `済`） | 自動／代表 |
| ステップメール進捗 | `未送信` / `①送信済` / `②送信済` / `③送信済` / `停止`。相手から返信があった・見積を出した・受注／失注になったら `停止` にする（自動送信の停止条件） | 自動／代表 |

## 2. ステータスの定義

| ステータス | 意味 | 入る条件 | 出る条件 |
|---|---|---|---|
| 新規 | 受付済み・代表未対応 | 台帳に行が追加された | 代表が一次返信を送った |
| 対応中 | 一次返信済み・ヒアリング中 | 一次返信を送った | 見積を送った／失注が確定した／30日以上反応がない |
| 見積提出 | 見積を送って返答待ち | 見積（概算含む）を送った | 受注・失注が確定した |
| 受注 | 日程確定・契約または発注確定 | 開催日と内容が確定し、契約書または発注書を取り交わした | （開催後は「既存顧客」として残す。次回アクション日に翌年同時期−2か月を入れる） |
| 失注 | 今回は見送り | 相手から見送りの連絡があった／見積提出から30日以上反応がない | 半年後に1回だけ再アプローチし、反応がなければそのまま |
| 休眠 | 情報収集のまま反応なし | C客で一次返信＋ステップメール③＋30日後フォローに反応がない | 相手から連絡があれば「対応中」に戻す |

失注時は担当メモに理由を1行入れる（`予算` / `日程合わず` / `他社` / `企画中止` / `反応なし` / `その他`）。`proposals.md` の改善に使う。

## 3. 条件付き書式の設定手順（次回アクション日が今日以前で未完了の行を赤くする）

台帳シートで、データ範囲全体（例：`A2:P1000`）を選択し、メニューの「表示形式」→「条件付き書式」を開く。「セルの書式設定の条件」で「カスタム数式」を選び、数式に `=AND($M2<>"", $M2<=TODAY(), NOT(OR($L2="受注", $L2="失注", $L2="休眠")))` を入力する（M列＝次回アクション日、L列＝ステータス。列がずれている場合は読み替える）。書式は背景色を薄い赤にして「完了」を押す。同じ手順でもう1つルールを追加し、数式を `=AND($L2="新規", NOW()-$A2>0.5)` にして背景を薄い黄色にすると、新規のまま12時間以上経った行（一次返信の期限が近い行）も目立つ。あわせて、「データ」→「フィルタを作成」で次回アクション日の昇順に並べ替えると、毎朝やることが上から順に並ぶ。
