## 1. 現状のマーケティング課題

### 1-1. 人手(リソース)のボトルネック
- マーケ専任が置けず、**イベント運営と兼務**で片手間対応になっている(現状の体制・工数は【要記入】)。
- 企画・撮影・投稿・広告設定・問い合わせ対応まで少人数で回すため、**繁忙期(週末・長期休暇・イベント本番)に発信が止まる**。
- 属人化しており、担当が動けないと更新・返信が滞る。

### 1-2. 更新頻度・コンテンツ供給のボトルネック
- SNS(【対象チャネル=要記入: Instagram / TikTok / LINE 等】)の投稿が不定期で、**アルゴリズム的に露出が伸びにくい**。
- イベント写真・動画は大量にあるが、**編集・キャプション化が追いつかず在庫化**している。
- BtoB向け(施設集客の実績訴求)とBtoC向け(親子の来場動機)で**訴求の作り分けができていない**。

### 1-3. 広告運用のボトルネック
- 広告文・クリエイティブの**ABテストを回す工数がなく、勘・単発**になりがち。
- 予算配分・停止判断の根拠となる**数値の集計/振り返りが手作業**で、改善サイクルが遅い。
- 流入後の**問い合わせ導線(サイト→フォーム/LINE→受注)**が最適化されておらず、流入が取りこぼれている可能性(現状CVRは【要記入】)。

> ※上記の頻度・工数・現状数値は社内実測に基づく確定値ではない項目を含むため、計画書提出前に**要・実績確認**。

## 2. AI活用で効率化・強化する内容

| 領域 | AIで何をするか | 効果(何が変わるか) |
|---|---|---|
| ① 投稿生成 | イベント写真/動画・実績メモから、SNS投稿文・ハッシュタグ・短尺台本を**下書き自動生成**(BtoB/BtoC出し分け) | 更新頻度の安定化、在庫写真の資産化、制作工数削減 |
| ② 広告文ABテスト | 広告見出し・本文の**複数パターン案出し**と、結果に基づく勝ちパターンの言語化 | テスト本数増、当たりクリエイティブの早期発見 |
| ③ 問い合わせ導線最適化 | LP/フォーム/LINE導線の文言・CTA改善案、**FAQ自動応答の下書き**、初回反応テンプレ生成 | CVR改善、一次対応の高速化・取りこぼし減 |
| ④ 分析・レポート | 各指標の**週次集計・振り返りコメントの自動化**、次アクション提案 | 改善サイクルの高速化、意思決定の材料整備 |
| ⑤ 企画・カレンダー | 季節・商業施設イベント暦に沿った**投稿/キャンペーン企画のたたき台** | 計画的発信、繁忙期の事前仕込み |

**運用原則**: AIは**下書き・提案・集計まで**を担い、公開・広告出稿・顧客への送信など**対外行為は必ず人が最終承認**してから実行する(社内ルール準拠)。

## 3. KPI設計(認知 → 問合せ → 受注のファネル)

### 3-1. ファネル構造と指標

```
[認知]      SNS投稿数 / インプレッション / エンゲージメント(いいね・保存・シェア)
   │
   ▼
[興味・流入]  サイト流入(セッション) / プロフィール遷移 / LINE友だち追加
   │
   ▼
[問合せ]     問い合わせ数(フォーム+LINE+電話) / 資料DL
   │
   ▼
[受注]       受注件数(受注CV) / 受注金額 / 平均単価
```

### 3-2. KPI一覧(目標値はプレースホルダ)

| 段階 | 指標 | 現状(基準値) | 目標(補助期間後) | 補足 |
|---|---|---|---|---|
| 認知 | 月間投稿数 | 【要記入】 | 【要記入】 | 発信の安定化を測る先行指標 |
| 認知 | インプレッション/月 | 【要記入】 | 【要記入】 | リーチ規模 |
| 認知 | エンゲージメント率 | 【要記入】% | 【要記入】% | (反応数 ÷ リーチ) |
| 流入 | サイトセッション/月 | 【要記入】 | 【要記入】 | SNS→サイトの送客 |
| 流入 | LINE友だち追加/月 | 【要記入】 | 【要記入】 | BtoC再来促進の資産 |
| 問合せ | 問い合わせ数/月 | 【要記入】 | 【要記入】 | 全チャネル合算 |
| 問合せ | 流入→問合せCVR | 【要記入】% | 【要記入】% | (問合せ ÷ セッション) |
| 受注 | 受注件数/月 | 【要記入】 | 【要記入】 | 主要成果指標 |
| 受注 | 問合せ→受注CVR | 【要記入】% | 【要記入】% | 営業クロージング率 |
| 受注 | 平均受注単価 | 【要記入】円 | 【要記入】円 | BtoB/BtoC別に管理推奨 |
| 受注 | 月間受注金額 | 【要記入】円 | 【要記入】円 | 売上直結の最終KPI |

### 3-3. 目標値の算定の考え方(埋め方の指針)

1. **基準値(現状)を先に確定する**: 直近3〜6か月の実測平均を各指標の分母に置く(SNS管理画面・GA・問い合わせ台帳から集計)。**要・実績確認**。
2. **ファネルは掛け算で積み上げる**:
   `受注件数 = セッション数 × (流入→問合せCVR) × (問合せ→受注CVR)`
   のように、上流指標の改善が下流にどう波及するかを式で明示する。
3. **改善レバーごとに目標を分解する**:
   - 投稿頻度 ↑ → インプレッション・セッション ↑(AI①投稿生成の寄与)
   - 広告ABテスト → CVR・CPA改善(AI②の寄与)
   - 導線最適化 → 流入→問合せCVR ↑(AI③の寄与)
4. **控えめ・標準・強気の3シナリオ**で目標レンジを置き、計画書には標準シナリオを採用(根拠を注記)。
5. **達成度は月次でトラッキング**し、未達時の見直しサイクル(週次レビュー)を運用に組み込む。

> 例(数式の型のみ・数値は仮置き):現状セッション A/月、流入→問合せ p1、問合せ→受注 p2 のとき、
> 受注 = A × p1 × p2。AI導入で A→A′、p1→p1′、p2→p2′ に改善する前提で目標受注を算定する。**具体値は【要記入】**。

## 4. 集客・受注の増加が「労働生産性・売上」に効くロジック

補助金の**生産性向上目標**に接続するための因果構造を明示する。

### 4-1. ロジックツリー

```
AIマーケ/SNS運用支援の導入
   │
   ├─(A)制作・運用工数の削減 ─────────────┐
   │    投稿下書き自動化・レポート自動化で              │
   │    1件あたり制作時間↓、繁忙期も発信継続          │
   │                                                     ▼
   ├─(B)発信量・質の向上 → 認知↑ → 流入↑ → 問合せ↑ → 受注↑ → 売上↑
   │                                                     ▲
   └─(C)広告/導線の最適化 → CVR↑・CPA↓ ──────────┘
        同じ工数・予算でより多く受注
```

### 4-2. 労働生産性への効き方

- **労働生産性(付加価値 ÷ 労働投入)の分子・分母の両面**に効く:
  - **分母(労働投入)を圧縮**: 投稿・レポート・一次対応の下書きをAI化し、同じ人員でこなせる業務量を増やす → 兼務の負荷を下げ、企画・現場対応など**付加価値の高い業務へ人手を再配分**。
  - **分子(付加価値=売上・粗利)を拡大**: 認知〜受注のファネル改善で受注件数・受注金額を増やす。
- 定量化の型(**要・実績確認**の上で計画書に記載):
  - 生産性 = 付加価値額 ÷ 労働投入(人・時間)
  - `削減工数 = (AI導入前の1件あたり制作時間 − 導入後) × 月間制作件数`
  - `増加付加価値 = 増加受注件数 × 平均受注単価 × 粗利率`
  - 上記を補助金様式の生産性向上率の計算式に接続(**補助金の定義・様式は要・公式確認**)。

### 4-3. 売上インパクトの示し方
- **売上増**: 追加受注件数 × 平均単価(BtoB/BtoC別に積算)。
- **コスト効率**: 広告CPA低減 × 出稿件数で獲得効率の改善額を提示。
- **持続性**: LINE友だち・SNSフォロワー等の**再来・リピートを生む資産**が蓄積し、補助期間後も効果が継続することを明記。
