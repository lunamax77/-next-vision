## 0. 結論(サマリ)

- 「AI補助金」として、まず狙うべきは **デジタル化・AI導入補助金2026**(旧・IT導入補助金 / 中小企業庁・中小機構)。
  AI搭載ソフト/クラウドの導入に最大 **450万円・補助率1/2〜4/5** が出る、最も本命の枠。
- DreamCreation は **中小企業・小規模事業者に該当**し、対象者要件は満たす見込み(適合性は §4)。
- ただし本制度は **①GビズIDプライム ②SECURITY ACTION宣言 ③登録IT導入支援事業者・登録ITツール経由**
  が前提で、"何のAIでも自由に申請"はできない。ここが実現可否を左右する。
- **時間が最大のリスク**: 2026年度は締切が絞られ、**最終締切は8/25 17:00 とされる(要・公式確認)**。
  GビズIDプライム取得に約2週間、SECURITY ACTIONに約1週間かかるため、
  **未取得なら今年度・最終回に間に合わない可能性が高い**。→ 代表確認事項(§8-Q2)。

## 2. デジタル化・AI導入補助金2026 の概要(本命)

- **実施**: 中小企業庁 / 独立行政法人 中小企業基盤整備機構(中小機構, SMRJ)
- **公式ポータル**: https://it-shien.smrj.go.jp/
- **目的**: 中小企業・小規模事業者の労働生産性向上のため、AIを含むITツール導入を支援。
- **補助上限 / 補助率**: 最大 **450万円** / **1/2〜4/5**。
- **主な申請枠(要・公式確認)**:
  - **通常枠**: 会計・受発注・在庫・勤怠等の業務デジタル化。プロセス数で階段
    (概ね 1〜3プロセス=5万〜150万未満、4プロセス以上=150万〜450万、補助率1/2)。
  - **インボイス枠**: インボイス対応の会計・受発注・決済ツール。**補助率 最大4/5**(最優遇)。
  - **セキュリティ対策推進枠**: サイバーセキュリティ対策。
  - (複数社連携・AI活用系の枠が別途ある場合あり=要確認)
- **対象経費(要・公式確認)**: 登録ITツールのソフトウェア費用、クラウド利用料(一定期間分)、
  導入関連費(設定・研修等)。ハード(PC/タブレット/レジ等)は枠により対象/対象外が分かれる。

## 3. なぜ DreamCreation で使えるか(想定ユースケース)

DreamCreation(キッズイベント遊具レンタル・運営代行、NextVisionブランド)で相性の良いAI導入候補:

1. **予約・問合せ自動対応AI(チャットボット)** — HP/LINEからのレンタル問合せ・見積依頼を自動一次対応。
2. **AI見積・請求の自動化** — 既存の見積/請求ジェネレーター(`tools/invoicing`)をAI-OCR/自動化で強化。
3. **案件・在庫(遊具)管理 + 需要予測AI** — `tools/pipeline` の案件管理を予測付きにし、稼働率を最適化。
4. **AIマーケ / SNS運用支援** — 集客コンテンツ・広告文の生成支援。
5. **AI-OCR / バックオフィス自動化** — 紙書類・領収書の読取り、経理入力の省力化。

→ どれを主目的にするかで **申請枠・登録ITツール・事業計画**が変わる。→ 代表確認事項(§8-Q3)。

## 6. スケジュールと注意 ⚠️

- 2026年度は締切回数が絞られ(4次締切制との情報)、**最終締切は 8/25 17:00 とされる(要・公式確認)**。
- **本日 2026-08-06 時点で、GビズID/SECURITY ACTION が未取得の場合、今年度・最終回への間に合いは非常に厳しい。**
- 選択肢:
  - (A) 事前準備が既に済んでいる → 最終回に向け全力で書類作成。
  - (B) 未準備 → まず GビズID/SECURITY ACTION の取得に着手し、**次年度(または次回公募)を本命**に据える。
    その間に書類は"提出できる状態"まで完成させておく(=今回のゴールと両立)。
- いずれにせよ **書類のドラフト作成は今すぐ進められる**(L0)。
