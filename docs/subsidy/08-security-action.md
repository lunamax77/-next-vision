### 株式会社Dream Creation 情報セキュリティ基本方針(案)

**1. 基本的な考え方**
株式会社Dream Creation(以下「当社」)は、人材派遣・イベント運営および遊具レンタル(NextVision)事業を通じて、取引先・従業員・派遣スタッフ・お客様の情報をお預かりしています。当社は、これらの情報資産を様々な脅威から守ることを社会的責務と認識し、情報セキュリティの確保に組織的に取り組みます。

**2. 適用範囲**
当社の全役員・従業員および業務に関わる派遣スタッフ・協力先、当社が取り扱うすべての情報資産(顧客・取引先情報、派遣スタッフの個人情報、契約・請求情報等)を対象とします。

**3. 取り組み**
- 情報セキュリティに関する社内ルールを定め、全員で遵守します。
- 「情報セキュリティ6か条」(OS・ソフトの更新、ウイルス対策、パスワード強化、共有設定の見直し、脅威・手口の把握、バックアップの取得)を継続的に実践します。
- 個人情報を含む情報資産を適切に管理し、業務目的の範囲でのみ取り扱います。
- 万一の情報セキュリティ事故に備え、報告・対応の体制を整えます。
- 従業員・関係者への教育・注意喚起を定期的に行います。
- 法令・規範を遵守し、本方針を継続的に見直し・改善します。

**4. 責任者**
本方針の実施責任者は代表取締役 竹村 英哲とします。
