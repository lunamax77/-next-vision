## いまの状態(サマリ)

- ✅ 制度の特定(デジタル化・AI導入補助金2026)、要件・手続き・スケジュールの整理
- ✅ 会社の実データ反映(令和8年5月期 売上 約4.25億円 ほか、Drive決算書より)
- ✅ 事業計画・費用効果・技術・KPI・手続きのドラフト一式
- 🔴 **代表判断待ち**: ①事業軸(人材派遣/遊具レンタル/両建て) ②申請枠・補助率(通常枠1/2 基本線) ③狙う締切(8/25/次回) ④登録IT導入支援事業者(パートナー)
- 🟡 **確認待ち**: 従業員数(小規模判定)、登記の事業目的、SECURITY ACTION宣言、公式公募要領の最終確認

## 次の一歩(代表の承認・判断が必要なもの)

1. 上記🔴の4点を確定 → ドラフトを主力事業に寄せて仕上げ、🟡を埋める。
2. SECURITY ACTION ★宣言に着手(約1週間 / 対外登録=代表承認)。
3. 登録IT導入支援事業者・登録ITツールを選定(打診=代表承認)。
4. 交付申請の提出は**交付決定前の発注厳禁**・**代表承認必須**。
