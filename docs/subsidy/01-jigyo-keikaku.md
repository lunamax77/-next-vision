## 2. 経営課題(現状)

当社はキッズイベントの遊具レンタルと運営代行を、少人数体制で運営している。事業拡大に伴い、**バックオフィスと集客が属人的・手作業**であることが成長の制約になっている。

1. **見積・請求・経理の手作業**: 見積/請求は自動生成の仕組みがあるものの、案件情報や証憑(領収書・発注書)の入力は人手で、転記ミスや処理遅延のリスクがある。
2. **遊具(在庫)と案件の管理**: 遊具単位の稼働カレンダーがなく、繁忙期のダブルブッキングや機材不足、閑散期の遊休を機械的に防げていない。需要予測もしていない。
3. **集客(マーケ)の属人化**: SNS・広告の制作が兼務・不定期で、繁忙期に発信が止まる。写真素材が活かしきれていない。

→ いずれも**「少人数のまま処理量と稼働率・集客力を上げる」**ことが必要で、AI/ITツールの導入が有効。

## 3. 本事業の内容(導入するAI/ITツール)

労働生産性の向上を目的に、以下の3本のAI/ITツール(登録ITツール/SaaSを核とし、既存の社内ツールと連携)を導入する。技術詳細は `03-ai-tools.md`。

| # | 導入AI | 解決する課題 | 想定される業務プロセス |
| --- | --- | --- | --- |
| ① | **AI見積・請求の自動化**(AI-OCR+請求/受発注SaaS) | 課題1 | 証憑デジタル化 / 見積作成 / 請求・売上計上 |
| ② | **需要予測・案件/遊具在庫管理AI**(予約・在庫SaaS+需要予測) | 課題2 | 在庫(遊具)管理 / 受発注・予約 / 需要予測・分析 |
| ③ | **AIマーケ/SNS運用支援**(生成AI+SNS運用SaaS) | 課題3 | 販促・顧客対応のデジタル化 |

- 既存の社内ツール(`tools/invoicing` 見積・請求ジェネレーター、`tools/pipeline` 案件管理、`site` コーポレートサイト)を**登録ITツールの入出力の受け皿**として活かし、二重投資を避ける。
- **枠の方針(要・公式確認 / 要・パートナー相談)**: ①はインボイス対応SaaSなら**インボイス枠(補助率最優遇)**の可能性。②③は**通常枠**。①②でプロセス数を積み上げると上位の補助額帯に届き得る。

## 4. 導入効果(定量・定性)

詳細な試算は `02-cost-benefit.md`(財務)/ `04-marketing-sns.md`(マーケ)。

### 4-1. 定量(工数削減の見込み・前提付き)

| 施策 | 削減見込 | 年間人件費換算(@1,500円想定) |

| ① 見積・請求自動化 | 約10.7時間/月 | 約19.3万円/年 |
| ② 需要予測・在庫管理 | 約12.0時間/月 | 約21.6万円/年 |

※件数・工数は前提値。現状実測(【要記入】)で精緻化する。加えて、**稼働率改善・失注減による売上増**が主効果(下記4-2)。

### 4-2. 定性・機会創出

- 見積スピード向上 → 成約率改善・失注減。

- 集客の内製化・持続 → 繁忙期前の先行集客、閑散期の販促。
- 空いた工数を**現場対応・企画など付加価値の高い業務へ再配分**。

- 基準年度の付加価値額は**前期比で減少(5,980万→4,986万)し、営業損益は営業損失**。生産性向上目標は「AI導入で反転・向上」の筋で組む。
- 付加価値の定義(営業利益/人件費/減価償却費の扱い、外注人件費を含むか)と目標水準(例: 3〜5年で年平均+一定%)は**要・公式確認**。

## 9. 事業の継続性・発展性

- 導入するAI/SaaSは既存業務フロー(見積・請求・案件・集客)に直結し、**補助期間後も継続利用**する前提。
