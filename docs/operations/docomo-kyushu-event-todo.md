## 2. イベントごとの定常タスク(実施前 → 実施中 → 実施後)

### 実施前

| 期限 | やること | 担当(案) |
|---|---|---|
| イベント3〜4週前(日程調整期間) | 代理店との事前MTG日程を調整 | 営業 |
| **イベント当日の4日前まで** | 代理店事前MTGを実施(原則Web)。調整時 or 日程確定後、ルート担当をCCに入れてメール送付。電話の場合は連絡日/担当者名/内容をメール(ロケハンシート送付のみでも可) | 営業 |
| **イベント実施週の水曜日まで** | ロケハンシートを作成し、指定格納先に報告。事前MTGはロケハンシートに沿って実施 | 営業 |
| **14日前まで**(イオンモール系列) | 中規模以上の集客コンテンツ(バルーン、ワークショップ等)を入れる場合、新通エスピーへメールで事前申請(簡易企画書 + レイアウト)。告知物(HP用1,040×1,040 JPG / A1ポスター / 紹介文)は任意 | プロダクト |
| **1週間前頃まで**(イオンモール以外) | 同上。原則代理店から申請するため、事前に代理店へ情報連携 | プロダクト |
| 事前(申請期日に準ずる) | 調理を伴う飲食コンテンツ(綿あめ、ポップコーン等)は保健所への申請・検査が必要。不備があればイベント実施不可 | プロダクト |
| 都度(支社から連絡) | 見積書・実施責任者通知書・再委託先承諾願(再委託がある場合)を提出 | 財務 |

### 実施中

| 期限 | やること | 担当(案) |
|---|---|---|
| イベント開始時 | 開始連絡 + ツール・POP・コンテンツ写真を +メッセージグループに送信 | 営業(現場) |
| **毎日** | 実績報告の「PI実績」を入力 | 営業(現場) |
| **毎日** | 定性情報報告の「毎日入力」欄を入力 | 営業(現場) |
| **毎日**(PO超過施設のみ) | 上記に加え「声掛け数」「着座数」を入力 | 営業(現場) |
| **当日中(遅くとも翌日9時まで)**(PO超過施設のうち土日報告対象) | 実績・定性情報を本社向けに報告。対象会場は毎週金曜までに +メッセージで通知される | 営業(現場) |

### 実施後

| 期限 | やること | 担当(案) |
|---|---|---|
| **イベント最終日の翌日10時まで** | 実績報告の全項目を入力 | 営業 |
| **イベント最終日の翌日10時まで** | 定性情報報告の全項目を入力 | 営業 |
| 翌週火曜の定例MTG | 目標未達の場合、振り返り(取り組み・未達原因・改善策)を報告 | 営業 |
| **翌月1日まで** | 請求書・作業完了報告書を提出 | 財務 |

## 4. ご指摘発生時の対応(発生したら即日)

| タイミング | やること |
|---|---|
| 発生時 | 責任者(ディレクター)が対応・お詫び。全スタッフにインカム等で共有 |
| 当日中 | 施設担当者へ報告・お詫び(施設経由の指摘でも、終了後当日中に改めてお詫び) |
| 当日中 | 九州支社へ +メッセージで報告(発生事象 / お客様対応状況 / 施設対応状況) |
| 当日中 | 新通エスピーへメールで報告(発生事象 / 発生要因 / 事実確認結果 / 対応状況) |
| 緊急時 | 電話。九州支社: 名郷・髙平 → 永田 → 武内 / 新通エスピー: 成清 → 赤尾 |

## 5. 常時順守事項(ガイドライン要点・期限なし)

- **身だしなみ**: 清潔な服装、名札着用、派手な髪色・アクセサリー・強い香水NG
- **勤務態度**: 腕組み・腰に手・歩きスマホ・立ったままの水分補給NG。お断り時も御礼とお見送り
- **特商法**: 勧誘目的を隠さない、お断り後の再勧誘禁止、進行方向に出る・手を振る・同一客への複数回声掛け禁止
- **ハウスルール**: リースライン内のみ声掛け(テープで明示)、通路動線確保、指定駐車場・搬入口・時間の順守
- **施設対応**: 施設担当者・他テナントスタッフへ挨拶。施設巡回時はディレクターが対応
- **顧客情報**: イベントスタッフによる保持・保管は絶対NG(代理店管理)。ID/PW取得NG、勝手な端末操作NG
- **私物端末**: 業務中の携帯・使用禁止。責任者が回収し金庫等で一括管理(休憩時のみ可)
- **搬入**: 車両搬入は運転要員 + 運搬要員の2名以上。搬入口に車両放置NG
- **整理整頓**: 備品を区画外に放置しない。設営・終了時はパーテーションで囲う
- **配布物**: お菓子等は賞味期限に注意
