# SEOキーワード調査（NextVision コンテンツSEO）

> 社内ドラフト（マーケティング担当AI作成）。外部の検索ボリュームツールは未使用のため、
> 「難易度」「優先度」はHPの内容と業界知識にもとづく**体感値**です。
> 公開後は Google Search Console の実クエリで毎月上書きしていきます。

## 0. 前提と考え方

- HPは5ページ・約1万字。技術SEO（title / description / OGP / 構造化データ / sitemap）は整備済み。
  不足しているのは「検索の面」＝担当者が悩みを検索したときに引っかかるページです。
- 主語は **商業施設・店舗の販促/集客担当者**（toB）。保護者（toC）向けの「子供 遊び場 大阪」等は
  当社が売る相手ではないため、意図的に外します。
- キーワードは2軸で分類します。
  - **今すぐ客**: 「レンタルしたい／業者を探している」＝商材ページ（klp / punilab / seal / air）で受ける
  - **これから客**: 「集客に悩んでいる／アイデアを探している」＝記事で受けて、商材ページへ誘導する
- ブランド語「こども免許証」「キッズライセンスパーク」は競合が少ないぶん検索数も少ない見込み。
  一般語（運転体験・キッズカー）とセットで狙います。

## 2. 優先順位（最初の3か月で狙う順）

1. **記事で取りに行く「これから客」の★〜★★語**（B3, B8, B10, B12, B15, B16, B19, B20）
   競合が弱く、当社の商材と悩みが直結するため、少ない記事数でも上位が狙えます。
2. **ブランド語＋一般語の複合**（A6〜A10）
   「こども免許証」「スクイーズ ワークショップ 出張」は現時点でほぼ競合不在の見込み。商材ページの本文を少し厚くするだけでも効果が期待できます。
3. **★★★の大語**（A3, A14, B1, B2）
   すぐには取れない前提で、記事を積み上げてから狙います。Googleビジネスプロフィールと「大阪」の地域語を組み合わせて足場を作ります。

## 3. 記事に共通で入れる「検索意図に答える要素」

Googleのスパムポリシー（大量生成・低品質コンテンツ）に抵触しないよう、記事は必ず次の要素を含めます。

- 担当者が実際に判断できる**具体的な数字**（スペース、所要時間、電源の要否、当社の料金）
- **当社の一次情報**（条件早見表・FAQ・運営フローなど、HPに書いてある事実）
- 断定できない効果は「〜が期待できます」に留める。実績数・顧客名・効果の数値は捏造しない
- 取引先の社名は非掲載。業種（家電量販店・商業施設・携帯キャリアなど）までにとどめる
- お子様の顔写真は使わない。イラスト・機材・完成品の写真を使う

## 4. 効果測定（公開後）

- Search Console: 記事ごとの表示回数・クリック・平均掲載順位を月1回記録
- 目標KPIは順位ではなく **記事経由の問い合わせ数**（フォーム送信・電話・LINE）
- 3か月後にこの表を実クエリで更新し、取れそうな語に記事を寄せる
