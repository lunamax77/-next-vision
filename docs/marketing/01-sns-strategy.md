# SNS・広報 戦略ドラフト（NextVision）

> ドラフト（社内たたき台）。実際のアカウント開設・投稿・公開は**対外行為**のため、
> 竹村代表の承認を得てから実行する。

## 1. 目的と位置づけ

- HPは「Instagram準備中」。SNSはHPへの**信頼補強と集客の入口**に置く。
- 2つの読み手を意識する：
  - **BtoB（主役）**：商業施設・店舗・企業の販促/集客担当。「安心して任せられる運営代行」を訴求。
  - **BtoC（副次）**：来場するご家族。イベントの楽しさ＝施設側が「呼びたくなる」実績づくり。

## 2. 使うSNS（優先順）

| 媒体 | 役割 | 優先 |
| --- | --- | --- |
| **Instagram** | 実績写真・動画のショーケース。施設担当者が雰囲気を掴む入口 | ◎ 最優先 |
| **TikTok / Reels** | こども免許証発行やエア遊具の short 動画で拡散 | ○ 二段目 |
| **Googleビジネスプロフィール** | 「大阪 イベント 遊具 レンタル」等のローカル検索対策（SEOとも連動） | ◎ 公開後すぐ |
| Facebook / X | BtoBの告知・拡散の補助 | △ 余力があれば |

## 4. コンテンツの柱（投稿テーマ）

1. **こども免許証**（運転体験）＝一番の“映え”＆象徴コンテンツ
2. **ワークショップ**（スクイーズ／シールデコ）＝制作の手元・完成品
3. **エア遊具**（エアリズム／カーニバル）＝賑わいの引き
4. **運営代行の裏側**（設営〜撤収、安全管理）＝BtoB信頼づくり
5. **開催実績・お客様の声**＝施設名は許可を得て掲載
6. **中の人/豆知識**（安全へのこだわり、対応エリア 等）

## 5. 運用の目安

- 投稿頻度：**週2〜3回**（無理なく継続できるペース）
- フォーマット：フィード（実績）＋リール（動画）＋ストーリーズ（開催告知・裏側）
- 1投稿の型：**1枚目でフック → 中身の写真 → 最後にCTA（相談・見積の導線）**
- ハッシュタグ（BtoB寄せ）：
  `#イベント企画 #集客イベント #商業施設 #販促 #キッズイベント #ファミリー集客 #エア遊具 #ワークショップ #こども免許証 #大阪イベント`

## 6. KPI（最初の3か月・仮）

- フォロワー数より **プロフィールのリンククリック / DM問合せ数** を重視
- 月次で「投稿数・保存数・プロフィールアクセス・HP流入・問合せ件数」を記録（案件管理表と接続）

## 7. 進め方（承認フロー）

1. アカウント名・@・プロフィールを代表が承認
2. 初期投稿9本（launch）のドラフトを承認（`02-launch-posts.md`）
3. 承認後にアカウント開設・投稿（＝対外行為）
