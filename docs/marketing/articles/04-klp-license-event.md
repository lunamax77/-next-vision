# こども免許証がもらえる運転体験とは｜仕組みと会場条件

「こども免許証がもらえる運転体験」は、EVカーでコースを周回し、顔写真入りの免許証をその場で受け取れる体験型のイベントです。NextVisionでは「キッズライセンスパーク」として、商業施設や店舗の店頭向けに提供しています。この記事では、販促担当者の方が企画前に知っておきたい仕組み、会場条件、料金の考え方、安全面をまとめます。

## どんな体験なのか

お子さまが本格的なEVカーを運転し、コースを約3周します。体験の最後に、顔写真入りの「こども免許証」がその場で発行され、そのまま持ち帰れます。

[figure: license.jpg|こども免許証の見本 :: 顔写真入りの免許証を持ち帰れます]

車両はスポーツカーやポリスカーなど7車種から、会場やご希望に合わせて選べます（車種は在庫状況により変わる場合があります）。

1組あたりの流れは次のとおりです。所要はおよそ8〜12分です。

1. 受付・撮影（タブレットで顔写真を撮影）
2. 運転体験（コースを約3周）
3. 免許証発行（即時発行・約5分）
4. 記念撮影（フォトスポットで）
5. 保護者さまと商談・案内の時間へ

対象は3〜8歳で、会場により調整します。

## イベントとして強い3つの理由

この体験が集客の看板になりやすい理由は、次の3点です。

**視認性。** キッズカーの展示とゲートがあることで、「何のイベントか」が一目で伝わります。通行するお客さまの足を止めるきっかけになることが期待できます。

**記念性。** 顔写真入りの免許証は「参加した証」として手元に残ります。持ち帰れる成果物があることで、満足度の高い体験になりやすい点が特長です。

**撮影価値。** 免許証とキッズカーを一緒に撮った写真は、SNSで共有されやすい絵づくりになります。ご家族の自然な投稿によって、来場の呼びかけやブランドの露出が期待できます。

運転体験の実施中は、保護者さまが見守る時間が生まれます。滞在時間が伸びることも期待できます（会場条件や動線によって変わります）。体験のあとを商談や案内の時間につなげる動線を、あらかじめ設計しておくと活用しやすくなります。

## 会場条件の目安

「うちの会場でできるのか」は、最初に確認したいポイントです。以下はいずれも目安で、会場条件により変動します。

| 項目 | 目安 |
|---|---|
| 必要スペース | 10m × 8m（コース＋受付・発行ブースを含む） |
| 屋内外 | 屋内・屋外どちらも対応可能 |
| 電源 | 必要（免許証の発行機材、EVカーの充電に使用） |
| 推奨スタッフ | 2〜3名 |
| 所要時間 | 1組およそ8〜12分 |
| 対象年齢 | 3〜8歳（会場により調整） |

コース配置は会場の形状に合わせて調整します。図面をお送りいただければ、配置案をご提案します。電源は、ご用意いただける容量をお知らせいただければ、それに合わせた構成をご案内します。

スペースが限られる場合は、6畳程度から実施できる着座型のワークショップ（ぷにラボ、シールデコ）との組み合わせも検討できます。運転体験の前後に着座の体験を置くことで、待ち時間への対策にもなります。

## 料金の目安と運営体制

機材レンタル費用は、1日あたり次のとおりです（税別・機材レンタル費用）。

- スタンダード（車両2台・1コース）：90,000円
- プレミアム（車両3台・フルセット）：135,000円

いずれも税別で、運営スタッフ費と送料は別途です。配送料は実費でご請求します。複数日で開催する場合、キッズライセンスパークは2日目以降の機材費が50％になります（目安）。

運営の体制は2通りから選べます。

- **機材レンタル：** 必要な機材を一式で配送し、設営手順書と運営マニュアルを添付します。事前のオンライン説明にも対応します。当日の運営は貴社スタッフさまが担当します。
- **運営代行オプション：** 設営・装飾から受付・安全管理・撤収・原状回復まで、当社スタッフが担当します。運営代行は、必要人員数・開催時間・会場所在地により変動するため、個別のお見積りとなります。

当日いちばん足りなくなるのは機材ではなく人手になりがちです。貴社スタッフさまが接客や商談に専念したい場合は、運営代行をご検討ください。

## 企画するときの考え方

運転体験は「当日だけ盛り上がるイベント」で終わらせず、来店前から来店後までを一続きで設計すると活用しやすくなります。

来店前は、「こども免許証がもらえる」という分かりやすい特長を告知に使えます。免許証と車両を並べた写真は、チラシやSNS投稿でも一目で内容が伝わる素材になります。当日は、受付・撮影・運転・免許証発行・記念撮影と、お子さまが次々に動く流れになるため、保護者さまの待ち時間を商談や案内に充てる動線を決めておくことが大切です。

来店後は、持ち帰った免許証が思い出として残り、ご家族での再来訪のきっかけになることが期待できます。1日の中でも時間帯ごとの混雑が予想される場合は、ほかの体験コンテンツやエア遊具を併設して、待ち時間に過ごせる場所をつくる方法もあります。

## 安全面で確認しておきたいこと

お子さまが乗る体験だけに、安全面は企画段階で確認しておきたい項目です。

運転体験のコースには、常時スタッフが立ち会い、走行速度と車間を管理します。また、イベント運営に関する賠償責任保険に加入しており、証明書類の提出にも対応します。

なお、こども免許証のサイズは91×55mmです。実物の免許証（85.6×54mm）と意図的にサイズを変えています。

## まとめ

こども免許証がもらえる運転体験は、運転体験・免許証の発行・記念撮影が1組8〜12分にまとまった、来店のきっかけになる体験型イベントです。10m × 8mほどのスペースと電源があれば、屋内でも屋外でも検討できます。

まずは会場の広さと電源の条件を整理し、機材レンタルで運営するか、運営代行を任せるかを決めるところから始めてみてください。費用の内訳は[店頭キッズイベントの費用相場と内訳](https://nextvision.fun/blog/kids-event-cost.html)、滞在時間の考え方は[体験型イベントが滞在時間を伸ばす理由](https://nextvision.fun/blog/taiken-stay-time.html)もあわせてご覧ください。
