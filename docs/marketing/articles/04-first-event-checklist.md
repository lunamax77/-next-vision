# 初めてのキッズイベント開催チェックリスト｜会場・電源・安全

「キッズイベントをやることは決まったが、何から手をつければいいかわからない」。初めて担当になった方が最初にぶつかる壁は、企画の中身より「準備の抜け漏れ」です。当日になって電源が足りない、スペースに機材が入らない、人手が足りない。こうしたトラブルの多くは、1か月前の確認で防げます。

この記事では、店頭・商業施設でのキッズイベントを想定して、1か月前から当日までのタイムラインと、確認すべき項目をチェックリスト形式でまとめました。そのままコピーして、社内の準備メモとしてお使いください。

## 全体のタイムライン（目安）

業者に機材や運営を依頼する場合、一般的な流れは次のとおりです。当社では、開催の1か月前にご相談いただく形を目安にしています。

| 時期 | やること |
|---|---|
| 1か月前〜 | 問い合わせ（日程未定でも可）→ ヒアリング（会場図面・広さの確認） |
| 3〜4週間前 | 見積り（コンテンツの組み合わせ提案）→ 契約 |
| 2〜3週間前 | 動線・安全計画の確定、告知開始、電源・養生の手配 |
| 1週間前 | 運営体制の最終確認、スタッフ向け説明（機材のみの場合はマニュアル確認・オンライン説明） |
| 前日 or 当日早朝 | 搬入・設営 |
| 当日 | 開催 → 撤収・原状回復 |

土日・連休は機材の予約が集中しやすいため、日程が決まっていなくても早めに相談を始めるのがおすすめです。

## チェック1: スペース

最初に確認するのは、会場の広さと形です。コンテンツごとに必要なスペースが大きく違います。

- **運転体験（コース型）**: 10m×8m程度が目安。走行コースと受付・免許証発行ブースを含みます。会場の形状に合わせてコース配置を調整できるので、正方形でなくても相談可能です。屋内・屋外どちらも対応。
- **工作ワークショップ（着座型）**: 6畳程度から。テーブルとイスがあれば、店内の空きスペースにも設置できます。屋内向き。
- **エア遊具**: 本体寸法に加えて、周囲に安全マージンが必要です。天井高も確認しておきましょう（高さ2〜3mの機種があります）。

会場図面を業者に送れば配置案を出してもらえます。「イベントスペースの広さ」だけでなく、「柱の位置」「通路幅」「天井高」「搬入経路（エレベーターの大きさ・段差）」まで押さえておくと、当日の設営がスムーズです。

## チェック2: 電源

見落とされやすいのが電源です。多くの体験コンテンツで電源を使います。

- 免許証の発行機材（タブレット・プリンター）
- EVカーの充電
- エア遊具の送風機（常時稼働）
- ワークショップは、内容により一部で使用（シールデコは不要、ぷにラボは一部必要）

確認するのは「電源の有無」だけでなく、**コンセントの位置**、**使える容量**、**延長コードの経路と養生**の3つです。ご用意いただける電源容量を業者に伝えれば、それに合わせた構成を提案してもらえます。屋外の場合は、近くに電源がない前提で早めに手配方法を相談してください。

## チェック3: 安全

お子様が使うものだからこそ、安全の確認は契約前に済ませておきます。業者に確認すべき項目は次のとおりです。

- **賠償責任保険**: イベント運営に関する賠償責任保険に加入しているか。施設側から証明書類の提出を求められることがあるので、対応可否も確認します。
- **走行・稼働中の見守り**: 運転体験のコースにはスタッフが常時立ち会い、走行速度と車間を管理する体制か。
- **機材の点検**: エア遊具は使用のたびに点検し、破損や劣化がないことを確認してから出荷されているか。
- **対象年齢**: コンテンツごとに対象年齢が異なります（運転体験3〜8歳、シールデコ3歳〜、ぷにラボ4歳〜、エア遊具3歳〜が目安）。受付で案内できるようにしておきます。
- **動線**: 通行客とコースが交差しないか、ベビーカーの置き場はあるか、避難経路をふさいでいないか。

施設によっては、消防・防災の観点でイベント申請が必要な場合があります。施設の管理部門への届け出も、スケジュールに入れておきましょう。

## チェック4: スタッフ体制

当日いちばん足りなくなるのは、機材ではなく人手です。運営体制は次の3つから選びます。

1. **自社スタッフで運営（機材レンタルのみ）**: 業者から設営手順書と運営マニュアルが届き、事前のオンライン説明を受けられる形が一般的です。推奨スタッフは運転体験で2〜3名、ワークショップ・エア遊具で1〜2名が目安。
2. **運営代行（設営〜撤収まで業者に任せる）**: 受付・安全管理・誘導を業者スタッフが常駐して担当。店舗スタッフは接客・商談に専念できます。人員数・開催時間・会場所在地で費用が変わるため個別見積りです。
3. **中間案（設営・撤収だけ代行）**: 設営と撤収は業者、当日の受付は自社で回す形。人手が「朝と夕方だけ足りない」会場に向いています。

自社運営を選ぶ場合は、当日のシフトに「休憩要員」を入れておくことを忘れずに。1人で受付と見守りを兼ねると、休憩のたびにイベントが止まります。

## チェック5: 雨天と天候

屋外開催の場合、雨天時の扱いを契約前に決めておきます。前日までの相談で、屋内向けのワークショップへ切り替えられる業者なら、当日中止のリスクを減らせます。切り替え前提の「二段構え」で契約しておくケースもあります。

## チェック6: 告知

体験型イベントの告知は「割引」ではなく「何ができるか」を前面に出します。館内ポスター、施設の公式SNS、チラシの1枚目に「車を運転できる」「免許証がもらえる」「スクイーズが作れる」といった子どもに伝わる一言と、体験の写真を置きます。

写真素材は業者に依頼すると提供してもらえる場合があります。お子様のお顔が写った写真の使用は避け、機材や完成品を主役にした素材を使えば、肖像権の心配がありません。

## チェック7: 当日と撤収

当日は「開始前」「運営中」「終了後」で確認点が分かれます。

- **開始前**: 搬入経路の確保、設営完了の確認、電源の通電テスト、受付導線とサインの設置、スタッフの持ち場確認。
- **運営中**: 待ち時間の案内、安全の見守り、保護者への案内（商談導線）、写真撮影のルール案内。
- **終了後**: 撤収、原状回復（床・壁の確認）、忘れ物、施設への終了報告。

原状回復まで含めて「撤収」です。運営代行の場合はここまで業者が担当しますが、自社運営の場合は撤収の人手も確保しておきます。

## コピーして使えるチェックリスト

```
□ 開催日・時間帯を決めた（未定でも業者に相談済み）
□ 会場図面を用意した（柱・通路幅・天井高・搬入経路を記載）
□ コンテンツごとの必要スペースを確認した
□ 電源の位置・容量・延長経路と養生を確認した
□ 業者の賠償責任保険・証明書類の提出可否を確認した
□ 見守り体制・機材点検・対象年齢を確認した
□ 動線（通行客・ベビーカー・避難経路）を確認した
□ 施設の管理部門へイベント申請をした
□ 運営体制（自社／代行／設営撤収のみ）を決めた
□ スタッフのシフトと休憩要員を決めた
□ 機材のみの場合: マニュアル確認・オンライン説明を受けた
□ 雨天時の切り替え方法を契約に入れた
□ 告知物（ポスター・SNS・チラシ）と写真素材を準備した
□ 整理券・時間指定の受付方法を決めた
□ 当日の開始前・運営中・終了後の担当を決めた
□ 撤収・原状回復・施設への終了報告の担当を決めた
```

## まとめ

キッズイベントの準備は、企画の面白さより「スペース・電源・安全・スタッフ」の4点を早く確認できるかで決まります。1か月前に会場図面と電源の情報を揃えて業者に相談すれば、配置案と見積りが出て、あとはチェックリストを上から潰していくだけです。初めての開催でも、確認する項目がわかっていれば難しくありません。
