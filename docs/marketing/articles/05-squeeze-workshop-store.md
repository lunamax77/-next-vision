# スクイーズ工作ワークショップを店頭で開く方法｜出張・レンタルの流れ

「店頭で子ども向けの工作イベントを開きたいが、スペースも人手も限られている」。そんなご相談に向いているのが、出張型のスクイーズ工作ワークショップです。NextVisionでは「ぷにラボ」として、機材と材料を会場にお持ちし、設営から運営までお手伝いしています。この記事では、販促担当者の方が企画前に知っておきたい、作れるもの、当日の流れ、会場条件、料金の目安をまとめます。

## 作れるもの：ぷにぷにの肉球スクイーズ

ぷにラボで作るのは、安心・安全なシリコン素材でできた肉球のスクイーズです。サイズは2種類あります。

- 肉球（大）：縦8cm×横8cm×厚さ3cmの極厚サイズ。
- 肉球（小）：縦4.3cm×横4.5cm×厚さ3cmの手のひらサイズ。小さなお子さまでも扱いやすい大きさです。

カラーは複数のパステルカラーから選べます。手元で何度も触りたくなる感触で、持ち帰ったあとも「あの店で作った」と思い出してもらえる成果物になります。

[figure: punilab-colors.jpg|パステルカラーの肉球スクイーズ ; punilab-mold.jpg|肉球のシリコン型 :: 選べるカラー（左）と、型のまま持ち帰るシリコンモールド（右）]

## 当日の流れ：会場作業は約20分、仕上げはおうちで

ぷにラボは全7工程ですが、会場で行うのは前半の3工程だけです。1組あたりの会場作業は約20分で、残りはご自宅で仕上げる設計になっています。

1. 型と色を選ぶ：お気に入りのサイズ（大・小）とカラーを選びます。
2. 計量して混ぜる：カップに液を入れ、色を付けて混ぜます。
3. 型に流し込む：こぼれないよう、静かにモールドへ流し込みます。
4. 会場作業はここまで：型のまま、お持ち帰り袋に入れてお渡しします。
5. ご自宅で水につけて、型からそっと剥がします。
6. マジックパウダーをかけて完成です。

「型のまま持ち帰って、家で完成させる」流れにしているのは、会場の回転を良くするためだけではありません。帰宅後にもう一度体験が続くので、家族の会話の中でお店の名前が出る機会が増えます。

## 店頭イベントに向いている3つの理由

### 着座型なので、保護者へのご案内時間ができる

お子さまがテーブルに着いて作業している約20分は、保護者の方が同じ場所にとどまる時間です。商談や商品のご案内を組み込みやすく、携帯キャリアショップや家電量販店のように「商談が売上に直結する業態」と相性の良い構成です。

### 6畳程度から開ける省スペース設計

テーブルとイスがあれば設置でき、必要スペースの目安は6畳程度からです。催事スペースが取れない店舗でも、売場の一角で開催できます。

### 持ち帰れる成果物がある

自分で作ったスクイーズは、家に帰ってからも残ります。「来てよかった」の記憶が形になるので、再来訪のきっかけとして期待できます。

## 会場条件の目安

企画の段階で確認しておきたい条件は次のとおりです。いずれも目安で、会場条件により変わりますので、まずはご相談ください。

| 項目 | 目安 |
| --- | --- |
| 必要スペース | 6畳程度から（テーブル＋イス） |
| 対象年齢 | 4歳〜 |
| 所要時間 | 約20分／1組（＋ご自宅での仕上げ） |
| 推奨スタッフ | 1〜2名 |
| 電源 | 一部必要 |
| 屋内外 | 屋内向き |

実施人数は会場の広さと開催時間によって変わります。想定来場者数をお知らせいただければ、テーブル数と材料の数量をこちらで組み立てます。

## 料金の目安

ぷにラボの機材レンタル費用は1日あたり90,000円（税別）です。運営スタッフ費と送料は別途で、配送料は実費でのご請求となります。

- 2日間以上の連続開催の場合、ワークショップ（ぷにラボ・シールデコ）は日数分の機材費となります。2日目以降の割引はキッズライセンスパークとエア遊具のみが対象です。
- 設営・受付・安全管理・撤収をお任せいただく運営代行は、必要人員数・開催時間・会場所在地により別途お見積りします。

費用の内訳や予算別の組み合わせ例は、記事「店頭キッズイベントの費用相場と内訳」で詳しく解説しています。

## 企画するときの考え方

- 開催時間を決める：1組約20分なので、1テーブルで1時間に2〜3組が目安です。混雑が予想される日は、テーブル数を増やすか、整理券の運用を検討します。
- 告知は「作れるもの」を主役に：チラシや館内ポスターでは、割引の文字よりも完成品の写真を大きく載せると、お子さまから保護者への「行きたい」が引き出しやすくなります。
- 商談の動線を先に決める：着座している約20分をどう使うかを、店舗スタッフと事前に共有しておくと効果が変わります。

## 安全面で確認しておきたいこと

材料は安心・安全なシリコン素材を使用しています。会場では小さなお子さまが液を扱うため、保護者の方に同席していただく運用をおすすめしています。当社はイベント賠償責任保険に加入しており、証明書類の提出にも対応します。

## まとめ

出張型のスクイーズ工作ワークショップは、6畳程度のスペースとテーブル・イスがあれば店頭で開催できます。1組約20分の着座時間が保護者へのご案内時間になり、持ち帰れる成果物が再来訪のきっかけになります。会場の広さと想定来場者数が分かれば、テーブル数・材料・スタッフの構成をこちらで組み立てますので、まずは条件だけでもご相談ください。
