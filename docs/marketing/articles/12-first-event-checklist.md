# 初めてのキッズイベント開催チェックリスト｜会場・電源・安全

「キッズイベントを開くことは決まったけれど、何から手をつければよいかわからない」。初めて担当になった方が最初に悩むのは、企画の中身よりも準備の抜け漏れではないでしょうか。当日になって電源が足りない、機材が置けない、人手が回らない。こうしたトラブルの多くは、早めの確認で防ぐことができます。

この記事では、NextVisionの条件をもとに、相談から撤収までの流れと、確認しておきたい項目をチェックリスト形式でまとめました。社内の準備メモとしてお使いください。

## 準備は1か月前から

当社では、開催の1か月前にご相談いただく形を目安にしています。流れは次の6ステップです。

| ステップ | 内容 |
|---|---|
| 1. お問い合わせ | 日程が未定の段階でも可 |
| 2. ヒアリング | 会場図面・広さの確認 |
| 3. お見積り | コンテンツの組み合わせを提案 |
| 4. ご契約・準備 | 動線・安全計画 |
| 5. 搬入・設営 | 前日か当日早朝 |
| 6. 開催・撤収 | 原状回復まで |

土日・連休を中心に稼働しているため、週末の開催は早めのご相談がおすすめです。機材の空き状況によっては直近のご相談に対応できる場合もありますので、まずはご希望日をお知らせください。

日程が決まっていなくても、最初の問い合わせは始められます。会場の広さと電源の情報が手元にあると、その後のヒアリングと見積りが進めやすくなります。

## 会場の広さと電源を確認

最初に確認するのは、会場の広さと形です。体験コンテンツごとに、必要なスペースが大きく異なります。

| コンテンツ | スペース | 電源 | 屋内外 |
|---|---|---|---|
| キッズライセンスパーク | 10m×8m目安 | 必要 | 屋内・屋外 |
| ぷにラボ（スクイーズ工作） | 6畳〜 | 一部必要 | 屋内向き |
| シールデコ ワークショップ | 6畳〜 | 不要 | 屋内向き |
| エア遊具 | 設置寸法＋余裕 | 必要（送風機用） | 屋内・屋外（機種による） |

キッズライセンスパークの10m×8mは、走行コースと受付・発行ブースを含めた目安です。会場の形に合わせてコース配置を調整します。ワークショップはテーブルとイスがあれば、店内の空きスペースにも設置できます。エア遊具は本体サイズに加えて、周囲に安全マージンが必要です。高さが3,000mmの機種もあるため、屋内では天井の高さも見ておくと安心です。

電源は、免許証の発行機材、EVカーの充電、エア遊具の送風機で使います。コンセントの位置と、ご用意いただける電源容量をお知らせいただければ、それに合わせた構成をご提案します。会場図面をお送りいただければ、配置案もお出しします。

## 安全は契約前に確認

お子さまが使うものだからこそ、安全面は契約前に確かめておきたいところです。当社では、次の体制をとっています。

- **賠償責任保険**: イベント運営に関する賠償責任保険に加入しています。証明書類の提出にも対応します。
- **走行の見守り**: 運転体験のコースには常時スタッフが立ち会い、走行速度と車間を管理します。
- **機材の点検**: エア遊具は使用のたびに点検し、破損や劣化がないことを確認してから出荷します。
- **免許証のサイズ**: こども免許証は91×55mmで、実物の免許証とは意図的にサイズを変えています。

あわせて、対象年齢も受付で案内できるようにしておきます。目安は、キッズライセンスパークが3〜8歳、シールデコが3歳〜、ぷにラボが4歳〜、エア遊具が3歳〜です。

[figure: license.jpg|こども免許証（見本） ; case-seal-store.jpg|店頭でのワークショップ :: 対象年齢と持ち帰れるものを、受付で案内できるようにしておきます]

会場側では、通行のお客さまと体験エリアの動線が交差しないか、ベビーカーを置く場所があるかも確認しておくと、当日の案内がスムーズになります。

## 運営体制と当日の段取り

当日いちばん足りなくなるのは、機材ではなく人手です。体制は大きく2通りから選べます。

**機材レンタル（プランA）**は、必要な機材・備品を一式で配送し、設営手順書と運営マニュアルを添付する形です。事前のオンライン説明にも対応しています。当日の運営は貴社のスタッフ様が担当します。推奨スタッフは、キッズライセンスパークが2〜3名、ワークショップとエア遊具が1〜2名です。

**運営代行オプション付き（プランB）**は、設営・装飾から受付・安全管理・誘導、撤収・原状回復までを当社のスタッフが担当します。店舗のスタッフ様は接客や商談に専念できます。設営と撤収だけの部分的なご依頼にも対応します。体制の選び方は、記事「[イベント機材は「借りる」か「任せる」か](rental-vs-operation.html)」で詳しく整理しています。

費用の目安として、キッズライセンスパークのスタンダード（車両2台・1コース）は90,000円／日、ぷにラボとシールデコは各90,000円／日です。いずれも税別・機材レンタル費用で、運営スタッフ費と送料は別途となります。キッズライセンスパークとエア遊具は、2日目以降の機材費が50％です（ワークショップは対象外）。

屋外で開く場合は、雨天時の扱いも決めておきます。前日までのご相談で、屋内向けのワークショップへの切り替えが可能です。考え方は記事「[屋外キッズイベントの雨天対策](rainy-day-seasonal-plan.html)」でまとめています。

## コピーして使えるチェックリスト

```
□ 開催の候補日を決めた（未定でも相談を始めた）
□ 会場図面を用意した（広さ・形・天井の高さ）
□ コンテンツごとの必要スペースを確認した
□ コンセントの位置と電源容量を確認した
□ 屋内か屋外か、雨天時の扱いを決めた
□ 賠償責任保険の証明書類が必要か確認した
□ 対象年齢を受付で案内できるようにした
□ 通行のお客さまとの動線を確認した
□ 運営体制（機材のみ／運営代行込み）を決めた
□ 機材のみの場合: マニュアルとオンライン説明を確認した
□ 当日のスタッフ人数と持ち場を決めた
□ 搬入・設営の時間（前日か当日早朝）を決めた
□ 撤収と原状回復の担当を決めた
```

## まとめ

初めてのキッズイベントは、企画の面白さより「スペース・電源・安全・人手」の4点を早く確かめられるかが鍵になります。開催の1か月前を目安に、会場図面と電源の情報をそろえてご相談いただければ、配置案と見積りをもとに準備を進められます。

確認する項目がわかっていれば、初めての開催でも落ち着いて準備ができるはずです。日程が未定の段階でも構いませんので、まずは[お問い合わせ](index.html#contact)から会場の条件をお聞かせください。担当者より1営業日以内（土日祝を除く）にご連絡いたします。
