# 商談中に子どもが飽きる問題を「着座ワークショップ」で解決する

携帯キャリアショップや家電量販店では、契約や相談に20分、30分とかかることがあります。その間、お子さま連れのお客さまは「子どもが退屈して落ち着かない」「早く終わらせたい」と感じやすく、ご案内に集中していただきにくくなります。この記事では、その悩みに応える手段として、店内に置ける「着座型のワークショップ」の考え方を、NextVisionで提供しているシールデコとぷにラボを例にまとめます。

## 商談中に子どもが飽きると起きること

お子さまが席を立ったり、売場を歩き回ったりすると、保護者の方は話を聞きながらお子さまを気にすることになります。説明の理解が浅くなり、納得して決めていただく前に「また今度」となってしまう可能性があります。店舗側も、他のお客さまへの配慮から、落ち着かない空気に気を遣う場面が増えます。

ここで大切なのは、お子さまを「静かにさせる」ことではなく、「夢中になれることを用意する」ことです。座って手を動かす体験があれば、お子さまは自分の席で過ごせ、保護者の方はご案内をじっくり聞くことができます。結果として、お客さまにも店舗にも負担の少ない時間になることが期待できます。

## 着座型が商談と相性のよい理由

当社のシールデコとぷにラボは、どちらも「着座」「約20分前後」「省スペース」を前提に設計しています。テーブルとイスがあれば設置でき、6畳程度から開催できます。制作の途中で席を立つ場面が少なく、お子さまが集中している間に、保護者の方へ落ち着いてご案内できます。

また、どちらも作ったものをお持ち帰りいただけます。「作って帰る」ことが来店の思い出になり、店舗への好印象につながることが期待できます。通信キャリアショップや大型商業施設の店頭イベントで、多数開催してきた体験コンテンツです。

## シールデコとぷにラボの違い

**シールデコ**は、星やハートの型と丸型カプセル、スパンコールなどを組み合わせて、振ると中で揺れる「シャカシャカシール」をつくるワークショップです。全5工程で約25分、はさみなどの道具を使わないので、小さなお子さまにも安心です。材料を選ぶ工程が集中を生み、一つひとつの工程が短いため、飽きにくいテンポになっています。対象は3歳からで、電源は不要です。詳しくは[シールデコのページ](seal.html)をご覧ください。

**ぷにラボ**は、シリコン素材の肉球スクイーズ（大・小）をつくる体験です。会場での作業は約20分で、型に流し込むところまで。型のまま袋に入れてお渡しし、ご自宅で水につけて剥がし、パウダーをかけて完成させます。会場作業が短く、お帰りの後にも楽しみが続く設計です。対象は4歳からで、電源は一部必要です。肉球（大）は「見積もり参加でプレゼント」のような景品設計にも使えるため、保護者の方に商談へ参加していただくきっかけにもなります。詳しくは[ぷにラボのページ](punilab.html)をご覧ください。

## 会場条件と料金の目安

| | シールデコ | ぷにラボ |
| --- | --- | --- |
| 必要スペース | 6畳〜 | 6畳〜 |
| 対象年齢 | 3歳〜 | 4歳〜 |
| 所要時間 | 約20〜25分／組 | 約20分／組（＋ご自宅で仕上げ） |
| 推奨スタッフ | 1〜2名 | 1〜2名 |
| 電源 | 不要 | 一部必要 |
| 屋内外 | 屋内向き | 屋内向き |
| 機材費／日 | ¥90,000 | ¥90,000 |

料金はいずれも機材レンタル費用（1日・税別）です。運営スタッフ費と送料は別途で、配送料は実費でのご請求となります。ワークショップは2日目以降の割引の対象外で、日数分のご請求です。費用全体の考え方は、記事「[店頭キッズイベントの費用相場と内訳](kids-event-cost.html)」でまとめています。

## 運営代行と保護者へのご案内

店舗スタッフの方は、接客と商談に専念したいものです。そこで、設営・受付・安全管理・撤収をお任せいただける運営代行オプションもご用意しています（別途お見積り）。機材レンタルのみで、運営を貴社スタッフ様が担当するプランもお選びいただけます。イベント運営に関する賠償責任保険にも加入しており、証明書類の提出にも対応します。

ワークショップの時間は、保護者の方へご案内するための時間でもあります。たとえば、お子さまが制作を始めたタイミングで商品のご説明に入る、といった流れが組み立てられます。店頭の動線や席の配置は店舗ごとに異なりますので、図面や写真をいただければ、置き方も含めてご提案します。滞在時間が伸びる理由については、記事「[体験型イベントが滞在時間を伸ばす理由](taiken-stay-time.html)」もあわせてご覧ください。

導入のご利用の流れは、お問い合わせ、会場図面や広さのヒアリング、お見積り、ご契約・準備、搬入・設営、開催・撤収の順です。目安として、開催の1か月前までにご連絡いただくと、動線や安全計画までゆとりをもって準備できます。日程が未定でもご相談いただけます。ご相談の段階では、決まっていないことが多くても問題ありません。

最初のご相談では、次の点をお知らせいただくと話が早く進みます。

- 置きたい場所の広さ（6畳程度から）と、テーブル・イスの数
- 電源の有無（ぷにラボは一部必要、シールデコは不要）
- 想定している開催日数と、1日の来店者数の目安
- 運営を自社で行うか、運営代行を希望するか

## まとめ

商談中にお子さまが飽きてしまう悩みには、座って手を動かせる着座型ワークショップが向いています。シールデコ（約25分・3歳〜）とぷにラボ（約20分・4歳〜）は、どちらも6畳程度から置け、機材費は1日90,000円（税別、運営スタッフ費・送料は別途）です。店内のスペースと席数をお聞かせいただければ、置ける構成と概算をご案内します。日程が決まっていない段階でも、お気軽にご相談ください。
