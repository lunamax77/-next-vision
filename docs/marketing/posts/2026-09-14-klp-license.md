### 投稿前にやること — 比率を揃える

**Instagramのカルーセルは1枚目の比率に全スライドが揃えられる。** 比率がバラバラのまま
投稿すると、2枚目以降が勝手に切れるか余白が入る。

- **7枚すべてを 1080×1350（4:5・縦長）に統一**してから投稿する
- 4:5がフィードで最も面積を取れるのでこの比率を推奨
- 車体が切れないよう、余白は背景色で足す（トリミングで詰めない）

### 1枚目（カバー画像）── 作成済み

**カバー画像を制作済み。1080×1350（4:5）でそのまま投稿できる。**

- 生成元：`assets/2026-09-14-klp-cover.html`
- 書体はHPと同じ **Zen Maru Gothic**、配色もHPのブランドカラー（濃紺 `#26576E` /
  スカイブルー `#3E9BD8` / オレンジ `#F5A623`）に揃えてある
- 載せた文言：「選べる、7車種。」／7車種名のチップ／対象3〜8歳・約5分・屋内外／
  「7車種を見る →」のスワイプ誘導
- **価格・取引先名・保有台数は入れていない**

作り直す場合は、HTMLを編集して次のコマンドで再生成する：

```bash
/opt/pw-browsers/chromium-1194/chrome-linux/chrome --headless --disable-gpu --no-sandbox \
  --window-size=1080,1350 --screenshot=cover.png --virtual-time-budget=8000 \
  file://$PWD/2026-09-14-klp-cover.html
```

したがってカルーセルは **カバー1枚 ＋ 車体写真7枚＝計8枚** になる。

※お子様の顔が写る写真、開催現場の写真は**今回使わない**
（施設名が特定される写真は掲載許諾の問題があるため）。

## 4. 投稿時の注意（守ること）

- **取引先の社名・店舗名を書かない。** 掲載許諾が取れていない。実績に触れるなら
  「大手家電量販店の店頭」「大型商業施設」などの**業種表記**にとどめる
- **保有台数を書かない・示唆しない。** 「複数台あります」もNG
- **料金はキャプションに書かない。** 価格表とHPの整合が未確定のため、聞かれたら
  「HPに記載しています」と案内し、個別見積は代表の承認後
- **保険**は「賠償責任保険に加入」「証明書類の提出にも対応」までは書いてよい。
  金額・保険会社名は書かない（今回のキャプションには入れていない）
