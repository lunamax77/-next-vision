## 1. なぜローカルSEOをやるのか（役割の確認）

SNSで拡散して興味を持った人・施設担当者は、**その場では問い合わせない**。
後日「エア遊具 レンタル 大阪」「スクイーズ ワークショップ イベント」で検索する。
このとき**GBPとHPが検索結果に出てこなければ、拡散は売上に変換されない**。

```
  SNS拡散（03の起点A/B/C）  →  時間差  →  検索  →  GBP / HP  →  問合せ
       ↑ 認知をつくる                        ↑ ここが本書の担当（受け皿）
```

- GBPは**無料**で、**Googleマップと検索結果の上部**に出る。着手コスト対効果が最も高い。
- BtoB（施設担当者）は**社名で検索して実在性を確認する**。GBPが無いと信頼が下がる。
- 拡散が先行しても受け皿が無いと漏れるため、**フェーズ1（Week 1–2）で着手**する。

### 5-1. 【再判断のお願い】GBPの住所 — DreamCreation の住所を記載する案のリスク

代表より「自社住所は公開しない／代理店の DreamCreation の住所を記載する」とのご意向をいただいた。

| 案B：DreamCreation の住所を登録 | DreamCreation の所在地を NextVision の所在地として登録する | **条件次第。要確認事項がある**（下記の訂正を参照） |

#### ⚠ 案Bの評価を訂正（2026-08-24 追記）

当初「自社が管理しない代理店の住所だから停止リスクが高い」と評価したが、**この前提は誤りだった。**

`tools/invoicing/templates/` の見積・請求テンプレートを確認したところ、**発行元は「株式会社DreamCreation 代表取締役 竹村英哲」**（適格請求書番号 T5120001206752）。
つまり **DreamCreation は竹村代表が代表取締役を務める会社**であり、「外部の代理店」ではない。

これを踏まえた評価：

| 論点 | 評価 |
| --- | --- |
| 住所を代表が管理しているか | **管理している可能性が高い**（代表が両社の代表者）。当初の「管理外の住所」という懸念は当たらない |
| GBPガイドライン上の適否 | **【要確認】その住所で「株式会社NextVision として」スタッフが顧客対応しているか**が判断基準。同一拠点を共有しているなら問題は小さい。**登記上の所在地が別で、NextVision の実務がそこで行われていない場合は依然リスクがある** |
| 結論 | **案A（サービス提供地域ビジネス／住所非表示）を引き続き推奨**。理由はリスクではなく**目的達成の確実性**：代表のご希望は「住所を公開しない」ことであり、案Aはそれを規約に沿ってそのまま実現できる。案Bは住所欄に何を書くかの整理が追加で必要になる |

**→ 案A を推奨する。** ただし当初述べた「停止リスクが高い」という強い表現は取り下げる。

> なお **DreamCreation の実際の所在地は代表から提供されていない**ため、
> 本書に住所は記載していない：`【要確認：DreamCreation の所在地（代表より未提供）】`

#### 🔴 併せて浮上した重要論点：見積・請求は「どちらの会社名義」で出すのか
