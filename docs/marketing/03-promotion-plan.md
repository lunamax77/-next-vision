## 2. 拡散のメカニズム設計 — なぜこの2商材が広がりうるか

拡散を「運」に任せず、**起点を指定して仕込む**。当社が狙う起点は次の4つ。

### 起点A：ぷにラボの「二段階UGC」（★最重要／今回の拡散の核）

ぷにラボは**会場で完成しない**。型のまま持ち帰り、自宅で水につけて剥がし、パウダーで完成させる。
これは他のワークショップに無い構造的な強みで、**投稿の機会が2回発生する**。

```
  会場（当日）                     自宅（当日夜〜翌日）
  ┌──────────────┐        ┌──────────────┐
  │ ①作っている手元・     │        │ ②型から剥がす瞬間     │
  │   選んだ色・真剣な顔   │  ──▶   │   完成した肉球スクイーズ │
  │ → 保護者が「今日ここに │        │ → 「できた！」報告投稿   │
  │    来てる」と投稿      │        │   （再現性が高い＝数が出る）│
  └──────────────┘        └──────────────┘
        施設の当日集客に効く              指名検索「ぷにラボ」を育てる
```

- ①は**施設側の当日集客**に効く（今その場でやっている、という即時性）。
- ②は**ブランド名の記憶**に効く。②のときイベント名を思い出せる設計が必要
  → **持ち帰り袋・説明カードにブランド名とハッシュタグを入れる**（後述4章）。
- ②があるので、**イベント終了後も投稿が続く**。これが「ぷにラボ」という固有名を
  検索されるワードに育てる唯一の現実的なルート。

### 起点B：エア遊具の「無人→行列」のビフォーアフター

跳ねている子どもの動画は可愛いが、**それ単体では他社と区別がつかない**。
拡散するのは**変化**。「開店前の何もない空きスペース」→「送風機ON・膨らむ」→「開場3分で行列」
という**時間圧縮の絵**を作る。
- BtoBには「うちの空きフロアもこうなるのか」という**自分ごと化**が起きる。
- BtoCには「膨らむ瞬間」という**理屈抜きに見てしまう画**が効く（保存・シェアが伸びる形式）。
- 当社は**設営から撤収・原状回復まで**を担うので、この一連を撮れるのは自社だけ。
  → **競合が真似しにくい素材**であり、ここに撮影投資を集中させる。

### 起点C：施設の公式アカウントによる「借り物拡散」

商業施設・店舗は自館の集客告知として**自分の公式SNSで告知したい動機がある**。
当社が投稿素材（縦動画・静止画・告知文の下書き）を**先に渡す**と、施設側は手間ゼロで投稿できる。
- 当社アカウントのフォロワー数に依存せず、**施設のフォロワーへ届く**＝立ち上がり期の最大の増幅装置。
- 「素材提供パック」を運営代行の付帯価値として整備する（後述4章）。
- ※**施設名・施設アカウントの言及、素材の相互利用は許諾が必要**【要確認】。

### 起点D：ローカル検索（GBP）からの「刈り取り側」の受け皿

SNSで生まれた興味を、検索で受け止める。「エア遊具 レンタル 大阪」等で見つからないと
拡散が売上に変換されない。設計は `05-local-seo.md` に分離。

### 起点の優先度

| 起点 | 拡散寄与 | 着手コスト | 初動90日での扱い |
| --- | --- | --- | --- |
| A ぷにラボ二段階UGC | ◎ | 中（同梱物の制作が要る） | **最優先で仕込む** |
| B エア遊具 変化の動画 | ◎ | 中（撮影手配が要る） | 次回開催で必ず撮る |
| C 施設の借り物拡散 | ○〜◎ | 低（素材を渡すだけ） | 許諾が取れ次第すぐ |
| D ローカル検索 | ○（受け皿） | 低 | 公開後すぐ着手 |

## 4. UGC（お客様投稿）を生む仕掛け

> **本章の施策は、いずれも実施前に代表の承認が必要**。
> 特に「景品・特典を伴うキャンペーン」は景品表示法の考慮が要る（【要確認】参照）。
> ここに書くのは**社内たたき台としての案**である。

### 4-1. ハッシュタグ設計（3層に分ける）

乱発せず、**役割で3層**にする。

| 層 | タグ案 | 役割 | 誰が使う |
| --- | --- | --- | --- |
| ①ブランドタグ | `#ぷにラボ` | 固有名の記憶と検索。ここに投稿を集約する | 当社＋保護者 |
| ②UGC回収タグ | `#おうちでぷにラボ` | **自宅完成（起点A②）の投稿を回収する専用タグ** | 保護者 |
| ③発見タグ | `#スクイーズ作り` `#キッズワークショップ` `#エア遊具` `#ふわふわ` `#商業施設イベント` `#キッズイベント` `#大阪イベント` | 新規到達 | 当社 |

- 01の BtoB寄せタグ群（`#イベント企画 #集客イベント #商業施設 #販促` 等）は**BtoB投稿で継続使用**し、
  上記③はBtoC投稿側で使う。**1投稿にBtoBタグとBtoCタグを混ぜない**（届く相手がぼやける）。
- `#おうちでぷにラボ` は当社が**先に投稿して器を作る**（空のタグに人は投稿しない）。
- ※タグ名は最終的に**既存投稿との衝突を確認してから確定**する【要確認】。

### 4-2. ぷにラボ：持ち帰り袋への「完成のしかたカード」封入（★核）

HPの工程⑤「お持ち帰り袋に入れ、型のままお渡し」に**カードを1枚入れる**だけで、
起点Aの②（自宅完成の投稿）が仕組み化される。

カード記載案（A6程度・両面）
- 表：**「おうちで完成させよう」** ＋ 工程⑥⑦のイラスト
  （⑥水につけて型からそっと剥がす → ⑦マジックパウダーをかけて完成）
- 裏：
  - 完成したら見せてね → **`#おうちでぷにラボ`**
  - `@（Instagramアカウント）`（※アカウント確定後）
  - QRコード → `https://nextvision.fun/punilab.html`
  - 保護者向け一言：「イベントのご相談は運営会社まで」＋会社名
- 効果：①**帰宅後の投稿導線**、②**保護者がHPに来る**（BtoBリードの副産物）、
  ③**当社名が記憶される**（施設のイベントだったで終わらせない）

**【要確認】**：カードの印刷・封入は費用と手配が発生。また**施設によっては
第三者の販促物の封入・自社SNS誘導を不可とする場合がある**ため、施設ごとの可否確認が要る。

### 4-3. 会場の撮影スポット（フォトスポット）

- **ぷにラボ**：テーブル上に**「サイズ比較ボード」**を置く。8×8×3cmの実寸枠と、
  手のひらを置く位置の目印。手＋完成品が1枚で撮れる＝**手元映えの再現性**が上がる。
  背景に無地のマット（ブランドカラー）を敷くと、誰が撮っても写真が揃う。
- **エア遊具**：遊具の**正面やや斜め・引きで撮れる立ち位置**に足元マーク。
  「ここから撮ると全部入ります」のミニ看板。行列の邪魔にならない位置に置く。
- 共通：**ハッシュタグを書いた小さなサインを撮影スポットに置く**（人は目に入ったタグしか使わない）。
- ※什器・サインの制作費、会場への設置可否は施設判断【要確認】。

### 4-4. 完成品の見せ方（当社投稿側）

- **サイズを必ず物差しで示す**：8×8×3cmは数字では伝わらない。手のひらとの比較を毎回入れる。
  「極厚」はぷにラボ最大の視覚的差別化点。
- **色のバリエーションを並べる**：工程①「型と色を選ぶ」＝選べることが価値。
  同じ型・違う色を横一列に並べたカットは保存されやすい。
- **アニマル3種（とら・ぞう・ペンギン）は「どれにする？」形式**で出す。
  選択を促す投稿はコメントが付きやすい＝リーチが伸びる。
- **「完成前／完成後」の対比**：型のまま→完成、の2枚は本商材でしか作れない絵。

### 4-5. 施設向け「投稿素材提供パック」（起点C）

運営代行・レンタルの**付帯価値**として、施設担当者にそのまま渡せる形で用意する。

| 中身 | 形式 |
| --- | --- |
| 縦動画 15〜30秒 | 施設が自館アカウントに投稿できるもの（当社ロゴは控えめ or なし） |
| 静止画 3〜5枚 | 告知用（開催日・場所を後から載せられる余白付き） |
| 告知文の下書き | 施設が日付・階数を埋めるだけで使えるテンプレート |
| 開催後お礼投稿の下書き | 開催後の投稿まで用意すると採用率が上がる |

**【要確認】**：素材の**権利関係**（当社が撮った写真の施設側利用、施設が撮った写真の当社利用）、
および**来場者の顔が写る写真の取り扱い**（肖像権・撮影同意の運用）を先に決める必要がある。

## 6. KPI と計測方法

`01-sns-strategy.md` の思想（**フォロワー数より、プロフィールのリンククリック／DM問合せ数を重視**）を
継承しつつ、今回は**拡散が最優先**のため「到達側の指標」を先行指標として追加する。

### 6-1. 3階層で見る

| 階層 | 指標 | なぜ見るか | 目標の置き方 |
| --- | --- | --- | --- |
| **① 拡散（先行指標・最優先）** | リール再生数／**フォロワー外リーチ率**／保存数／シェア数 | 拡散しているかを最速で判断できる。フォロワー外リーチ率が拡散の本体 | 【要確認】初月を実測してベースラインを置き、以降はその改善率で見る |
| **② 記憶・関心（中間指標）** | プロフィールアクセス数／**指名検索数**（「ぷにラボ」「NextVision」）／UGC投稿件数（`#おうちでぷにラボ`） | 拡散が「当社の記憶」に変換されたか | UGC件数は**開催1回あたり何件出たか**で見る（絶対数でなく再現率） |
| **③ 成果（結果指標）** | プロフィールリンククリック／**HP流入**／DM・問合せ件数／見積依頼件数 | 01のKPI思想の本体 | 01の月次記録に統合 |

### 6-2. 計測方法

- **SNS内**：Instagramインサイト／TikTokアナリティクスを**月次で手動記録**（月初に前月分）。
  リール単位で「再生・フォロワー外リーチ率・保存・シェア」を記録し、
  **勝ちフォーマットを1つ特定して翌月それを増やす**（散らさない）。
- **HP流入**：GBP・SNSからの流入を分けて見る必要がある。
  → **アクセス解析の導入状況を確認**【要確認】。未導入なら、まずは
  プロフィールリンクに**計測用パラメータ付きURL**を使う案（例：`?utm_source=instagram`）。
  ※実装はプロダクト部門と調整。
- **UGC件数**：`#おうちでぷにラボ` `#ぷにラボ` を**月1回手動で数える**（当面は自動化不要）。
- **問合せ**：HPフォーム・DM・電話の流入元を、営業部門の案件管理表に**「きっかけ」欄**として記録。
  ※記録項目の追加は営業部門の領域のため、依頼ベースで調整。
- **開催1回あたりの素材化率**：撮影できた開催／全開催。**拡散の燃料切れを防ぐ内部指標**。

### 6-3. 90日時点で判断すること

1. エア遊具とぷにラボ、**どちらが拡散したか**（フォロワー外リーチ率で比較）→ 次90日の配分を寄せる
2. 拡散した投稿が**問合せに繋がったか**（拡散と成果が別物なら訴求の設計を見直す）
3. **UGCが1件でも出たか**（出ていなければ封入カード／撮影スポットの設計を作り直す）

## 8. この計画で「やらないこと」

拡散を最優先にするため、初動90日では以下を**意図的にやらない**。

- **媒体を増やさない**：Instagram（＋TikTokへの再編集）とGBPに絞る。Facebook/Xは転載のみ。
- **フォロワー数を目標にしない**：買う・相互フォローで増やす類は一切行わない。
- **毎日投稿しない**：01の週2〜3回を守る。**素材が無い週に無理に出さない**（質が落ちると拡散が止まる）。
- **HPを直接いじらない**：`site/` はプロダクト部門の担当領域。当部門は指摘リストまで。
- **未確認の事実を言わない**：実績・安全・スペックはHP記載の範囲を超えない。
