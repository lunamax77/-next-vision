> 社内ドラフト。公開は対外行為のため、各記事とも**竹村代表の承認後**に公開します。
> キーワードの根拠は `docs/marketing/seo-keywords.md`。記事ドラフトは `docs/marketing/articles/`。

## 全体の流れ

```
第1月  土台になる基礎記事   （集客の悩み → 費用 → 効果の理屈 → 準備の手順）
第2月  商材別の深掘り       （運転体験 → スクイーズ → エア遊具 → 着座ワークショップ）
第3月  業種別・比較         （住宅展示場 → カーディーラー → レンタルか代行か → 雨天・季節）
```

- ペース: 週1本（月4本）。公開曜日は火曜または水曜（担当者が翌週末の企画を考えるタイミング）。
- 1本あたり 2,500〜3,500字。構成は title（32字以内）／meta description（120字以内）／リード／H2・H3／まとめ／CTA。
- 内部リンク: 基礎記事 → 商材ページ、商材記事 → 基礎記事（費用・チェックリスト）へ相互に張る。
- すべての記事の末尾に `<!-- 要確認 -->` を残し、代表が事実確認してから公開する。

## 運用ルール

- **捏造禁止**: 実績数・顧客名・効果の数値はHPに書かれていることだけを使う。効果は「期待できます」。
- **社名非掲載**: 取引先は「大手家電量販店」「携帯キャリアショップ」など業種で表現。
- **写真**: お子様の顔写真は使わない。`site/images/` の機材・完成品・イラスト（svg）を使う。
- **価格**: すべて「税別・機材レンタル費用・送料別・運営スタッフ費別」を明記。
- **CTA**: 記事1本につき1つの主CTA（商材ページ）＋末尾の「相談する」導線。
- **公開前**: 代表が `<!-- 要確認 -->` をチェック → 承認 → 公開（公開は対外行為）。

## 公開後の見直し

- 月末に Search Console で「表示回数はあるがクリックが少ない」記事の title / description を改稿。
- 3か月で問い合わせにつながった記事の型（費用系／チェックリスト系／業種系）を見極め、次の3か月の配分を決める。
