# 竹村代表グループ — AI組織

竹村代表が保有する**2社**の「AI組織」を定義・運営するリポジトリです。
代表を全決済権を持つ最終意思決定者とし、業務の種類によって担当会社に振り分けます。

| 会社 | 事業 | AI |
| --- | --- | --- |
| 株式会社ドリームクリエーション | 通信インフラ/利確、プロモ・特販、人材派遣、代理店 | **マスターくん**(社長直轄の統括AI)/ Googleドライブ「AI専用」 |
| 株式会社ネクストビジョン | キッズイベント遊具レンタル・運営代行 | **ジョブズ**(CEO・実行部隊トップ)/ 5部署 |

## ルールの核(両社共通)

1. **原本不可侵** — 既存データ(スプレッドシート・議事録等)は読むだけ。上書き・編集・削除しない。
   参照した上で**別の新しい成果物**を作り、AIの作業場に格納します。原本に触るのは代表承認が必要です。
2. **対外行為・重要決定は代表承認** — 送信・公開・支払い・提出・対外コミット・人に関する決定は、
   実行の前に必ず代表の承認を得ます。AIの出力はすべて「下書き」です。

## 使い方

- 実行部隊に仕事を流したいときは、**ジョブズ**に話しかけます(または `/jobs`)。
  ジョブズが方針を提案し、代表の承認を得てから各担当AIに振り分けます。
- 組織の詳細は以下を参照してください。
