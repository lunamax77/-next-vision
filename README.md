# 株式会社ネクストビジョン

株式会社ネクストビジョンの「AI組織」を定義・運営するリポジトリです。

竹村代表を最終意思決定者とし、実行部隊トップの **ジョブズ(CEO)** が方針を提案・振り分け・統括し、
その下の5部署(営業・マーケティング・プロダクト・業務管理・財務)の担当AIが実作業を担います。

## この会社のルールの核

**会社の外部に影響が及ぶ行為(送信・公開・支払い・提出・対外コミットなど)は、
実行の前に必ず竹村代表の承認を得ます。** 社内の調査・ドラフト作成は進めてよいですが、
「実際に外に出す最後の一歩」の手前で必ず止まり、代表の許可を取ります。

## 使い方

- 実行部隊に仕事を流したいときは、**ジョブズ**に話しかけます(または `/jobs`)。
  ジョブズが方針を提案し、代表の承認を得てから各担当AIに振り分けます。
- 組織の詳細は以下を参照してください。
