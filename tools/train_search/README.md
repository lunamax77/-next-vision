# 新幹線・在来線の経路リンク(駅すぱあと API フリープラン)

出張の移動手段比較用。駅名・日時を指定すると、駅すぱあとの検索結果ページのURLを出します。

## 準備(初回のみ・要代表承認)

1. 駅すぱあと API(https://api-info.ekispert.com/plan/)でフリープランに登録し、アクセスキーを取得
2. 環境変数 `EKISPERT_KEY` にアクセスキーを設定
3. クラウド環境のネットワーク許可に `api.ekispert.jp` を追加

## 使い方

```bash
python3 link.py --from 新大阪 --to 宮崎 --date 2026-10-26 --time 09:00
python3 link.py --from 宮崎 --to 新大阪 --date 2026-11-01 --time 20:00 --arrival
```

## 注意

- フリープランでは運賃・所要時間のデータは取れません。リンク先で確認します
- 比較表の数字はAIがWebで調べた値です。出典と調査日を必ず添えます
