# 見積・請求ジェネレーター

既存の御見積書・御請求書テンプレート（Excel）を土台に、**顧客・期間・遊具を指定するだけで
御見積書／御請求書のxlsxを自動生成**するツールです。体裁・印影・数式（小計／消費税／合計）は
テンプレートのまま保持されます。

## 使い方

```bash
# 御見積書
python3 generate.py jobs/sample_quote.json

# 御請求書
python3 generate.py jobs/sample_invoice.json
```

生成物は `output` に指定したパス（既定は `out/`）に保存されます。
出力xlsxは Excel / Google スプレッドシートでそのまま開けます。

## ジョブJSONの書き方

```jsonc
{
  "type": "quote",                     // "quote"=御見積書 / "invoice"=御請求書
  "customer": "株式会社新通エスピー",   // 宛先(自動で「御中」付与)
  "subject": "エアー遊具レンタルについて",
  "period": "2026年9月1日～2026年9月30日",
  "issue_date": "2026-08-06",          // 省略時はテンプレの =TODAY()
  "due_date": "令和8年9月30日",         // 請求書のみ(振込期限)
  "person": "竹村英哲",
  "rental_items": [                    // レンタル費(最大4件)
    {"item": "エアリズム トランポリン", "qty": 1, "days": 2},   // ← 遊具名だけで単価自動計算
    {"name": "エアー遊具", "qty": 1, "days": 1, "unit_price": "一式", "amount": 300000} // ← 金額明示も可
  ],
  "transport_items": [                 // 運送費(見積:最大3件 / 請求:最大5件)
    {"name": "配送料金(片道)　大阪→福岡", "qty": 1, "days": 1, "unit_price": 10000, "note": "..."}
  ],
  "output": "out/見積_新通エスピー_202609.xlsx"
}
```

### 金額の自動計算
`item`（遊具名）と `days` を指定すると `pricebook.json` から単価を引いて金額を計算します。
ルールは **初日は満額・2日目以降は50%**（`pricebook.json` の `multiday_rule` で変更可）。
`unit_price` / `amount` を明示した場合はそちらを優先します。運送費など台帳に無い項目は
金額を明示するか、`unit_price` だけ入れればテンプレの計算式（数量×日数×単価）で算出されます。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `generate.py` | 生成スクリプト本体 |
| `pricebook.json` | 遊具マスタ（価格はHP掲載と同一） |
| `templates/` | 元テンプレート（御見積書・御請求書） |
| `jobs/` | ジョブJSONの見本 |
| `out/` | 生成物（Git管理対象外） |

## 注意・確認事項

- **発行元**：現在のテンプレートの発行元は **株式会社DreamCreation**（適格請求書番号
  T5120001206752、振込先 池田泉州銀行 難波支店）です。NextVision名義で発行する場合は
  テンプレートの発行元ブロックを差し替える必要があります（要・代表確認）。
- 消費税は10%固定（テンプレの数式）。軽減税率等が必要な場合は別途対応。
- **請求書の対外送付は「対外行為」**です。生成（社内作業）まではこのツールで行い、
  実際の送付前には必ず竹村代表の承認を得てください。
