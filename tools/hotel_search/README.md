# 会場周辺の空室検索(楽天トラベル)

イベント遠征時のスタッフ宿探し用。会場の緯度経度と日程を指定すると、半径3km以内で空室のある宿を安い順に出します。

## 準備(初回のみ・要代表承認)

1. 楽天ウェブサービス(https://webservice.rakuten.co.jp/)で楽天IDでログインし、アプリIDを発行
2. `export RAKUTEN_APP_ID=発行したID`
   (アクセスキーも発行された場合は `export RAKUTEN_ACCESS_KEY=...`)

## 使い方

```bash
python3 search.py --lat 36.7550 --lng 137.0200 --in 2026-11-14 --out 2026-11-15 \
    --adults 1 --rooms 3 --max 10000 --csv 宿候補.csv
```

- 緯度経度は Google マップで会場を右クリックするとコピーできます
- `--adults` は1室あたりの人数、`--rooms` は部屋数
- 予約はしません。表示されたURLから人が予約します

## 注意

- 分かるのは空室の有無と料金だけです。他の宿の予約数や稼働率は取れません
- 公式APIのみを使い、スクレイピングはしません
