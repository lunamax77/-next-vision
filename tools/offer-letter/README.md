# 内定通知書 自動発行システム

Googleフォームに入力すると、印影入りの内定通知書（＋内定承諾書）をPDFにして `info@xpr0615.com` へ自動でメールし、
発行件数を管理簿に記録します。Google Apps Script だけで動き、費用はかかりません。

```
Googleフォーム → 回答シート → [Apps Script] → PDF生成（印影入り）→ ドライブ保存
                                           → Gmailで info@ へ送付 → 管理簿に1行追加
```

## ファイル

| ファイル | 内容 |
| --- | --- |
| `Code.gs` | 本体（設定・会社情報・フォーム項目・PDF文面・メール文面） |
| `appsscript.json` | Apps Script の設定（タイムゾーン等） |
| `sample_preview.pdf` | 出力イメージ（ダミーデータ・仮の印影） |

## フォーム項目

発行会社（DreamCreation / NextVision）、氏名、入社予定日、雇用形態、試用期間、
配属先、職種・業務内容、勤務地、給与

## セットアップ（初回のみ）

1. Apps Script（script.google.com の新規プロジェクト、またはスプレッドシートの「拡張機能 → Apps Script」）を開く
2. `Code.gs` の中身を貼り付けて保存（単体のプロジェクトなら、管理簿スプレッドシートは setup が自動作成）
   （プロジェクトの設定で「appsscript.json を表示」をONにし、同ファイルの内容も貼り付け）
3. 関数 `setup` を選んで実行 → 権限を承認
   - フォームが作成され、回答シート・「管理簿」シート・送信トリガーが自動でできる
   - フォームURLは実行ログに出る
4. フォームから1件テスト入力 → info@xpr0615.com に届いたPDFと管理簿を確認

送信元は `setup` を実行したGoogleアカウントのGmailになります。送付先は `CONFIG.RECIPIENT` で変更できます。

## 管理簿

「管理簿」シートに 発行番号（例 `DC-2026-0001` / `NV-2026-0001`）・発行日時・会社・氏名・各条件・
送付先・PDFリンク・送信状況 を記録。右側に発行総数・会社別件数・エラー件数を自動集計。
送信に失敗した場合は「エラー」と記録され、実行アカウントに通知メールが届きます。

## 変更するとき

- 会社情報・印影：`COMPANIES`（印影はドライブのファイルIDで指定）
- 文面：`renderHtml()`（PDF）／`sendMail()`（メール本文）
