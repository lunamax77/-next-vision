# 勤怠確認アプリ(試作)

スタッフの「起床確認・出勤確認・移動確認・退勤確認」を、GPS位置情報 + 本人確認用の写真を
同時取得して記録する社内向けプロトタイプ。

## 構成

- `index.html` / `app.js` / `config.js` … フロントエンド(氏名入力 + 4ボタン + 記録一覧)
- `server/` … CoreServer(Value-Domain)へデプロイするバックエンド(PHP + MySQL)。
  デプロイ手順は `server/README.md` を参照

## 現状(試作版のスコープ)

- 4つのボタン(起床/出勤/移動/退勤)をタップ → カメラ起動 → 撮影と同時にGPS取得 → 記録一覧に表示
- `config.js` の `API_URL` が未設定の場合は端末内(`localStorage`)保存のみで動作する
- `API_URL` を設定すると、記録のたびにサーバー(MySQL)へ保存され、任意で
  Googleスプレッドシートにも自動反映できる(要サービスアカウント設定・代表承認)
- 認証はスタッフの氏名入力のみ(簡易)。ログイン機能は未実装

## 使い方(ローカル確認)

カメラ・位置情報はブラウザのセキュリティ上、`https` または `localhost` でのみ動作する。

```bash
cd tools/attendance-app
python3 -m http.server 8000
```

スマートフォンで確認する場合は、同一ネットワーク内で `https` 経由でアクセスするか、
ngrok 等でトンネルすること(外部公開は代表の承認が必要)。

## 次のステップ(要相談)

- CoreServer への実デプロイ(FTP/SSH・MySQL接続情報が必要 → 代表に確認)
- Googleスプレッドシート連携の本番有効化(サービスアカウント作成は代表承認のうえ実施)
- スタッフごとのログイン・本人紐付け(現状は氏名の自己申告のみ)
- 位置情報の許容範囲チェック(勤務先から離れすぎている場合の検知など)
- 写真データの保持期間(プライバシー配慮)
