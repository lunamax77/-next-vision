# 勤怠確認アプリ

スタッフの「起床確認・出勤確認・移動確認・退勤確認」を、GPS位置情報 + 本人確認用の写真を
同時取得して記録する社内向けアプリ。稼働中: https://d-creation-o.com/attendance/

## 構成

- `index.html` / `app.js` / `config.js` … スタッフ用フロントエンド(ID/PWログイン + 4ボタン)
- `admin/` … 管理者用ダッシュボード(本日の状況・アカウント発行)。Basic認証で保護
- `server/` … CoreServer(Value-Domain)へデプロイするバックエンド(PHP + MySQL)。
  デプロイ手順は `server/README.md` を参照

## 機能

- 4つのボタン(起床/出勤/移動/退勤)をタップ → 位置情報取得 → カメラで本人確認撮影 → 記録
- 出勤・移動・退勤では、移動手段・経路・金額(任意)も記録できる
- 位置情報またはカメラの取得に失敗した場合は記録が行われない(なりすまし・未確認記録を防ぐため)
- GPS座標はOpenStreetMap(Nominatim、無料・APIキー不要)で住所に変換して保存する
- スタッフはID/パスワードでログイン(自己申告の氏名入力ではない)。
  アカウントは管理画面から発行する
- 記録はMySQLに保存され、任意でGoogleスプレッドシートにも自動反映できる

## 管理画面(`admin/`)

- `admin/index.html` … 本日の出勤状況を一覧表示(各スタッフの直近の記録写真・住所・地図リンク付き)
- `admin/accounts.html` … スタッフアカウントの発行・パスワード再発行・無効化
- どちらもHTTP Basic認証で保護されている(`.htpasswd` はgit管理外、代表に別途共有)

## デプロイ

初回セットアップ・追加のマイグレーションSQLは `server/README.md` と `server/db/` 配下の
