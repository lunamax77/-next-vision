# 案件管理表

顧客・案件・ステータス・金額・開催日を一元管理するスプレッドシートを生成します。
Excel / Google スプレッドシートで開けます。

```bash
python3 build_pipeline.py   # -> 案件管理.xlsx
```

## シート構成

- **案件一覧**：1案件1行。ステータス・プラン・入金はプルダウン入力。
  上部固定＋オートフィルタ付き。400行目まで数式対応。
  - 列：案件ID／受付日／顧客名／経路・業種／案件内容／主なコンテンツ／プラン／開催日／
    会場／ステータス／見積(税込)／請求(税込)／入金／担当／次アクション／備考
  - ステータス：問合せ→ヒアリング→見積提出→受注→開催準備→開催済→請求済→入金済（／失注・保留）
- **ダッシュボード**：ステータス別件数、パイプライン見込、請求済・入金済・未入金残を数式で自動集計。

## 見積・請求ツールとの連携

`../invoicing/` の見積・請求ジェネレーターと組み合わせて運用します。
案件が「受注」→開催後「請求済」に進んだら、案件の顧客名・金額をそのまま請求ジョブに転記できます。

## 注意

- 初期データのうち **新通エスピー** は実在の継続案件、他の2行は **★サンプル（要差し替え）** です。
- 金額はすべて税込。
- 既存案件データ（過去の請求実績等）を反映したい場合は、ドライブの請求書xlsxから取り込めます。
