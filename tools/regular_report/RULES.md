# 来店予告レポート — 定義とルール(代表決定事項)

対象: madonna-bbs.site「ご来店予告」掲示板 / 実行: `python3 tools/regular_report/report.py`

## 1. 運用
- 報告は代表が「報告」と入力したときだけ実行する(定期配信なし)
- 報告は簡潔に、表で出す
- たっぴー(代表本人)は集計から除外

## 2. 営業日と部
| 区分 | 時間 |
|---|---|
| 営業日 | 5:00〜翌5:00 |
| 1部 | 13:00〜19:00 |
| 1.5部 | 16:30〜23:30 |
| 2部 | 19:00〜翌5:00 |

- 部の移動はないものとする(部ごとに表を分ける)
- カップルは別項目(1組で数える、分割しない)

## 3. 常連の定義
- 常連 = 過去半年の予告日数で男女それぞれ上位30位(同数は含む)
- 名前は半角/全角・絵文字の違いを同一人物とみなす
- 名前の横に過去の来店回数(半年)を表示、初めては(初)

| レベル | 条件 |
|---|---|
| Lv4 | 半年で100回以上、または代表認定(あつし) |
| Lv3 | 78回以上 |
| Lv2 | 52〜77回 |
| Lv1 | その他の常連 |

## 4. 到着時刻
- 優先順: 書かれた時刻 > 「1部/2部」等の部 > 「夜」=19:00・「夕方」=16:30 > 「今から/間もなく」等=投稿時刻
- 時刻の記載がない場合は予測(表示に「予測」と付ける)
  1. 本人の過去の記載時刻の中央値(3回以上ある人)
  2. なければ一般傾向: 朝(5〜13時)の投稿→16:30(カップル17:00)/ 昼→投稿の約2〜3時間後 / 夕→約1時間後 / 夜→約40分後
- 部の開始時刻より前には来ない。開店前の投稿は13:00以降
- 予告なしで来た人(スタッフの代理投稿)は投稿時刻に来店
- 部ごとの表では名前の横に到着時刻を表示する

## 5. 滞在時間(今いると思われる人)
- 常連: 部の終了までいる。ただし最大6時間
- 常連以外・カップル: 来店から3時間
- どちらも部の終了時刻で退店
- 1部の男性は1.5部開始(16:30)以降、半分帰った想定で0.5人として数える

## 6. 判定(どれか1つで ✕ 行かない方がいい)
1. Lv4が2名以上いる
2. 男性の常連が50%を超える
3. 女性率が40%以下(女性÷男女合計。カップルは除く。Lv3以上の女性常連は女性として数えない)

## 7. 報告に含めるもの
- 部ごとの表(Lv4/Lv3/Lv2/Lv1/常連以外/計、カップル)+ 名前・来店回数・到着時刻
- 予告の到着時刻別(1時間ごとに女性・男性・カップルの名前・レベル・到着時刻)
- 今いると思われる人(常連の割合つき)
- 実測補正(代表の実測データ `observations.csv` から男女の倍率を出す)
- 判定と、この先 ✕ になる時間帯
- 時間帯別表(1時間ごと: 女性・男性・カップル・女性率・女性常連率・男性常連率・全体常連率・Lv4・判定)
- 予告が少ないときは過去の同じ曜日の傾向も添える
